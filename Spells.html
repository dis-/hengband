呪文一覧 / Spell List

このデータは、ヘンガバンド（変愚蛮怒）で魔法職が唱えられる全ての呪文（技）の名前と効果説明を定義します。呪文は13の「領域」(realm) に分かれ、各領域は4冊の「呪文書」(book) を持ち、各呪文書には最大8つの呪文が収録されています（全13領域 × 4冊 × 最大8呪文 = 416呪文）。各呪文は識別番号 spell_id（呪文書内での0〜31の位置）、読み込み用の spell_tag、そして日本語・英語の呪文名と効果説明を持ちます。実際の消費MP・失敗率・最低レベルなどの数値は職業や領域ごとにプログラム側で決まるため、このファイルには含まれません。ここにあるのは呪文の「名前」と「何をするか」のテキストのみです。「歌」(MUSIC)、「武芸」(HISSATSU)、「呪術」(HEX) の3領域はメイジ系の呪文ではなく、それぞれ吟遊詩人の歌・剣術の技・呪いの詠唱ですが、データ構造は完全に共通です。

This data defines the name and effect description of every spell (or technique) that a spellcasting class can cast in Hengband. Spells are organized into 13 "realms," each realm holds 4 "spellbooks," and each book contains up to 8 spells (13 realms × 4 books × up to 8 spells = 416 spells total). Each spell carries an identifier spell_id (its 0–31 slot within the book), a load-time spell_tag, and Japanese/English name and effect description. The actual mana cost, fail rate, and minimum level are decided in code per class and realm, so they do not appear in this file — only the spell's name and a plain-text summary of what it does. Three realms — MUSIC (bard songs), HISSATSU (Kendo sword techniques), and HEX (curse chants) — are not mage-style spells, but they share exactly the same data structure.
