恐怖耐性（TR_RES_FEAR）

← プレイヤー耐性一覧 / Resistances

概要

恐怖耐性は TR_RES_FEAR に対応する耐性で、has_resist_fear() が真になると恐怖状態の付与を防ぐ。状態付与本体の BadStatusSetter::mod_fear() と set_fear() は耐性判定を持たず、呼び出し側が has_resist_fear() を見て付与を止める。

効果

恐怖状態の付与

mod_fear() は現在値に加算して set_fear() を呼ぶだけで、耐性による確率軽減はない。

bool BadStatusSetter::mod_fear(const TIME_EFFECT tmp_v)
{
    return this->set_fear(this->player_ptr->effects()->fear().current() + tmp_v);
}

恐怖打撃では、恐怖耐性がある場合にその場で終了する。

if (has_resist_fear(player_ptr)) {
    msg_print("You stand your ground!");
    return;
}
if (randint0(100 + monrace.level / 2) < player_ptr->skill_sav) {
    return;
}
BadStatusSetter(player_ptr).mod_fear(3 + randint1(monap_ptr->rlev));
条件 恐怖付与
恐怖耐性あり 完全に防ぐ
恐怖耐性なし、かつセービング成功 防ぐ
恐怖耐性なし、かつセービング失敗 3 + 1..rlev 加算

恐怖打撃ダメージ

モンスターの恐怖打撃では、耐性がある場合に打撃ダメージも軽減される。

if (has_resist_fear(player_ptr)) {
    monap_ptr->damage = monap_ptr->damage * (randint1(4) + 3) / 8;
}
条件 打撃ダメージ倍率
恐怖耐性なし 100%
恐怖耐性あり (1d4 + 3) / 8

呪いによる臆病

装備呪い COWARDICE の恐怖付与も、恐怖耐性がある場合は発生しない。

if (!one_in_(chance) || (has_resist_fear(player_ptr) != 0)) {
    return;
}
BadStatusSetter(player_ptr).mod_fear(duration);
条件 呪いによる恐怖
恐怖耐性なし、かつ one_in_(chance) 成功 付与
恐怖耐性あり 付与されない
