最大MPへの装備重量ペナルティ

魔法を使う職業では、身に着けている防具（と扱いによっては武器）の重量が一定の上限を超えると、最大MPが減少します。この処理は src/player/player-status.cpp の update_max_mana() 関数で行われます。

以下では、その内部仕様をソースから正確に再導出して解説します。

判定に用いる重量 cur_wgt

まず、装備の重量を合計した値 cur_wgt を求めます。次の装備スロットの重量が常に加算されます。

  • 胴体（ボディアーマー）
  • 頭部（かぶと類）
  • 体の上（クローク類）
  • 腕（籠手・こて）
  • 足（ブーツ類）

さらに、盾スロット・武器スロットの中身のうち「刀剣より重い扱い」のアイテム（内部的に tval が SWORD を超えるもの＝鈍器・飛び道具など）は、常に全重量が加算されます。

一方、武器スロットに「刀剣以下」のアイテム（tval が SWORD 以下）が入っている場合、その重量は職業ごとに決められた割合だけ cur_wgt に加算されます。加算割合は次のとおりです。

  • 全重量（そのまま）を加算する職業：魔術師、上級魔術師、青魔道士、練気術師、および 修行僧・仙術師・魔王
  • 重量の 2/3 を加算：プリースト、吟遊詩人、観光客
  • 重量の 1/2 を加算：超能力者、召喚術師、鏡使い
  • 重量の 1/3 を加算：盗賊、レンジャー、赤魔道士、魔法戦士
  • 重量の 1/5 を加算：パラディン、混沌の戦士

なお重量の単位はゲーム内部値で、アイテムの weight フィールド（0.1ポンド単位）そのままの合計です。したがって内部値を10で割るとポンド表記になります。

cur_wgt = 胴体 + 頭 + 体の上 + 腕 + 足
        + (盾スロットが刀剣より重い ? 盾の全重量 : 0)
        + (主武器が刀剣より重い     ? 主武器の全重量 : 0)
        + (主武器が刀剣以下 ? 主武器の重量 × 職業係数 : 0)
        + (盾スロットが刀剣以下 ? 盾の重量 × 職業係数 : 0)

職業係数 = 1, 2/3, 1/2, 1/3, 1/5 のいずれか（職業依存、整数除算）

重量上限 max_wgt

重量の上限 max_wgt は、職業ごとに定義された armour_weight_limit（内部フィールド名 spell_weight）の値です。この値もアイテム重量と同じ内部単位（0.1ポンド単位）で、10で割るとポンド表記になります。

ソースおよびクラス定義データ lib/edit/ClassMagicDefinitions.jsonc で確認できた armour_weight_limit の値には、次のようなものがあります。

  • 430（内部値。ポンド換算で 43.0）
  • 400（同 40.0）
  • 450（同 45.0）
  • 350（同 35.0）
  • 40（同 4.0）
  • 0（重量制限が実質無効／該当スロットで使わない設定）

正確な職業ごとの割り当ては上記データファイルに定義されています。

最大MPの減少量

cur_wgt が max_wgt を超えたとき、超過分に比例して最大MP（msp）が減少します。基本形は次のとおりです。

超過重量 = cur_wgt - max_wgt          （> 0 のときのみペナルティ発生）

msp = msp - msp × 超過重量 / 除数

除数（分母）は職業によって異なり、値が大きいほど減少がゆるやかになります。ソースで確認できた除数は次のとおりです。

  • 除数 600：魔術師、上級魔術師、青魔道士、練気術師
  • 除数 800：プリースト、超能力者、魔王、吟遊詩人、仙術師、観光客、鏡使い
  • 除数 900：召喚術師
  • 除数 1000：盗賊、レンジャー、修行僧、赤魔道士
  • 除数 1200：パラディン、混沌の戦士、魔法戦士
  • 除数 800：上記以外（デフォルト）
  • サムライ：ペナルティなし（重量超過による最大MP減少を受けない）

計算はすべて整数演算で行われ、最終的に msp が負になった場合は 0 に丸められます。

超過重量 = cur_wgt - max_wgt
if (超過重量 > 0):
    # 例：魔術師なら
    msp = msp - msp × 超過重量 / 600

if (msp < 0):
    msp = 0

除数の違いにより、たとえば魔術師（除数600）は超過1あたりの減少が最も大きく、パラディン・混沌の戦士・魔法戦士（除数1200）は最も小さくなります。サムライだけは重量超過によるMPペナルティを一切受けません（cumber_armor も立ちません）。

籠手（こて）によるMPペナルティ

上記の重量ペナルティとは別に、腕スロット（籠手）を装備していること自体による最大MPペナルティが存在します。適用されるかどうかは職業ごとの has_glove_mp_penalty フラグで決まります。

このフラグが有効な職業では、腕スロットに有効なアイテム（籠手）を装備しているとき、原則として最大MPが 3/4 に減少します。

msp = 3 × msp / 4      （整数除算）

ただし、その籠手が次のいずれかの特性を持つ場合、この籠手ペナルティは免除されます（減少しません）。

  • 自由行動（TR_FREE_ACT）
  • 消費魔力減少（TR_DEC_MANA）
  • 詠唱容易（TR_EASY_SPELL）
  • 魔法道具支配（TR_MAGIC_MASTERY）で、かつ pval が正の値
  • 器用さ上昇（TR_DEX）で、かつ pval が正の値

これらの条件を1つでも満たす籠手であれば、籠手を着けていても最大MPが 3/4 に減らされることはありません。

なお、この籠手ペナルティ（3/4化）は重量ペナルティよりも先に計算され、その後に前述の重量超過ペナルティが適用されます。
