閃光免疫（TR_IM_LITE）

← プレイヤー耐性一覧 / Resistances

概要

閃光免疫は TR_IM_LITE、または mimic_form == MimicKindType::DEMIGOD で得られる。has_immune_lite() が真なら、閃光属性ダメージ倍率は calc_lite_damage_rate() の先頭で 0 になる。

has_resist_lite() は TR_RES_LITE、TR_IM_LITE、ult_res、tim_res_lite、mimic_form == MimicKindType::DEMIGOD を含む。ただし calc_lite_damage_rate() では has_immune_lite() が弱点・通常耐性より先に処理される。

効果

閃光属性ダメージ倍率は次の通り。

per = 100;
if (has_immune_lite(player_ptr)) return 0;
if (race.tr_flags().has(TR_VUL_LITE)) {
    if (race.life() == PlayerRaceLifeType::UNDEAD) per *= 2;
    else per = per * 4 / 3;
}
if (has_resist_lite(player_ptr)) {
    per *= 400;
    per /= randrate(4, 7, mode);
}
if (player_ptr->wraith_form) per *= 2;
return per;
条件 効果
has_immune_lite(player_ptr) calc_lite_damage_rate() が 0 を返す
race.tr_flags().has(TR_VUL_LITE) かつ race.life() == PlayerRaceLifeType::UNDEAD per *= 2
race.tr_flags().has(TR_VUL_LITE) かつ上記以外 per = per * 4 / 3
has_resist_lite(player_ptr) かつ免疫なし per = per * 400 / randrate(4, 7, mode)
player_ptr->wraith_form per *= 2

randrate(4, 7, mode) の値は次の通り。

mode 値
CALC_RAND randint1(4) * 100 + 700
CALC_AVERAGE 950
CALC_MIN 800
CALC_MAX 1100

盲目付与は effect_player_lite() で次の条件をすべて満たすときだけ発生する。

条件
まだ盲目ではない
!has_resist_lite(player_ptr)
!has_resist_blind(player_ptr)
!check_multishadow(player_ptr) 
BadStatusSetter(player_ptr).mod_blindness(randint1(5) + 2);

一時耐性・補足

has_immune_lite() は common_cause_flags(player_ptr, TR_IM_LITE) に加えて、次の条件で FLAG_CAUSE_MAGIC_TIME_EFFECT を立てる。

条件
player_ptr->mimic_form == MimicKindType::DEMIGOD

effect_player_lite() では、ダメージ処理後に player_ptr->wraith_form && !check_multishadow(player_ptr) なら player_ptr->wraith_form = 0 になる。
