放射性廃棄物 / AttributeType::NUKE

← AttributeType 一覧

項目 内容
ID 73
enum AttributeType::NUKE
分類 ダメージ / Damage
プレイヤー処理 effect_player_nuke()
モンスター処理 effect_monster_nuke()
地形処理 effect-feature.cpp で参照
アイテム処理 -
描画色 mh_attr(2)

概要

放射性廃棄物属性（AttributeType::NUKE）は、放射能による攻撃属性。毒属性の系統に属し、耐性は毒耐性で代用される。主な発生源は放射能のブレス、ニュークリア・ボールなどのボール系呪文。

ボール系ではゼロ地点からの距離 r に応じて基礎減衰を受ける。

dam = (dam + r) / (r + 1)

モンスターへの効果

effect_monster_nuke() で処理される。毒免疫（IMMUNE_POISON）で軽減。免疫が無い場合、1/3 の確率で対象を変身（ポリモーフ）させる。

条件 メッセージ ダメージ倍率
IMMUNE_POISON 保持 「には耐性がある。」 dam = dam * 3 / (randint1(6) + 6)
上記以外 （なし） 等倍、1/3 で do_polymorph 
// 耐性時（乱数軽減、約 3/7～3/12 倍）
dam *= 3;
dam /= randint1(6) + 6;

プレイヤーへの効果

effect_player_nuke() で処理される。盲目時のみ「放射能で攻撃された！」と表示。

ダメージ倍率は毒同様 calc_pois_damage_rate() による（毒耐性・一時耐性で軽減）。

per = 100
耐性(has_resist_pois)      : per = (per + 2) / 3
一時耐性(is_oppose_pois)   : per = (per + 2) / 3
dam = dam * per / 100

※ NUKE 専用の calc_nuke_damage_rate()（耐性ごとに per = (2*per + 2) / 5）も定義されているが、effect_player_nuke() は毒レートを使用する。

副次効果（毒耐性・一時耐性のいずれも無く、分身でない場合）:

  • 毒状態を randint0(dam) + 10 ターン付与。
  • 1/5 の確率で「奇形的な変身を遂げた！」。さらにその 1/4 で自己変身（do_poly_self）、3/4 で能力値シャッフル（status_shuffle）。
  • 1/6 の確率で inventory_damage(BreakerAcid(), 2)（所持品破壊判定）。
mod_poison(randint0(dam) + 10);
if (one_in_(5)) { /* 変身 */
    if (one_in_(4)) do_poly_self();
    else            status_shuffle();
}
if (one_in_(6)) inventory_damage(BreakerAcid(), 2);

アイテムへの効果

affect_item() に放射性廃棄物属性（NUKE）の case は無く、床アイテムへの破壊効果は持たない。

地形への効果

affect_feature() では、対象が木（TREE）の場合のみ効果を持つ。

  • メッセージ: 「木は枯れた。」
  • 木は 1/3 で藪（BRAKE）、それ以外で草（GRASS）へ変化する。

これ以外のダンジョン地形に対しては効果を持たない。
