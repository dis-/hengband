毒耐性（TR_RES_POIS）

← プレイヤー耐性一覧 / Resistances

概要

毒耐性は TR_RES_POIS、一時耐性は is_oppose_pois() で判定される。対象コード範囲で毒の TR_IM_POIS や TR_VUL_POIS に相当するプレイヤーフラグ処理は確認できず、calc_pois_damage_rate() は通常耐性と一時耐性だけを処理する。

効果

毒属性ダメージ倍率は per を 100 から始め、通常耐性と一時耐性をそれぞれ適用する。

per = 100;
if (has_resist_pois(player_ptr)) per = (per + 2) / 3;
if (is_oppose_pois(player_ptr)) per = (per + 2) / 3;
dam = dam \* per / 100;
条件 効果
has_resist_pois(player_ptr) per = (per + 2) / 3。
is_oppose_pois(player_ptr) さらに per = (per + 2) / 3。通常耐性と重複する。
effect_player_poison() で !(is_oppose_pois()
effect_player_poison() で !(is_oppose_pois()
effect_player_nuke() で is_oppose_pois()
毒薬 QuaffEffects::poison() で has_resist_pois()
毒の落とし穴 TrapType::POISON_PIT で has_resist_pois()
毒地形 POISON_PUDDLE の追加処理で !has_resist_pois(player_ptr) BadStatusSetter(player_ptr).mod_poison(static_cast<TIME_EFFECT>(damage))。この追加処理の条件は is_oppose_pois() を見ない。

病気打撃 calc_blow_disease() は毒属性ダメージ倍率とは別に、毒耐性と一時毒耐性をそれぞれ乱数式で軽減する。

if (has_resist_pois(player_ptr)) damage = damage \* (randint1(4) + 4) / 9;
if (is_oppose_pois(player_ptr)) damage = damage \* (randint1(4) + 4) / 9;

if (!(has_resist_pois(player_ptr) || is_oppose_pois(player_ptr)))
    BadStatusSetter(player_ptr).mod_poison(randint1(monap_ptr->rlev) + 5);

disease_possibility = randint1(100) > calc_nuke_damage_rate(player_ptr);

calc_nuke_damage_rate() は通常毒耐性・一時毒耐性ごとに次の式を適用する。

per = 100;
if (has_resist_pois(player_ptr)) per = (2 \* per + 2) / 5;
if (is_oppose_pois(player_ptr)) per = (2 \* per + 2) / 5;

一時耐性・補足

has_resist_pois() は TR_RES_POIS の共通原因に加え、player_ptr->ult_res を耐性原因として返す。酸・電撃・冷気と異なり、確認範囲では免疫を耐性原因へ足す処理はない。

is_oppose_pois() は次のいずれかで true になる。

条件
player_ptr->oppose_pois != 0
music_singing(player_ptr, MUSIC_RESIST)
PlayerClass(player_ptr).samurai_stance_is(SamuraiStanceType::MUSOU)
PlayerClass(player_ptr).has_poison_resistance()

set_oppose_pois() は継続時間 v を 0 から 10000 に丸める。PlayerClass(player_ptr).has_poison_resistance() が true の場合は v = 1 にする。既に oppose_pois があり do_dec == false で既存値の方が大きい場合は更新しない。
