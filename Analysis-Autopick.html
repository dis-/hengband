自動拾い

← 解析 / Analysis

自動拾いとは

自動拾い（Auto-picker/Destroyer）は、床に落ちているアイテムに対して「拾う」「破壊する」「放置する」「拾う前に確認する」といった処理を、あらかじめ登録した設定に従って自動的に行う機能である。設定は 1 行につき 1 つの「エントリ」を記述するテキスト形式で管理され、各行は「行動を表す接頭辞」＋「対象を表すキーワード列」＋「アイテム名（省略可）」＋「自動刻印（省略可）」から構成される。

本稿は src/autopick/ 配下のソースから、設定書式・マッチング条件・判定の優先順位・床アイテムに対する処理の流れを再導出したものである。

ゲーム内で自動拾いを有効にする操作

自動拾いは設定ファイル（.prf）に1つ以上のエントリがあれば、その内容に従って常時働く。個別の ON/OFF スイッチは無く、「ルールを書く＝有効になる」。ゲーム内での操作は次の通り。

設定ファイル

  • 設定はユーザーフォルダ（ANGBAND_DIR_USER）の .prf ファイルに保存される。ファイル名は日本語版で picktype.prf、英語版で pickpref.prf。キャラクターごとに分けたい場合は picktype-<キャラクター名>.prf（PT_WITH_PNAME）が使われる。
  • このファイルはゲーム開始時やレベル移動時に自動的に読み込まれる（autopick_load_pref）。読み込みに成功すると「○○を読み込みました。」と表示される。初回はテンプレートが自動生成される。

主なコマンド（マップ画面）

キー 機能
_ 自動拾いエディタを開く（do_cmd_edit_autopick）。ここでルールを編集する
$ 設定ファイルを再読み込みする（do_cmd_reload_autopick）。外部エディタで書き換えた後などに使う
=（オプション） オプションメニューからも自動拾いエディタに入れる

エディタ内の主な操作

エディタはテキストを直接編集する方式で、本稿で説明する書式の行を1行ずつ書く。Emacs風のコントロールキーで操作する。

キー 機能
Ctrl+I 選択したアイテムの名前を挿入（持ち物・床のアイテムからルール行を生成。最も手軽な追加方法）
Ctrl+W 保存して終了（＝設定を適用）
Ctrl+Q 保存せず中止
Ctrl+Z 変更を元に戻す
Ctrl+X / Ctrl+C / Ctrl+V 行のカット / コピー / ペースト
Ctrl+G 条件分岐ブロックの挿入
矢印キー / Ctrl+B,N,P,F 等 カーソル移動

典型的な使い方は、「拾いたい／捨てたいアイテムを持った状態で _ を押す → Ctrl+I でそのアイテムのルール行を挿入 → 先頭に !（破壊）や ~（放置）などの行動接頭辞（後述）を付ける → Ctrl+W で保存」。以後、そのルールが床アイテムに自動適用される。

1 行エントリの構造

1 行の設定は、先頭から順に次の要素で構成される。

[行動接頭辞][ ( ][形容キーワード...][名詞キーワード][ : ][アイテム名][ # 自動刻印]
  • 行動接頭辞（! ~ ;、および表示抑制の (）は行の先頭側でのみ解釈される。
  • 続いて「形容キーワード」（品質・状態などを表す語）を任意個並べ、最後に「名詞キーワード」（アイテム種別を表す語）を最大 1 個置く。
  • キーワード列とアイテム名を明示的に区切りたい場合は :（日本語では全角コロン ： も可）を用いる。
  • # 以降はそのアイテムに自動で刻む銘（inscription）として扱われる。
  • 英大文字は解釈時にすべて小文字化される（アイテム名の照合も小文字同士で行われる）。
  • 空行、および ? % A P C のいずれかで始まり 2 文字目が : の行（条件式・ファイル取込・キーマップ定義など）はエントリとして登録されない。

行動接頭辞

行の先頭に置く記号で、一致したアイテムに対する動作を指定する。何も付けない場合は「拾う」（AUTOPICK）となる。( は「アイテムリスト画面に表示しない」指定で、他の接頭辞と併用できる。

接頭辞 内部動作 意味
（なし） AUTOPICK 自動的に拾う
! AUTODESTROY 自動的に破壊する
~ NOT_AUTOPICK 拾わず床に放置する
; QUERY_AUTOPICK 拾う前に確認を求める
( 表示OFF（DISPLAY解除） アイテムリスト等の画面に表示しない（他接頭辞と併用可）

内部処理では、行動は既定で「拾う」かつ「表示する」の状態で始まり、! ~ ; のいずれかが現れた時点で「拾う」を解除して対応する動作に切り替える。これらの記号は行の連続する先頭部分でのみ効力を持ち、( は表示状態の解除として独立に処理される。

形容キーワード（品質・状態などの条件）

名詞キーワードの前に任意個並べられる条件語。すべての条件を同時に満たしたアイテムだけが一致する（AND 条件）。

キーワード 意味・一致条件
すべての すべてのアイテム（種別を限定しない）
収集中の すでに持ち物の同種スロットに合流できる（is_similar）アイテムのみ
未判明の 種別が判明していない（未鑑別）アイテムのみ
未鑑定の 未鑑定かつ感知もされていないアイテムのみ
鑑定済みの 鑑定済みのアイテムのみ
*鑑定*済みの 完全に鑑定（*鑑定*）されたアイテムのみ
ダイス目の違う 基本ダイスと異なる打撃ダイスを持つ近接武器のみ
無価値の 売却価格が 0 のアイテムのみ
エゴ エゴアイテムのみ（未鑑定時は感知で「素晴らしい」と判ったもの）
上質の 装備品で、鑑定済みなら無銘かつ命中/ダメージ/AC がプラス、未鑑定なら感知が「上質(GOOD)」のもの
無銘の 装備品で、鑑定済みなら無銘、未鑑定なら感知が並/上質/壊れ/呪いのもの
並の 装備品で、無銘かつ呪い・破損なし、命中/ダメージ/AC がプラスでない（未鑑定なら感知が「並」）もの

人間の 人間型モンスターの死体のみ
読めない 現在の職業では読めない魔法書のみ
第一領域の 第一領域の魔法書のみ（魔道士・赤魔法使いを除く）
第二領域の 第二領域の魔法書のみ（魔道士・赤魔法使いを除く）

2冊目の 魔法書の 2 冊目（sval=1）のみ
3冊目の 魔法書の 3 冊目（sval=2）のみ
4冊目の 魔法書の 4 冊目（sval=3）のみ

数値を伴う条件

次の 2 つは数値を伴う。数値は 1〜2 桁で指定する。

書式 意味・一致条件
ダイス目 N 以上の 打撃ダイスの最大値（maxroll）が N 以上の武器のみ
修正値 N 以上の 鑑定済みで、pval があれば pval が N 以上、なければ命中/ダメージ/AC/pval のいずれかが N 以上

種別キーワード（名詞・アイテム分類）

エントリの末尾側に最大 1 個だけ置ける。省略した場合は「アイテム」（すべての種別）とみなされる。特別に「アーティファクト」は他の名詞キーワードの直前に置ける修飾語として扱われる。

アイテム名による照合

キーワード列の後ろにアイテム名を書くと、名前による絞り込みが加わる。照合はアイテム表示名を小文字化した文字列に対して行われる。

記法 動作
名前 アイテム名にその文字列を部分一致で含めば一致
^名前 先頭一致。アイテム名が ^ を除いた文字列で始まる場合のみ一致

^ はエゴ銘のようにアイテム名の先頭に現れる語を、後方の別アイテムに誤って一致させないために用いる。

自動刻印（インスクリプション）

# 以降の文字列は、一致したアイテムへ自動的に付ける銘として扱われる。すでに銘が付いているアイテムには上書きせず、未刻印のアイテムにのみ設定される。刻印は拾う・破壊のどちらの行動でも、対象一致時に適用される。

マッチング（判定）の流れと優先順位

床アイテムやアイテム 1 個に対して設定リストを検索する際は、リストを先頭から順に走査し、is_autopick_match が真を返した最初のエントリを採用する（登録番号が返り、なければ -1）。したがってリスト上で先に書かれたエントリが優先される。なお所持金（GOLD）は常に対象外。

1 エントリ内での判定は次の順で行われ、いずれか 1 つでも条件に反すればそのエントリは不一致となる（全条件 AND）。

  1. 状態・品質条件（未判明／未鑑定／鑑定済み／*鑑定*済み／ダイス目違い／ダイス目以上／修正値以上／無価値／アーティファクト／エゴ／上質／無銘／並／レア／ありふれた／賞金首／ユニーク／人間／読めない／領域／冊目）
  2. 種別条件（check_item_features：名詞キーワードに対応する種別か）。種別条件は if の連なりで、先に判定された種別が優先される。
  3. アイテム名条件（部分一致または ^ 先頭一致）
  4. 「収集中の」条件が付く場合、持ち物内に合流可能な同種アイテムが存在するかを最後に確認

床アイテムに対する自動処理の流れ

プレイヤーがいるマスのアイテムを処理する autopick_pickup_items は、マス上の各アイテムについて次を行う。

  1. 設定リストを検索し、一致エントリの番号を得る（find_autopick_list）。
  2. 一致エントリに自動刻印があれば刻む（auto_inscribe_item）。
  3. 一致がない、または一致エントリの行動が「拾う」でも「確認して拾う」でもない場合は、自動破壊処理（auto_destroy_item）へ回して次のアイテムへ。
  4. 「拾う／確認して拾う」の場合、ザックに空きが無ければ「隙間がない」旨を表示して次へ。
  5. 行動が「確認して拾う」でなければそのまま拾う。
  6. 「確認して拾う」の場合、確認メッセージを出し、承諾すれば拾う。拒否すればそのアイテムは以後問い合わせない印を付ける。

自動破壊の判定

auto_destroy_item は、次の複合条件で破壊するかどうかを決める。

  • ゲームオプション由来の破壊確認（is_opt_confirm_destroy）が成立していれば破壊候補とする。
  • 一致エントリの行動が「破壊（!）」でなければ、破壊候補から外す。
  • 「常に拾う（always_pickup）」オプションが無効なときは、一致エントリの行動が「破壊」なら破壊候補とする。

is_opt_confirm_destroy では、destroy_items が無効なら破壊しない。有効でも次の「残す」オプションに該当すれば破壊しない。

条件 破壊しない対象
leave_worth 売却価格が正のアイテム
leave_equip 武器・防具・矢
leave_chest 中身のある箱
leave_wanted 賞金首の死体など
leave_corpse モンスターの死体
leave_junk がらくた類
leave_special 職業・種族固有の重要アイテム（バルログの人間死体、狩人の骨、忍者の暗黒光源、テイマーのモンスター治癒の魔法棒など）

さらに所持金（GOLD）は常に破壊対象外。破壊が確定したアイテムには破壊マークが付き、後で autopick_delayed_alter が持ち物・床の順にまとめて破壊する。破壊時に「破壊不能」なアイテムはその旨を表示して残る。破壊されたアイテムは検索用に最後の破壊対象として保持される。
