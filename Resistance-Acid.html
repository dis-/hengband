酸耐性（TR_RES_ACID）

← プレイヤー耐性一覧 / Resistances

概要

酸耐性は TR_RES_ACID、一時耐性は is_oppose_acid()、免疫は TR_IM_ACID、弱点は TR_VUL_ACID と PlayerMutationType::VULN_ELEM で判定される。酸属性ダメージは主に acid_dam() で calc_acid_damage_rate() を通して補正される。

効果

ダメージ倍率は per を 100 から始め、免疫、弱点、通常耐性、一時耐性の順に処理する。

per = 100;
if (has_immune_acid(player_ptr)) return 0;

for each flag in has_vuln_acid(player_ptr):
    if flag == FLAG_CAUSE_MUTATION:
        per \*= 2;
    else:
        per += per / 3;

if (has_resist_acid(player_ptr)) per = (per + 2) / 3;
if (is_oppose_acid(player_ptr)) per = (per + 2) / 3;
dam = dam \* per / 100;
条件 効果
has_immune_acid(player_ptr) calc_acid_damage_rate() が 0 を返し、acid_dam() はダメージ 0 で終了する。
has_vuln_acid() の原因が FLAG_CAUSE_MUTATION 現在の per を 2 倍にする。
has_vuln_acid() のその他の原因 現在の per に per / 3 を加える。
has_resist_acid(player_ptr) per = (per + 2) / 3。
is_oppose_acid(player_ptr) さらに per = (per + 2) / 3。通常耐性と重複する。
!(is_oppose_acid()
acid_minus_ac(player_ptr) が true 補正後ダメージを (dam + 1) / 2 にする。装備が TR_IGNORE_ACID で酸を防いだ場合も true。
!aura && !(is_oppose_acid() && has_resist_acid()) inventory_damage(player_ptr, BreakerAcid(), inv)。inv は元ダメージが 30 未満なら 1、60 未満なら 2、それ以上なら 3。

一時耐性・補足

has_resist_acid() は TR_RES_ACID の共通原因に加え、player_ptr->ult_res と has_immune_acid() も耐性原因として返す。has_immune_acid() は TR_IM_ACID と、player_ptr->ele_immune && (player_ptr->special_defense & DEFENSE_ACID) を見る。

is_oppose_acid() は次のいずれかで true になる。

条件
player_ptr->oppose_acid != 0
music_singing(player_ptr, MUSIC_RESIST)
PlayerClass(player_ptr).samurai_stance_is(SamuraiStanceType::MUSOU)

set_oppose_acid() は継続時間 v を 0 から 10000 に丸める。既に oppose_acid があり do_dec == false で既存値の方が大きい場合は更新しない。
