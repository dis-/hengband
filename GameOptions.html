ゲームオプション / Game Options

ゲーム中に = から開く「ゲームオプション」は、入力方法、画面表示、ゲーム進行、自動破壊、記録、出生オプションなどをまとめて変更する設定画面です。このページでは通常プレイで触る項目を、実装上の区分（GameOptionPage）に沿って整理します。

項目名・初期値・メニュー区分は src/game-option/option-types-table.cpp と src/cmd-io/cmd-gameoption.cpp に基づきます。出生オプションのうちスコアやプレイモードを大きく変えるものは ゲームモード と 鉄人オプション に詳しく分けています。

メインメニュー

キー メニュー 内容
1 Input Options 入力・確認・自動操作の補助。
2 Map Screen Options マップの中央寄せ、記憶表示、描画更新。
3 Text Display Options アイテム説明、一覧、ステータス表示などの文字情報。
4 Game-Play Options フロア生成、スタック、死亡時ダンプなどの進行設定。
5 Disturbance Options 休憩・連続行動・探索を中断する条件。
6 Easy Auto-Destroyer Options 簡易自動破壊と保護対象。
r Play record Options プレイ記録へ残すイベント。
p Auto-picker/destroyer editor 自動拾い/自動破壊の詳細ルール編集。
d Base Delay Factor 画面演出などの基本ウェイト。
h Hitpoint Warning HP 警告しきい値。0-9 で 0%-90%。
m Mana Color Threshold MP 色変更しきい値。0-9 で 0%-90%。
a Autosave Options 階移動時・一定ターンごとの自動セーブ。
w Window Flags サブウィンドウに表示する情報。
b Birth Options 出生オプション。通常は閲覧のみ。
c Cheat Options デバッグ/詐欺オプション。スコア登録を放棄する設定。

出生・自動セーブ・詐欺オプション

  • 出生オプションはキャラクター作成後には通常変更できず、ゲーム中メニューでは閲覧のみです。スコアや難易度に関わる主要項目は ゲームモード を参照してください。
  • 自動セーブは autosave_l（新しい階へ入る時）と autosave_t（一定ターンごと）の 2 項目です。F で頻度を 0, 50, 100, 250, 500, 1000, 2500, 5000, 10000, 25000 ターンの順に切り替えます。
  • 詐欺オプションは cheat_* 系です。一度でも ON にすると InnerGameData::add_no_score() によりスコア登録対象外になります。
