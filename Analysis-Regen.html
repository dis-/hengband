自然回復

← 解析 / Analysis

概要

プレイヤーのHP・MPは、何もしなくても時間経過とともに少しずつ自然回復する。この処理は process_player_hp_mp()（src/hpmp/hp-mp-processor.cpp）で行われ、WorldTurnProcessor::process_world() から10ゲームターン毎に1回呼び出される。刻み幅は TURNS_PER_TICK = 10（src/system/gamevalue.h）で定義されており、以下ではこの1回分の処理を「1回の回復処理」と呼ぶ。

HPとMPはいずれも mhp（最大HP）／msp（最大MP）に対する割合で回復し、内部的には 1/65536（= 1/2^16）単位の固定小数点で端数（chp_frac／csp_frac）まで管理されている。そのため実際に整数値が増えるまでには複数回の処理を要することがある。

回復量の基本パラメータ

回復率は regen_amount（HPの回復比率）として算出される。基準となる定数は src/hpmp/hp-mp-regenerator.h で以下のように定義されている。

定数 値 意味
PY_REGEN_NORMAL 197 満腹時の基準回復率（×2^16 単位）
PY_REGEN_WEAK 98 空腹（衰弱）時の回復率
PY_REGEN_FAINT 33 衰弱（気絶寸前）時の回復率
PY_REGEN_HPBASE 1442 HP回復の最小加算量（×2^16 単位）
PY_REGEN_MNBASE 524 MP回復の最小加算量（×2^16 単位）

regen_amount の初期値は PY_REGEN_NORMAL（= 197）で、以降の各補正で増減する。

満腹度による補正

まず満腹度（food）によって基準回復率が決まる。閾値は src/player/digestion-processor.h の定義による。

満腹度 food の範囲 regen_amount 状態
PY_FOOD_WEAK（1000）以上 PY_REGEN_NORMAL（197） 通常
500 以上 1000 未満 PY_REGEN_WEAK（98） 空腹（衰弱）
100 以上 500 未満 PY_REGEN_FAINT（33） 気絶寸前
100 未満（PY_FOOD_STARVE未満） 0 飢餓（自然回復なし）

すなわち満腹度が下がるほど回復率が落ち、飢餓状態（food < 100）では回復率が 0 になる。

その他の状態補正（乗算・除算）

満腹度で決めた regen_amount に対して、以下の補正が順に適用される。パターン（The Pattern）上にいる場合は下記のうち「急速回復」以下の補正は適用されず、代わりに後述の回復不能フラグが立つ。

条件 補正
「急速回復」能力あり（regenerate） regen_amount × 2
修行僧の構え／剣術家の型を取っている（NONE 以外） regen_amount ÷ 2
呪い「回復力低下」（SLOW_REGEN） regen_amount ÷ 5
探索モード（ACTION_SEARCH）または休息（ACTION_REST）中 regen_amount × 2

上記のうち「急速回復」「構え・型」「回復力低下」はパターン上にいない場合のみ適用される。探索・休息の×2はその後に別途適用される。

さらに最後に突然変異による補正が乗算される。

regen_amount = regen_amount × mutant_regenerate_mod / 100

mutant_regenerate_mod（%）は calc_mutant_regenerate_mod()（src/mutation/mutation-calculator.cpp）で算出され、突然変異が無ければ 100（等倍）。変異数に応じて回復速度が低下する。

  • 通常は 1変異につき 10% 減少（mod = 10）。
  • ビーストマンは変異10個までペナルティ無し、それ以降は 1変異につき 5% 減少（count -= 10; mod = 5）。
  • 性格「幸運」は変異カウントを 1 減らす。
  • 下限は 10%（regen < 10 なら 10 に補正）。

計算式は regen = 100 - count × mod（count は補正後の実効変異数、0以下なら 100）。

自然回復しない条件

以下のいずれかに該当する場合、その回のHP自然回復は行われない（regen_amount が 0 になる、または回復関数自体が呼ばれない）。

  • 毒状態（poison）……regen_amount = 0。加えて毎回1ダメージを受ける。
  • **出血（切り傷）**状態（cut）……regen_amount = 0。加えて切り傷の深さに応じたダメージを受ける。
  • 回復不能フラグ（cave_no_regen）が立っている場合……regen_amount = 0 かつ HP回復処理自体が呼ばれない。このフラグは以下の状況で立つ。
    • 溶岩・冷気/電撃/酸/毒の水たまり等、地形ダメージを受けたとき
    • 深い水で溺れているとき
    • 壁の中にいてダメージを受けるとき（幽体化・パターン歩行等でない場合）
    • パターン（The Pattern）上にいるとき（pattern_effect() が真）
    • アンデッド種族が光でダメージを受けているとき

HP回復は最終的に「現在HPが最大HP未満」かつ「cave_no_regen でない」場合にのみ regenhp() が呼ばれる。

また regenhp() 内部でも次の場合は即座に return し、HP回復は行われない。

  • **剣術家の型「降鬼」（KOUKIJIN）**を取っているとき
  • **早駆け（ACTION_HAYAGAKE）**中のとき

HP回復量の計算式

regenhp(player_ptr, percent)（percent は上記で確定した regen_amount）では、最大HP mhp に回復率を掛けたものを 1/2^16 単位で加算する。1回の処理で chp（現在HP、整数）と chp_frac（端数）に加算される総量は次の通り。

加算量（1/65536 単位） = mhp × percent + PY_REGEN_HPBASE
                       = mhp × regen_amount + 1442

この値を 2^16（= 65536）で割った商が現在HPに整数として加算され、余りが端数 chp_frac として次回に持ち越される。実質的な1回あたりのHP回復量（HP単位）は次式で表せる。

1回あたりのHP回復量（HP） = (mhp × regen_amount + 1442) / 65536

PY_REGEN_HPBASE（1442）は最大HPが小さいキャラでも最低限の回復が進むための下駄。回復後、現在HPが最大HPを超えた場合は最大HPに丸められる。

なお、HPが実際に増えたとき（old_chp != chp）は広域マップ移動の回復カウンタ wild_regen が 20 にリセットされる。

MP回復量の計算式

MP回復は regenmana(player_ptr, upkeep_factor, regen_amount)（src/hpmp/hp-mp-regenerator.cpp）で行われる。upkeep_factor はペット維持に要するMPコスト量で、calculate_upkeep() で算出される。さらに以下の場合には upkeep_factor に 100 が加算される。

  • 練習モード（ACTION_LEARN）中
  • 早駆け（ACTION_HAYAGAKE）中
  • 剣術家の型「降鬼」（KOUKIJIN）中

まず実効的な回復レート regen_rate が次式で決まる。

regen_rate = regen_amount × 100 − upkeep_factor × PY_REGEN_NORMAL

すなわちペット維持コストが高いほどMP回復レートは下がり、負になればMPが減少する。処理は現在MP csp の状態で分岐する。

  • 余剰MP（csp > msp）がある場合：余剰分は通常の32倍の速さで減衰する。1回の減衰量（1/65536 単位）は
    減衰量 = msp × 32 × PY_REGEN_NORMAL + PY_REGEN_MNBASE
    で、msp を下回ったら msp に丸める。
  • 余剰MPが無く regen_rate > 0 の場合：MPが回復する。1回の加算量（1/65536 単位）は
    加算量 = msp × regen_rate / 100 + PY_REGEN_MNBASE
    で、msp に達したら msp で頭打ちにする。
  • regen_rate < 0 の場合（余剰MPの有無に関わらず）：MPが減少する。1回の減少量（1/65536 単位）は
    減少量 = msp × (−regen_rate) / 100 + PY_REGEN_MNBASE
    で、0 を下回ったら 0 に丸める。

HP同様、実際に得られる整数MPは加算量を 2^16（= 65536）で割った商で、余りは端数 csp_frac に持ち越される。PY_REGEN_MNBASE（524）は最低回復量の下駄。

MPには毒・切り傷・地形ダメージによる regen_amount = 0 の補正は掛からず（それらの判定はMP処理より後）、MPの増減は主に満腹度・構え/型・突然変異・ペット維持コストによって決まる点に注意。

補足：モンスター・魔道具の回復

  • フロア上のモンスターは regenerate_monsters() により100ゲームターン毎に、maxhp/100（0なら1/2の確率で1）ずつ回復する。「再生」フラグ持ちは2倍。
  • ボール（捕獲）中のモンスターは regenerate_captured_monsters() により30ゲームターン毎に同様の割合で回復する。
  • 魔道具術師は regenmagic() により、取り込んだ杖・魔法棒・ロッドのチャージが回復する。回復量は regen_amount と知能補正（adj_mag_mana）に比例する。

要素 HP回復への影響
満腹度が低い 回復率が段階的に低下、飢餓で 0
「急速回復」能力 ×2
探索・休息中 ×2
構え・型（修行僧/剣術家） ÷2
呪い「回復力低下」 ÷5
突然変異（数に応じ） 最大 90% 減（下限10%）
