破滅の手 / AttributeType::HAND_DOOM

← AttributeType 一覧

項目 内容
ID 98
enum AttributeType::HAND_DOOM
分類 精神・呪い / Mind or curse
プレイヤー処理 effect_player_hand_doom()
モンスター処理 effect_monster_hand_doom()
地形処理 effect-feature.cpp で参照
アイテム処理 -
描画色 0x07

概要

破滅の手 (HAND_DOOM) は、対象の現在HPの割合に応じた大ダメージを与える属性である。モンスターに対してはユニークに無効で、成功判定に通ると現在HPの40〜60%のダメージを与える。プレイヤーに対しては判定に失敗すると装備が呪われHPが減少する (最低1で下げ止まる)。

モンスターへの効果

処理は effect_monster_hand_doom (effect-monster-switcher.cpp) で行われる。

ユニークモンスター (UNIQUE) には効果がなく、「には効果がなかった。」と表示されダメージ 0。

それ以外の場合、術者に応じた成功判定を行う。

術者 成功条件
モンスター caster_lev + randint1(dam) > level + 10 + randint1(20)
プレイヤー (caster_lev / 2) + randint1(dam) > level + randint1(200)

成功した場合、現在HPの割合ダメージを与える。

dam = ((40 + randint1(20)) * hp) / 100
hp < dam なら dam = hp - 1

（すなわち現在HPの約40〜60%。ただし相手を即死させず最低1HPを残す）

失敗した場合、「は破滅の手に耐え切った！」と表示されダメージ 0。

プレイヤーへの効果

処理は effect_player_hand_doom (effect-player-resist-hurt.cpp) で行われる。

抵抗判定に成功した場合 (randint0(100 + rlev/2) < skill_sav かつ 多重影でない)、「しかし効力を跳ね返した！」と表示される。

失敗した場合、多重影でなければ「あなたは命が薄まっていくように感じた！」と表示され、curse_equipment(player_ptr, 40, 20) で装備が呪われる。その後 take_hit でダメージを受ける。

ダメージ処理後、chp < 1 なら chp = 1 (最低1HPで下げ止まる)

アイテムへの効果

アイテムへの効果はない。

地形への効果

地形への効果はない (effect-feature.cpp で無視される属性に含まれる)。
