クラス別魔法 / Class Magic

このデータは各**職業(クラス)の魔法能力を定義します。上位レベルでは、職業ごとに呪文書のタイプ(spell_type)、詠唱に使う能力値(magic_status)、籠手によるMPペナルティの有無、失敗率下限5%の有無、呪文の訓練可否、最初に呪文を使えるレベル、装備重量によるMP減少が始まる閾値を持ちます。下位レベルでは、その職業が扱える各領域(realm)**ごとに、個々の呪文の習得可能レベル・消費MP・難易度(失敗率計算に使用)・初回詠唱成功時の経験値レートが並びます。戦士系など魔法を持たない職業は spell_type が NONE で realms が空です。習得可能な領域・呪文の実際のラインナップは職業選択時に決まる各領域の組み合わせに依存します。

This data defines the magic capabilities of each player class. At the class level, every class carries its spell-book type (spell_type), the ability score used for casting (magic_status), whether gloves impose an MP penalty, whether the spell fail rate is capped at a 5% floor, whether spells are trainable, the level at which the class can first cast, and the equipment-weight threshold above which MP is reduced. At the leaf level, each realm the class can use lists its individual spells with the level at which each becomes learnable, its mana cost, its difficulty (used in fail-rate calculation), and the experience rate awarded on the first successful cast. Non-casting classes (most warrior types) have spell_type = NONE and an empty realms array. The exact realms and spells available depend on the realm combination chosen at character creation.
