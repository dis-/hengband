経験値維持（TR_HOLD_EXP）

← プレイヤー耐性一覧 / Resistances

概要

経験値維持は TR_HOLD_EXP に対応する能力で、プレイヤー状態では player_ptr->hold_exp = has_hold_exp(player_ptr) として保持される。has_hold_exp() は装備・種族・職業・構えの TR_HOLD_EXP に加え、性格 PERSONALITY_MUNCHKIN、一時効果 ult_res を原因として成立する。

経験値吸収への基本処理は drain_exp(player_ptr, drain, slip, hold_exp_prob) で、経験値維持がある場合は指定確率で完全に防ぎ、失敗時も減少量を slip に抑える。アンドロイドはこの関数の経験値吸収を受けない。

効果

成立条件

条件 効果
装備・種族・職業・構えが TR_HOLD_EXP を持つ has_hold_exp() が真になる
性格 PERSONALITY_MUNCHKIN has_hold_exp() が真になる
ult_res has_hold_exp() が真になる

drain_exp() の式

if Android:
    no drain

if hold_exp && evaluate_percent(hold_exp_prob):
    no drain
else if hold_exp:
    lose_exp(slip)
else:
    lose_exp(drain)
条件 経験値減少
アンドロイド なし
経験値維持あり、かつ hold_exp_prob% に成功 なし
経験値維持あり、確率判定に失敗 slip だけ失う
経験値維持なし drain だけ失う

モンスターの経験値吸収打撃

経験値吸収打撃では、経験値維持があると打撃ダメージも軽減される。地獄耐性も同じ式に入る。

damage_ratio = 1000
if has_hold_exp:
    damage_ratio -= 75
if has_resist_neth:
    damage_ratio -= 75
damage = damage * damage_ratio / 1000
打撃効果 drain_exp() に渡す防止確率
EXP_10 95%
EXP_20 90%
EXP_40 75%
EXP_80 50%

生命力吸収打撃では、経験値維持があると打撃ダメージが 9/10 になる。

if hold_exp:
    damage = damage * 9 / 10

その他の経験値吸収

処理 経験値維持の効果
地獄属性の副作用 地獄耐性がない場合、drain_exp(..., hold_exp_prob = 75)
カオス属性の副作用 地獄耐性もカオス耐性もない場合、drain_exp(..., hold_exp_prob = 75)
生命力吸収系の食いつき処理 drain_exp(d, d / 10, 50)
血の呪い hold_exp && evaluate_percent(75) なら吸収なし
暗黒魔法の逆流 spell_id > 15 && one_in_(6) && !hold_exp のときだけ lose_exp(spell_id * 250)

血の呪いで 75% 判定に失敗した場合、経験値維持があれば減少量は exp / 160、なければ exp / 16 になる。

if hold_exp:
    lose_exp(exp / 160)
else:
    lose_exp(exp / 16)
