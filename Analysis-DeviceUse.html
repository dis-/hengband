魔法道具使用成功率

← 解析 / Analysis

概要

杖・魔法棒・ロッドといった魔法道具を使用する際は、プレイヤーの 使用魔法道具技能 skill_dev とアイテムの 基本アイテムレベル item_level を比較して成否を判定する。技能が高くアイテムが低レベルなほど成功しやすい。判定に失敗しても行動turn（100エネルギー）は消費される。

魔法棒・杖と、ロッドとで判定式が異なる。以下はいずれもソース（src/object-use/ 各 execution）の実装に基づく。最低失敗基準値は USE_DEVICE = 3（src/system/gamevalue.h）。

狂戦士（BERSERKER職）は魔法道具を一切使用できず、種類を問わず常に失敗する。

使用魔法道具技能 skill_dev

skill_dev は calc_device_ability()（src/player/player-status.cpp）で毎回再計算される。

skill_dev = 種族r_dev + 職業c_dev + 性格a_dev
          + (職業x_dev × レベル ÷ 10) + (性格a_dev × レベル ÷ 50)
          + 装備の魔法道具支配ボーナス
          + adj_int_dev[知力]
          - 20 （狂戦士化状態 is_shero のとき）
  • 種族 r_dev / 職業 c_dev / 性格 a_dev … 基本値（race_info / class_info / personality_info）。変身中は変身先の種族値を使う。
  • レベル成長 … 職業ごとの伸び x_dev × Lv/10 と、性格ごとの伸び a_dev × Lv/50 を加算。
  • 魔法道具支配（TR_MAGIC_MASTERY） … 装備している各スロットのアイテムが持つと 8 × pval を加算（例: 「魔法道具支配 +2」で +16）。
  • 知力補正 adj_int_dev[知力] … 下表。知力が高いほど大きく加算される。
  • 狂戦士化状態（is_shero） … ヒーロー上位の狂乱状態の間は -20。混乱については後述（判定時に技能を半減）。

ゲーム画面の「魔法道具」表示との対応

キャラクター情報画面（C コマンド）右下の技能欄に表示される 「魔法道具」の数値が、そのまま skill_dev である。例えば 魔法道具 : 63-超越 なら skill_dev = 63。したがって画面の値を読めば、判定式へそのまま代入できる。

  • 数値部分（63- の 63）は、オプション 「技能値等に実値を並記する」（show_actual_value、既定ON） が有効なときだけ %3d- 形式で並記される。OFF のときは段位ラベルのみ表示。
  • 段位ラベル（悪い〜伝説的）は likert(skill_dev, 6)（src/view/status-first-page.cpp）が skill_dev ÷ 6（整数除算）で決める。魔法道具欄の除数は 6。
  • 表示値は装備の魔法道具支配・知力・狂戦士化状態（is_shero）を反映済み。ただし 混乱の 1/2 補正は使用時の判定にのみ掛かり、この画面表示には反映されない。値が負なら「最低」と表示される。
skill_dev の範囲 段位ラベル
0未満 最低
0〜11 悪い
12〜17 劣る
18〜29 普通
30〜35 良い
36〜41 大変良い
42〜53 卓越
54〜83 超越
84〜107 英雄的
108以上 伝説的[N]（N = ((skill_dev ÷ 6 − 17) × 5) ÷ 2）

例の skill_dev = 63 は 63 ÷ 6 = 10 で「超越」。この値でレベル30の魔法棒（item_level = 30）を使うなら、chance = 63 − 30 = 33、成功率 ≈ 1 − 2/33 ≈ 93.9% となる。

魔法棒・杖（Wand / Staff）

魔法棒（zapwand-execution.cpp）と杖（use-execution.cpp）は同一の判定式を使う。

item_level = 基本アイテムレベル
if (item_level > 50)  item_level = 50 + (item_level - 50) / 2   // 高レベル品は圧縮
chance = skill_dev
if (混乱中)  chance = chance / 2
chance = chance - item_level
if (chance < 3 かつ one_in_(3 - chance + 1))  chance = 3        // 低技能の救済
失敗する条件: (chance < 3) または (randint1(chance) < 3) または 狂戦士職
  • chance ≥ 3 のとき、成功率は (chance − 2) / chance ＝ 1 − 2/chance。randint1(chance) が 1 か 2 のときだけ失敗するため、どれだけ技能が高くても 100% にはならない。
  • chance < 3（技能がアイテムレベルに大きく届かない）とき、one_in_(4 − chance) を引けた場合のみ chance = 3 に底上げされ、その後 1/3 で成功する。届かない場合は必ず失敗。

ロッド（Rod）

ロッド（zaprod-execution.cpp）は魔法棒・杖と異なり、item_level の高レベル圧縮を行わず、技能とアイテム難度を双方向に補正し合う。

item_level = 基本アイテムレベル
chance = skill_dev
if (混乱中)  chance = chance / 2
fail = item_level + 5
if (chance > fail)  fail  -= (chance - fail) * 2      // 技能超過分だけ難度を大きく下げる
else                chance -= (fail - chance) * 2      // 技能不足分だけ判定値を大きく下げる（二重ペナルティ）
if (fail   < 3)  fail   = 3
if (chance < 3)  chance = 3
判定:
  狂戦士職            → 失敗
  else if (chance > fail) → randint0(chance × 2) ≥ fail で成功  → 成功率 1 − fail/(2×chance)
  else                    → randint0(fail × 2) < chance で成功   → 成功率 chance/(2×fail)
  • 技能が難度（item_level + 5）をちょうど満たす（chance == fail）とき、成功率は 50%。
  • 技能が難度を上回るほど fail が二倍速で下がり、成功率は 100% に漸近する。逆に不足すると chance が二倍速で下がり急激に成功率が落ちる。
  • ロッドは充填中（timeout > 0）だと成功判定以前に使用できない。チャージ切れの概念はなく、成否は上式のみで決まる。

状態・その他の影響（まとめ）

要因 効果
狂戦士（BERSERKER職） 魔法道具を一切使用できない（常に失敗）。
混乱中 判定時に chance（＝実効技能）を 1/2 にする。
狂戦士化状態（is_shero） skill_dev を −20。
魔法道具支配（TR_MAGIC_MASTERY） 装備1つにつき skill_dev += 8 × pval。
高レベルの魔法棒・杖 item_level > 50 の超過分を半分に圧縮（ロッドには圧縮なし）。

判定に失敗しても行動turn（100エネルギー）は消費され、成功時は (item_level + レベル/2) / レベル の経験値が入る。
