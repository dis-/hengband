暗黒領域の失敗ペナルティ

← 解析 / Analysis

概要

「暗黒領域」は内部の領域種別 RealmType::DEATH に対応します（src/player/player-realm.cpp の領域名テーブルで RealmType::DEATH の日本語名が「暗黒」と定義され、対応する魔法書は ItemKindType::DEATH_BOOK「暗黒の魔法書」です）。本稿では暗黒（死）領域魔法の詠唱に失敗したときに発生する副作用（ペナルティ）の内部仕様を、ソースコードから確認できた範囲でのみ記述します。

呪文の詠唱失敗判定そのものは失敗率 chance に基づいて行われ、失敗した場合に以下の一連の処理が実行されます。処理の中心は src/cmd-action/cmd-spell.cpp の失敗時ブロックです。

失敗時に共通して起こること

詠唱に失敗すると、まず失敗メッセージが表示され、失敗音が鳴ります。続いて領域ごとの徳（Virtue）変化が判定されます。暗黒（死）領域の場合、確率的に「反生命（UNLIFE）」の徳が下がります。

失敗時、randint1(100) < chance ならば
    「反生命(UNLIFE)」の徳 -1

ここで randint1(100) は 1〜100 の一様乱数、chance は失敗率（％）です。

その後、SpellProcessType::FAIL を指定して呪文個別の失敗時副作用処理（exe_spell）が呼ばれます。ただし暗黒（死）領域の呪文処理関数 do_death_spell（src/realm/realm-death.cpp）は FAIL モードでの分岐を持たないため、暗黒領域では呪文個別の失敗時副作用は発生しません（歌・トランプ領域のような呪文固有の失敗処理は暗黒領域には存在しません）。

暗黒領域固有の失敗ペナルティ（逆流）

暗黒（死）領域に固有のペナルティは、魔法書の種別が暗黒の魔法書（ItemKindType::DEATH_BOOK）であることで発動判定される、以下の「逆流」処理です。

まず、発動するかどうかの判定は次のとおりです（spell_id は 0 から始まる呪文の通し番号）。

発動判定: randint1(100) < spell_id

spell_id は魔法書内の呪文位置に応じた 0 始まりの通し番号で、番号が大きい（＝高位）呪文ほど逆流が発動しやすくなります。呪文番号 0 の呪文では randint1(100) < 0 が成立しないため、この逆流は発生しません。

発動判定を満たした場合、以下の 2 通りに分岐します。sval は暗黒の魔法書の巻数（0 始まり）です。

(A) 4冊目の魔法書 かつ 1/2 の確率: 正気喪失

条件: sval == 3 かつ one_in_(2)
効果: sanity_blast(必要領域魔法版) が発動

sval == 3（4 冊目の暗黒の魔法書）の呪文で逆流が発動し、さらに 1/2 の確率を引いたとき、sanity_blast（src/player/eldritch-horror.cpp）が「暗黒領域魔法の詠唱失敗による」モードで呼ばれます。このとき「ネクロノミコンを読んで正気を失った！」というメッセージが表示され、以下の判定に進みます。

判定強度 power = 100
セーヴィングスロー: 5回連続で (プレイヤーの技能 skill_sav - power) の判定に全て成功すれば無効化

5 回の判定に一度でも失敗すると、randint1(22) による乱数で選ばれた正気喪失の効果（低能・臆病といった突然変異の付与、記憶喪失、能力値低下など）のいずれかが発生します（具体的にどの効果になるかは sanity_blast 内の分岐で決まります）。

(B) それ以外: HP減少（暗黒魔法の逆流）

上記 (A) の条件を満たさない場合（4 冊目以外の魔法書、または 4 冊目でも 1/2 を外した場合）は、HP へのダメージが発生します。

メッセージ: 「痛い！」
ダメージ: (sval + 1)d6  （原因表記: 「暗黒魔法の逆流」）

すなわちダイス Dice::roll(sval + 1, 6) により、sval + 1 個の 6 面ダイスの合計値だけ HP が減少します。巻数（sval）が大きい魔法書ほどダメージが大きくなります。ダメージ種別は DAMAGE_LOSELIFE です。

さらに、このダメージ発生時には経験値喪失の追加判定があります。

条件: spell_id > 15 かつ one_in_(6) かつ プレイヤーが経験値保持(hold_exp)を持たない
効果: 経験値を spell_id * 250 だけ喪失

spell_id が 15 より大きい（＝より高位の）呪文で、1/6 の確率を引き、かつ経験値保持能力を持たない場合に限り、spell_id * 250 の経験値を失います。

失敗判定に関するその他の徳変化

上記処理の最後に、失敗率に関連した徳判定が行われます。

randint1(100) >= chance ならば
    「機会(CHANCE)」の徳 -1

まとめ（暗黒領域の失敗ペナルティ一覧）

  • 徳変化: 確率 randint1(100) < chance で「反生命」-1、randint1(100) >= chance で「機会」-1
  • 呪文個別の失敗時副作用: なし（do_death_spell は FAIL 分岐を持たない）
  • 逆流の発動判定: randint1(100) < spell_id
    • 4冊目(sval == 3) かつ one_in_(2): 正気喪失（sanity_blast、判定強度 power = 100、5回セーヴ）
    • それ以外: HP減少 (sval + 1)d6（種別 DAMAGE_LOSELIFE、原因「暗黒魔法の逆流」）
      • 加えて spell_id > 15 かつ one_in_(6) かつ 経験値保持なし で spell_id * 250 の経験値喪失
