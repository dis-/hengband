水耐性（TR_RES_WATER）

← プレイヤー耐性一覧 / Resistances

概要

水耐性は TR_RES_WATER に対応する高級耐性で、has_resist_water() が真になると水属性ダメージを軽減し、水属性の朦朧・混乱・アイテム破壊を防ぐ。深い水での溺れ判定にも使われる。

効果

水属性ダメージ

calc_water_damage_rate() では、水耐性がある場合だけ倍率が変わる。

per = 100;
if (has_resist_water(player_ptr)) {
    per *= 400;
    per /= randrate(4, 7, mode);
}

CALC_RAND では randrate(4, 7) は (1d4 + 7) * 100 なので、実戦時の倍率は次の範囲になる。

damage_rate = 400 / (1d4 + 7)
実効倍率 = 36% から 50%
条件 ダメージ倍率
水耐性なし 100%
水耐性あり 400 / (1d4 + 7)%

水属性の副次効果

水属性の副次効果は、水耐性がない場合だけ発生する。

if (!has_resist_sound(player_ptr) && !has_res_water) {
    bss.mod_stun(randnum1<short>(40));
}
if (!has_resist_conf(player_ptr) && !has_res_water) {
    bss.mod_confusion(randint1(5) + 5);
}
if (one_in_(5) && !has_res_water) {
    inventory_damage(player_ptr, BreakerCold(), 3);
}
条件 副次効果
水耐性なし、かつ轟音耐性なし 朦朧 1..40 加算
水耐性なし、かつ混乱耐性なし 混乱 1d5 + 5 加算
水耐性なし 1/5 で冷気系アイテム破壊 inventory_damage(..., 3)
水耐性あり 上記の水属性副次効果を防ぐ

深い水での溺れ

深い水地形では、水耐性は溺れを防ぐ条件に含まれる。

if (can_drown && !player_ptr->levitation && !player_ptr->can_swim && !has_resist_water(player_ptr)) {
    if (calc_inventory_weight(player_ptr) > calc_weight_limit(player_ptr)) {
        take_hit(player_ptr, DAMAGE_NOESCAPE, randint1(player_ptr->lev), "drowning");
    }
}
条件 溺れ
深い水、浮遊なし、水泳不可、水耐性なし、重量超過 1..レベル ダメージ
水耐性あり この溺れ条件を満たさない

自動走行時の深い水回避

自動走行では、深い水を無視できる条件にも水耐性が含まれる。

can_ignore_water =
    player_ptr->levitation ||
    player_ptr->can_swim ||
    has_resist_water(player_ptr) ||
    calc_inventory_weight(player_ptr) <= calc_weight_limit(player_ptr);
