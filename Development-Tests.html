集計基準 / Counting rules

  • テストソース数: hengband_test_SOURCES に登録された test-*.cpp。テストランナーの test-main.cpp は除外。
  • ケース数: 各登録ソースにある TEST_CASE(...) の宣言数。SUBCASE や個々の CHECK は別ケースとして数えない。
  • 構成による差: 条件付きコンパイル（日本語版・英語版、Windows・Unix 系など）の各分岐にある宣言をすべて含みます。実行時のケース数やテスト合格数を示すものではありません。
  • 対象: テストファイル名から読み取れる主対象。複数コンポーネントを横断するテストは、テストの目的を表す名称を記載。

実行方法やテスト追加時の登録手順は、develop の src/test/README.md を参照してください。

一覧外の検証 / Other checks

次の回帰プローブは Unix 系の既存ビルドディレクトリで明示的に実行します。make check や MSVC の doctest には登録されていないため、上記のファイル数・ケース数には含めません。

  • make -C src -j2 check-main-window-wipe: 共通描画の回帰プローブ。メッセージ待ち中の描画要求の保留・再入と、消去後の所持金描画などを独立プロセスで確認します。
  • make -C src -j2 check-arena-status: アリーナの状態解除の回帰プローブ。時限効果・歌・呪術の解除や入場・観戦・取り消しなどを独立プロセスで確認します。

ゲーム進行やフロントエンドを含むシナリオ検証は、制御サーバと hbctl.py の手順を参照してください。
