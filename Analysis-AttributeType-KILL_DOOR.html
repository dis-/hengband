ドア破壊 / AttributeType::KILL_DOOR

← AttributeType 一覧

項目 内容
ID 41
enum AttributeType::KILL_DOOR
分類 地形 / Feature
プレイヤー処理 未処理（defaultでダメージ0）
モンスター処理 未処理（defaultでスキップ/ダメージ0）
地形処理 effect-feature.cpp で参照
アイテム処理 effect-item.cpp で参照
描画色 既定色

概要

ドア破壊属性（AttributeType::KILL_DOOR）は、罠と扉を破壊して床（通路）に変える地形改変属性。「トラップ・ドア破壊」系の効果が発生源。モンスターへの直接ダメージは持たない。

ボール系ではゼロ地点からの距離 r に応じて基礎減衰を受ける。

dam = (dam + r) / (r + 1)

地形への効果

affect_feature() の case AttributeType::KILL_DOOR で処理される。

条件 結果 メッセージ
罠がある（has_trap_at()）または DOOR 特性を持つ地形 cave_alter_feat(..., TUNNEL) で床（通路）へ変化 既知時「まばゆい閃光が走った！」
上記以外 何もしない （なし）
  • 処理後、盲目でなく視線が通る（has_los()）場合、CAVE_UNSAFE フラグを消して再描画し obvious を立てる。

KILL_TRAP と異なり、扉は解錠ではなく TUNNEL で破壊され床になる。木やその他の地形には効果を持たない。

モンスターへの効果

effect_monster_switcher の default 分岐に落ち、skipped = true／dam = 0 となる。モンスターへの効果は無い。

プレイヤーへの効果

effect_player_switcher に KILL_DOOR の分岐は無く、プレイヤーへの効果は無い。

アイテムへの効果

affect_item() の case AttributeType::KILL_DOOR（KILL_TRAP と共通）で処理される。対象は箱（CHEST）のみ。

条件 結果 メッセージ
箱（CHEST）でない 何もしない （なし）
箱の pval <= 0（罠・施錠が無い） 何もしない （なし）
箱に罠・施錠がある（pval > 0） pval を負値化して罠・施錠を解除、鑑定済みにする 既知かつ発見済みなら「カチッと音がした！」
