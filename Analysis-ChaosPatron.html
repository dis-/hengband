カオスパトロンからの報酬

「カオスパトロン」は、カオスの戦士（クラス）または突然変異「カオスの守護」（CHAOS_GIFT）を持つキャラクターに割り当てられる守護存在です。キャラクター作成時に全16体の中からランダムに1体が決定されます。ここでは、パトロンが「報酬」（多くは有益ですが、しばしば懲罰でもある）を与える仕組みと、その内容をソースコードから再導出して解説します。

このページの記述は src/player/patron.cpp、src/player/patron.h、src/mind/mind-chaos-warrior.cpp、src/player/player-status.cpp に基づきます。

報酬が発生する契機

報酬は、キャラクターがそれまでの最大レベルを更新してレベルアップした瞬間に発生します。具体的には、以下の条件を満たすときにパトロンからの報酬処理が呼び出されます。

  • 新しいレベルがそれまでの最大レベルを超えた（初到達のレベルである）
  • 職業が「カオスの戦士」である、または突然変異「カオスの守護」を持っている

なお、1回の経験値取得で複数レベルを同時に上がった場合、報酬の多重受け取りを防ぐフラグ（suppress_multi_reward）により、原則として1回分に抑えられます。

報酬決定のおおまかな流れ

パトロンごとに20項目の「報酬テーブル」が定義されています。報酬が発生すると、次の手順で1つの効果が選ばれます。

  1. まず「有害な効果（nasty）」を許可するかどうかを乱数で判定します。標準では確率は約6分の1です。ただしプレイヤーレベルによって危険度が変動します（下表）。
  2. 有害な効果が許可された場合、テーブルの1〜20番目からランダムに1項目を選びます（先頭側に危険な効果が並ぶ）。許可されなかった場合は6〜20番目から選びます（比較的安全な後半のみ）。
  3. さらに、それとは別に6分の1の確率で、テーブルを無視して「突然変異を与える」報酬に置き換わることがあります（明示的な報酬指定時を除く）。

有害効果の発生確率（nasty_chance）

プレイヤーレベルの条件 有害効果が許可される確率
レベルが13ちょうど 2分の1
レベルが13の倍数（13を除く） 3分の1
レベルが14の倍数 12分の1
上記以外（標準） 6分の1

報酬テーブルの各効果

報酬テーブルに登録される効果の種類（patron_reward）と内容を、有益な報酬・中立/状況次第・懲罰に分けて示します。数値はソースで確認できたもののみ記載します。「lev」はプレイヤーレベルを指します。

混沌の武器について

「混沌の武器」の下賜（REW_CHAOS_WP）では、プレイヤーレベルに応じた剣が選ばれます。低レベルではダガーなどの小型武器、高レベルほど強力な剣となり、レベル40以降は「カオスブレード」が候補に入ります。生成される武器には命中・ダメージ修正（それぞれ 3＋ダンジョン階層依存）と1種のランダム耐性が付き、エゴ「混沌（CHAOTIC）」が付与されます。

パトロンごとの傾向

全16体のパトロンは、それぞれ固有の20項目報酬テーブルと「強化傾向能力（増強・能力低下で優先されやすい能力）」を持ちます。テーブルの構成によって、召喚を多用する者・アイテムを気前よく与える者・懲罰が重い者など個性があります。強化傾向能力は以下の通りです（ソースで確認できた範囲）。

パトロン（日本語 / 英語） 強化傾向能力
スローター / Slortar 耐久力（CON）
マベロード / Mabelode 耐久力（CON）
チャードロス / Chardros 腕力（STR）
ハイオンハーン / Hionhurn 腕力（STR）
キシオムバーグ / Xiombarg 腕力（STR）
ピアレー / Pyaray 知能（INT）
バラン / Balaan 腕力（STR）
アリオッチ / Arioch 知能（INT）
イーカー / Eequor 耐久力（CON）
ナージャン / Narjhan 魅力（CHR）
バロ / Balo ランダム（毎回無作為な能力）
コーン / Khorne 腕力（STR）
スラーネッシュ / Slaanesh 魅力（CHR）
ナーグル / Nurgle 耐久力（CON）
ティーンチ / Tzeentch 知能（INT）
カイン / Khaine 腕力（STR）

傾向としては、コーンやカイン、バロのように懲罰（怒り・分解の球・苛立ち）や召喚を多く含む攻撃的なパトロンがいる一方、ナージャンやティーンチのようにアイテム下賜や能力上昇に寄った比較的温厚なパトロンもいます。「バロ」は強化傾向がランダムで、テーブルにも増強と全能力低下が混在するなど、特に予測しにくい存在です。

なお、最終ボス（混沌のサーペント）を撃破して勝利者になったとき、パトロンはプレイヤーを称賛するメッセージを発します（実質的な報酬効果はありません）。
