描画色 既定色

概要

聖戦（AttributeType::CRUSADE、GF_CRUSADE）は、善なるモンスターを味方（ペット）に引き入れ、それ以外のモンスターを恐慌させる属性である。処理は effect_monster_crusade() および補助関数 effect_monster_crusade_domination()（src/effect/effect-monster-charm.cpp）にある。

善のモンスターに対しては支配（味方化）＋加速を試み、善以外や支配に失敗したモンスターには恐怖を与える。

モンスターへの効果

まず effect_monster_crusade_domination() で支配判定を行う。

適用外の条件（支配失敗＝false）:

条件 挙動
対象が善（MonsterKindType::GOOD）でない 支配処理を行わず false
闘技場内（inside_arena） 支配処理を行わず false

善のモンスターの場合、以下の補正を行う。

NO_CONF を持つなら dam -= 50
dam < 1 なら dam = 1

その後の分岐:

  • 対象が既にペットの場合、加速のみ行う。

の動きが速くなった。

set_monster_fast(..., 残り加速 + 100) で加速する。

  • そうでない場合、以下のいずれかに該当すると支配失敗:
失敗条件
クエスト対象（QUESTOR）
ユニーク（UNIQUE）
ペット化不可フラグ（NOPET）
プレイヤーが has_aggravate（周囲刺激）状態
(モンスターのレベル + 10) > randint1(dam)

失敗時は 1/4 の確率で NOPET フラグが立ち、以後ペットにできなくなる。

支配成功時:

を支配した。

ペット化（set_pet）し、set_monster_fast(..., 残り加速 + 100) で加速する。プレイヤーに見えていれば善（GOOD）の種族知識が記録される。

支配に成功しなかった場合、effect_monster_crusade() 側で恐怖処理に移る。

条件 効果
NO_FEAR を持たない do_fear = randint1(90) + 10（恐怖付与）
NO_FEAR を持ち、視認済み 恐怖耐性を種族知識に記録

いずれの経路でも最終的に dam = 0（直接ダメージは無し）となる。

プレイヤーへの効果

switch_effects_player()（src/effect/effect-player-switcher.cpp）に CRUSADE の分岐は無く、default に落ちて dam = 0 となり、プレイヤーには何の効果も無い。

アイテムへの効果

affect_item()（src/effect/effect-item.cpp）に CRUSADE の分岐は無く、default（break のみ）に落ちるため、アイテムには一切影響しない。

地形への効果

affect_feature()（src/effect/effect-feature.cpp）に CRUSADE の分岐は無く、default（break のみ）に落ちるため、地形には一切影響しない。
