生命魅了 / AttributeType::CHARM_LIVING

← AttributeType 一覧

項目 内容
ID 101
enum AttributeType::CHARM_LIVING
分類 モンスター制御 / Monster utility
プレイヤー処理 未処理（defaultでダメージ0）
モンスター処理 effect_monster_charm_living()
地形処理 -
アイテム処理 -
描画色 既定色

概要

生命魅了 (CHARM_LIVING) 属性は、生命を持つモンスターを魅了してペット化させる効果。ダメージは与えない（処理後に dam = 0）。効果はモンスターへの魅了判定のみで、プレイヤー・アイテム・地形への効果はない。

魅了パワー (dam) は術者の徳 (Virtue) によって補正される。

// 反生命 (UNLIFE) の徳を持つ場合
dam -= virtues[UNLIFE] / 10;
// 個人主義 (INDIVIDUALISM) の徳を持つ場合
dam -= virtues[INDIVIDUALISM] / 20;

モンスターへの効果

処理は effect_monster_charm_living() (effect-monster-charm.cpp)。まず「(対象)を見つめた。」と表示される。抵抗判定は common_saving_throw_charm() (spells-diceroll.cpp) による。

対象が生命を持たない (has_living_flag() が偽) 場合、または抵抗判定が成立した場合は魅了失敗となる。

抵抗判定 common_saving_throw_charm() は、次のいずれかで**必ず抵抗（魅了失敗）**となる。

条件 結果
アリーナ内 (inside_arena) 抵抗
全耐性 (RESIST_ALL) を持つ 抵抗
混乱しない (NO_CONF) を持つ 抵抗
クエスト対象 (QUESTOR) または NOPET フラグ 抵抗

上記に該当しない場合、パワーに魅力補正を加えたうえでレベル判定を行う。

pow += adj_chr_chm[CHR] - 1;
// ユニーク または ナズグルの場合
pow = pow * 2 / 3;
// 以下が真なら抵抗成功（魅了失敗）
monrace.level > randint1((pow - 10) < 1 ? 1 : (pow - 10)) + 5

判定結果ごとの挙動:

結果 メッセージ 追加処理
抵抗成功／非生命 「には効果がなかった。」 1/4 の確率で NOPET フラグを付与
プレイヤーが反感 (aggravate) 持ち 「はあなたに敵意を抱いている！」 1/4 の確率で NOPET フラグを付与
魅了成功 「を支配した。」 ペット化。対象が動物 (ANIMAL) なら自然 (NATURE) の徳 +1

プレイヤーへの効果

CHARM_LIVING に対応するプレイヤー側 case は effect-player-switcher.cpp に存在せず、default により dam = 0 となり効果はない。

アイテムへの効果

affect_item() (effect-item.cpp) に CHARM_LIVING の case は存在せず、床のアイテムに影響しない。

地形への効果

affect_feature() (effect-feature.cpp) に CHARM_LIVING の case は存在せず、地形を変化させない。
