火炎耐性（TR_RES_FIRE）

← プレイヤー耐性一覧 / Resistances

火炎耐性の効果

プレイヤーが受ける火炎属性ダメージは、fire_dam() で火炎免疫を先に判定し、免疫がある場合は 0 になる。免疫がなく、基本ダメージが正の場合、calc_fire_damage_rate() の倍率を掛けて 100 で割る。

実ダメージ = 基本ダメージ * calc_fire_damage_rate(player_ptr) / 100

TR_RES_FIRE は get_player_flags() で has_resist_fire() に対応する。has_resist_fire() は TR_RES_FIRE の通常耐性に加えて、究極耐性 ult_res と火炎免疫 has_immune_fire() も火炎耐性ありとして扱う。

ダメージ倍率

calc_fire_damage_rate() は per = 100 から開始し、火炎弱点、通常耐性、一時耐性の順に整数演算で倍率を変える。戻り値は百分率で、100 が等倍。

per = 100

火炎弱点ごと:
  変異による弱点なら per = per * 2
  それ以外の弱点なら per = per + per / 3

通常火炎耐性があれば per = (per + 2) / 3
一時火炎耐性があれば per = (per + 2) / 3

通常火炎耐性だけなら 100 から 34 になり、約 1/3 ダメージになる。

(100 + 2) / 3 = 34

一時火炎耐性だけでも同じく 34 になる。通常火炎耐性と一時火炎耐性が両方ある場合は、同じ処理が2回かかり 12 になる。

通常耐性あり: (100 + 2) / 3 = 34
一時耐性あり: (34 + 2) / 3 = 12

一時火炎耐性

一時火炎耐性は is_oppose_fire() で判定される。確認できた成立条件は次の通り。

  • oppose_fire != 0
  • 耐性の歌 MUSIC_RESIST を歌っている
  • 侍の無想の構え
  • 悪魔変化中
  • バルログでレベルが 44 より大きい

set_oppose_fire() で設定される時限値は 0 から 10000 に丸められる。バルログでレベルが 44 より大きい場合、または悪魔変化中の場合は、設定値が 1 になる。

火炎免疫

fire_dam() は has_immune_fire() が真なら、calc_fire_damage_rate() の計算前に 0 を返す。したがって火炎免疫中のHPダメージ倍率は実質 0%。

has_immune_fire(player_ptr) が真 -> 火炎ダメージ 0

has_immune_fire() は TR_IM_FIRE と、元素免疫 ele_immune 中かつ DEFENSE_FIRE が立っている場合で成立する。

火炎弱点

火炎弱点は has_vuln_fire() で判定され、TR_VUL_FIRE と変異 VULN_ELEM が確認できる。calc_fire_damage_rate() では弱点の原因ビットごとに倍率を増やす。

変異 VULN_ELEM による弱点は 2 倍になる。

per = per * 2

それ以外の火炎弱点は per / 3 を加える。

per = per + per / 3

弱点計算は耐性計算より先に行われる。例えば変異による火炎弱点と通常火炎耐性が同時にある場合、確認できる計算は次の通り。

弱点: per = 100 * 2 = 200
通常耐性: per = (200 + 2) / 3 = 67

変異以外の火炎弱点と通常火炎耐性が同時にある場合は次の通り。

弱点: per = 100 + 100 / 3 = 133
通常耐性: per = (133 + 2) / 3 = 45

付随効果

fire_dam() では、通常火炎耐性または一時火炎耐性がある場合、火炎による腕力低下判定は行われない。両方がある場合、火炎による所持品破壊処理も行われない。どちらか一方だけの場合は、所持品破壊処理は呼ばれる。
