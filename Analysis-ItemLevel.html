アイテムレベルが決まるルール

← 解析 / Analysis

概要

変愚蛮怒におけるアイテムの「レベル」は、生成の全過程で二重の意味を持ちます。

  • ベースアイテムの生成レベル: どの種類のアイテム（＝ベースアイテム）が抽選されるかを決める深度。これがいわゆる「アイテムレベル」で、深い階ほど高レベルなアイテム種別が出やすくなります。
  • 強化レベル (magic level): 抽選されたアイテムに与えられる魔法的強化の基準となる深度。上質 (good) / 高級品 (great) の判定、エゴ・アーティファクト化、ボーナス値の大きさに効きます。

両者の起点となるのがフロアの生成レベル object_level です。本稿では object_level がどのように決まり、それがアイテムの「抽選」と「強化」にどう波及するかを、ソースで確認できた範囲で説明します。

フロアの生成レベル (base_level / object_level)

フロアには基準となる生成レベル base_level と、そこから一時的に変更されるアイテム用の object_level があります。

  • base_level: 各種生成レベルの参照元となる基本値。通常のダンジョン階では dun_level（現在の階層）が設定されます。
  • object_level: アイテム生成時に実際に参照されるレベル。既定では base_level と等しく、特定の状況（特別部屋・宝箱・モンスタードロップなど）で一時的に加算・上書きされます。

通常のフロア生成では次のように設定されます。

base_level   = dun_level
object_level = base_level

クエスト階では、そのクエストに設定されたレベルが base_level として使われます。

base_level   = quest.level
object_level = base_level

object_level を一時変更する状況

object_level は生成コンテキストに応じて一時的に変更され、処理が終わると base_level へ戻されます。ソースで確認できた変更値は次の通りです。

状況 object_level の値
通常 base_level（＝多くの場合 dun_level）
特別部屋の財宝配置（最上質枠） base_level + 20
特別部屋の財宝配置（上質枠） base_level + 10
特別部屋の財宝配置（通常枠） base_level + 7
ヴォルト等の配置 base_level + 20 / base_level + 12 / base_level + 7（配置種別による）
モンスターのドロップ (dun_level + モンスターのレベル) / 2
宝箱（一般） abs(chest.pval) + 10
宝箱（缶詰＝KANDUME） 宝箱の chest_level（さらに強化モード AM_GREAT が付与）

モンスタードロップの生成レベルは、階層とモンスター自身のレベルの平均です。

object_level = (dun_level + monster.level) / 2

これにより、浅い階でも強いモンスターを倒せば相応に高レベルなアイテムが出うる一方、深い階の弱いモンスターのドロップは階層より低いレベルになります。

生成モードによる基準レベルの底上げ (good / great)

make_object() は、良質アイテムを狙う生成モード AM_GOOD / AM_GREAT に応じて、抽選に渡す基準レベル（コード上の base）を object_level から底上げします。

モード 抽選に渡す基準レベル base
通常 object_level
AM_GOOD object_level + 10
AM_GREAT（ランダムクエスト討伐対象レベル rq_mon_level あり） rq_mon_level + 10 + randint1(10)
AM_GREAT（rq_mon_level なし） object_level + 15

randint1(10) は 1〜10 の一様乱数です。

なお強化モード指定とは別に、make_object() は一定確率で「その場限りのアーティファクト (instant artifact)」の生成を試みます。その試行確率は次の通りです。

モード instant artifact 試行確率
AM_GOOD あり one_in_(10)（1/10）
それ以外 one_in_(1000)（1/1000）

ベースアイテムの抽選（アイテムレベル本体）

底上げされた基準レベル base は select_baseitem_id(base, mode) に渡され、ここでベースアイテムの種類が抽選されます。この関数の中で、アイテムレベルに関する重要な処理が二つ行われます。

1. レベルのクランプと深度ブースト

まず基準レベルは最大深度で頭打ちにされます。MAX_DEPTH は 128 なので、上限は 127 です。

if (level > MAX_DEPTH - 1) level = MAX_DEPTH - 1

次に、初心者向けフラグ (BEGINNER) の付いていないダンジョンでは、一定確率でレベルが大きく引き上げられます。ブーストの発生確率は定数 CHANCE_BASEITEM_LEVEL_BOOST = 10 により one_in_(10)（1/10）です。

発生条件: level > 0 かつ ダンジョンが BEGINNER でない
確率:     one_in_(10)  (= 1/10)
ブースト時:
    level = 1 + (level * MAX_DEPTH / randint1(MAX_DEPTH))
          = 1 + (level * 128 / randint1(128))

randint1(128) は 1〜128 の一様乱数です。分母が小さい値を引くとレベルは大きく跳ね上がり、まれに本来の階層より遥かに高レベルなベースアイテムが出現します（いわゆる「out-of-depth」なアイテム）。分母が 128（最大）のときはブースト後もほぼ元のレベルのままです。

2. 抽選テーブルの構築と複数回抽選

ブースト後のレベルで抽選テーブルが構築されます。ベースアイテムは種別ごとに複数の「割り当てエントリ（レベルと出現確率の対）」を持ち、make_table() は エントリのレベルが基準 level 以下のものだけ を候補に含めます。

候補条件: entry.level <= level

抽選は複数回引かれ、そのうち 最もレベルの高いエントリ が採用されます。抽選回数は次の確率で決まります。

抽選回数 確率
1 回 40 %（乱数 p が 60 以上）
2 回 50 %（10 ≤ p < 60）
3 回 10 %（p < 10） 
p = randint0(100)
count = 1
if (p < 60) count++   // 60% で +1
if (p < 10) count++   // 10% で さらに +1

複数回引いて最高レベルを採る仕組みのため、基準レベルが高いほど高レベルなベースアイテムが選ばれやすくなります。この「複数回引いて最高レベルを採る」処理がアイテムレベルの実効的な深度依存性を強めています。

アイテムの強化（magic level と good/great 判定）

抽選で種類が決まったアイテムは ItemMagicApplier により魔法的な強化を受けます。ここで参照される基準レベル lev は、make_object() から渡される object_level（good/great の底上げ前の値） です。

ItemMagicApplier の基準レベル lev = object_level

lev に対しては次の補正が入ります。

  • 性格がマンチキン (PERSONALITY_MUNCHKIN) の場合: lev += randint0(player.lev / 2 + 10)
  • 上限クランプ: lev が MAX_DEPTH - 1（＝127）を超える場合は 127 に制限。

上質・高級品の確率

上質 (good) と高級品 (great) の生成確率 [%] は lev を基準に算出されます。

chance_good  = lev + 10                     (ダンジョンの obj_good で上限クランプ)
chance_great = chance_good * 2 / 3          (ダンジョンの obj_great で上限クランプ)

さらに幸運・不運による補正が入ります。

条件 chance_good chance_great
幸運 (good luck) +5 +2
突然変異による不運 (BAD_LUCK) -5 -2

（高級品確率の obj_great 上限クランプは、マンチキン性格の場合は適用されません。）

強化パワーの決定

これらの確率を用いて強化パワー power が決まります。

判定 power
AM_GOOD 指定、または chance_good に当選 1（さらに AM_GREAT 指定か chance_great 当選で 2、加えて AM_SPECIAL で 3）
上記に非該当だが chance_good に当選 -1（さらに chance_great 当選で -2）
いずれでもない 0

AM_CURSED が指定された場合は、正の power は符号反転、非正の power はさらに 1 減算されます。

  • power >= 2（＝ great 相当）以上のとき、アイテムは上質枠として扱われ、アーティファクト化の試行が発生しうる。
  • power <= -2 は劣悪（呪われた粗悪品）方向の強化。

アーティファクト化の試行回数

強化パワーとモードからアーティファクト（ランダムアーティファクト）生成の試行回数 rolls が決まります。

条件 rolls
power >= 2 1
AM_GREAT または AM_SPECIAL 4（上書き）
AM_NO_FIXED_ART 指定、または既に固定アーティファクト 0

アーティファクト化の試行は 地下（ダンジョン内）でのみ 行われます。各試行では現在の階層 dun_level を基準に判定されます。

o_ptr->try_become_artifact(dun_level)

幸運持ちの場合は、失敗しても one_in_(77)（1/77）で追加の再試行が発生します。

ボーナス値の大きさ (m_bonus)

命中・ダメージ・AC などのボーナス値の大きさも lev に依存します。共通ルーチン m_bonus(max, level) は、レベルが上がるほど平均値が max に近づく分布を返します。

level は MAX_DEPTH - 1 (=127) で上限クランプ
bonus = (max * level) / MAX_DEPTH
      = (max * level) / 128
（端数 (max*level) % 128 の確率で bonus を +1）
標準偏差 stand = max / 4 として randnor(bonus, stand) を返す
（0 未満は 0、max 超は max にクランプ）

つまり level が 128 に近いほどボーナスの期待値が最大値に近づき、浅い階では小さなボーナスに偏ります。

全体の流れ（まとめ）

アイテム生成におけるレベルの流れは次のように整理できます。

dun_level (現在の階層)
   ↓
base_level  = dun_level（クエスト階では quest.level）
   ↓
object_level = base_level（特別部屋・宝箱・モンスタードロップ等で一時変更）
   ├─ [抽選側] make_object で good/great 補正 → base
   │      通常 : object_level
   │      GOOD : object_level + 10
   │      GREAT: object_level + 15（ランダムクエストなら rq_mon_level + 10 + 1d10）
   │        ↓ select_baseitem_id(base)
   │        ├ 1/10 で深度ブースト level = 1 + level*128/randint1(128)
   │        └ 1〜3 回抽選し最高レベルのベースアイテムを採用
   │
   └─ [強化側] ItemMagicApplier の lev = object_level（補正前）
          ├ chance_good = lev + 10（上限 obj_good）
          ├ chance_great = chance_good * 2/3（上限 obj_great）
          ├ power / rolls を決定 → エゴ・アーティファクト化
          └ m_bonus(max, lev) でボーナス値を決定

抽選側は good/great による大きな底上げと深度ブーストを受けるため、モードや運次第で階層を大きく超えたベースアイテムが出うる一方、強化側は底上げ前の object_level を基準にするため、強化の平均的な質は素直に現在の階層深度を反映します。
