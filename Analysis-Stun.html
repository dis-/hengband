朦朧処理

← 解析 / Analysis

概要

朦朧はプレイヤーとモンスターで別々の状態値・蓄積処理を使います。プレイヤー側は重症度ランクを持つ bad status、モンスター側は MonsterTimedEffect::STUN の残り値として処理されます。

プレイヤーの朦朧 / Player stun

状態値とランク

プレイヤーの朦朧値は PlayerStun が保持し、BadStatusSetter::set_stun() で 0-10000 に丸められます。種族または職業が朦朧耐性を持つ場合、設定値は 0 になります。

値 ランク 表示 意味
0 NONE なし 朦朧ではない
1-50 SLIGHT やや朦朧 軽い朦朧
51-100 NORMAL 朦朧 通常の朦朧
101-150 HARD ひどく朦朧 重い朦朧
151-200 UNCONSCIOUS 意識不明瞭 意識が遠のく
201+ KNOCKED 昏倒 行動不能扱い

ランク上昇時の副作用

朦朧値のランクが上がる時だけ、朦朧メッセージ、知能/賢さ低下判定、構え解除、集中解除、呪術詠唱停止が実行されます。ランク低下時は、完全に 0 へ戻った場合に回復メッセージが出ます。

主な蓄積源

原因 追加量 条件
モンスター打撃の朦朧効果 ダメージからランクを求め、1d10 から 1d10+70 まで 実ダメージが 20 以下、または通常最大ダメージの 95% 未満なら追加なし
轟音属性 1d(ダメージ/3+5)、ダメージ 90 超は 1d35 轟音耐性なし、かつ分身回避なし
プラズマ属性 1d(ダメージ*3/4+5)、ダメージ 40 超は 1d35 轟音耐性なし、かつ分身回避なし
水属性 1d40 轟音耐性なし、水耐性なし、かつ分身回避なし
フォース/ロケット 1d20 轟音耐性なし、かつ分身回避なし
重力属性 轟音と同じ式 轟音耐性なし、浮遊なし、かつ分身回避なし
氷属性 1d15 轟音耐性なし、かつ分身回避なし

プレイヤーへの影響

ランク 魔法/魔道具系失敗率加算 アイテム失敗率加算 攻撃/命中系ペナルティ
なし 0 0 0
やや朦朧 +10 0 5
朦朧 +20 0 10
ひどく朦朧 +30 +5 20
意識不明瞭 +50 +10 40
昏倒 +100 +100 100

魔法、青魔法、超能力、エレメンタル魔法などは get_magic_chance_penalty() を失敗率に加算します。アイテム使用は get_item_chance_penalty() を参照します。昏倒ランクでは麻痺と同様に行動不能処理に入ります。

回復

プレイヤーの朦朧値は、毎ターンの時限効果更新で自然減少します。src/core/magic-effects-timeout-reducer.cpp の処理は毒と同じ式で、朦朧中なら adj_con_fix[耐久の能力値インデックス] + 1 を現在値から引きます。

耐久 adj_con_fix 1ターンの減少量
3-13 0 1
14-17 1 2
18/00-18/49 2 3
18/50-18/99 3 4
18/100-18/119 4 5
18/120-18/129 5 6
18/130-18/149 6 7
18/150-18/169 7 8
18/170-18/199 8 9
18/200+ 9 10

減少は BadStatusSetter::mod_stun(-adjust) 経由で行われるため、0 未満にはならず、ランクが下がると再計算・再描画が発生します。値が 0 になった時は「やっと朦朧状態から回復した。」のメッセージが表示されます。

行動による解除

薬を飲む、杖・ロッドを使う、一部の呪文を唱えるなどの行動でもプレイヤーの朦朧値は回復します。下表の効果は自然回復のように少しずつ減らすのではなく、BadStatusSetter::set_stun(0)、cure_critical_wounds()、true_healing()、life_stream() などを経由して朦朧値を 0 に戻します。宿屋の休息だけは effects()->stun().reset() で直接 0 にします。

分類 行動・効果 内部処理 備考
薬 癒し、致命傷の治癒、体力回復、*体力回復*、生命 true_healing() / cure_critical_wounds() / life_stream() 軽傷の治癒、重傷の治癒は朦朧を治さない
ロッド 癒し、体力回復 true_healing() / cure_critical_wounds() 復活のロッドは能力値・経験値回復で、朦朧は対象外
杖 癒し、体力回復、聖浄 true_healing() / cure_critical_wounds() / cleansing_nova() 賢者の杖は朦朧を治さない
施設 建物の治療サービス、宿屋の休息 cure_critical_wounds(200) / stun().reset() 宿屋は HP/SP も全快する
生命領域 致命傷の治癒、体力回復、*体力回復* cure_critical_wounds() 生命領域の復活は能力値・経験値回復で、朦朧は対象外
自然領域 薬草治療 cure_critical_wounds(500) 傷と毒治療は朦朧を治さない
匠領域 癒し true_healing(0) HP 回復なしで状態異常だけを治す
破邪領域 身体浄化、聖なる御言葉 set_stun(0) 聖なる御言葉は HP 100 回復、恐怖・毒・切り傷も治す
呪術 致命傷の治癒 cure_critical_wounds(4d10) 継続中の毎ターン処理でも朦朧を治す
歌 ヤヴァンナの助け set_stun(0) 継続中の毎ターン処理で HP 15d10 回復、切り傷も治す
超能力者 アドレナリン・ドーピング set_stun(0) 恐怖も解除し、英雄気分・加速などを得る
青魔法・ものまね モンスター能力「体力回復」 set_stun(0) 青魔法は HP を Lv*4、ものまねは Lv*6 回復し、切り傷も治す
発動 一部のアーティファクト発動（天国の歌、体力回復700、体力回復1000、癒し） cure_critical_wounds() / true_healing() 発動タイプは CHOIR_SINGS、CURE_700、CURE_1000、CURING
地形 パターン終端 cure_critical_wounds(1000) 体力回復、能力値・経験値回復などと同時に朦朧を治す

なお、朦朧が重い時はアイテム使用側の事前判定で行動自体に失敗することがあります。その場合は効果処理まで進まないため、上記の薬・杖・ロッドでも朦朧は回復しません。

モンスターの朦朧 / Monster stun

状態値と設定

モンスターの朦朧は mtimed[MonsterTimedEffect::STUN] に保存され、set_monster_stunned() で 0-200 に丸められます。値が 0 から正になると処理リストへ登録され、0 に戻ると処理リストから外れます。

蓄積と耐性

魔法効果側では一度 EffectMonster::do_stun に追加量を積み、ダメージ処理後にまとめて適用します。NO_STUN を持つモンスターはここで朦朧追加を無効化します。既に朦朧中なら 現在値 + 追加量/2、そうでなければ 追加量 が新しい値になります。

原因 追加量 主な無効/軽減条件
STUN 属性 (術者Lv/20+3)dダメージ + 1 NO_STUN で最終無効
轟音属性 (10 + 1d15 + r) / (r + 1) 轟音耐性でダメージ軽減、朦朧追加なし
フォース属性 (1d15 + r) / (r + 1) フォース耐性でダメージ軽減、朦朧追加なし
重力属性 (術者Lv/20+3)dダメージ + 1 ユニーク、レベル判定成功、重力耐性で朦朧追加なし
氷属性 (1d15 + 1) / (r + 1) 轟音耐性があると朦朧追加なし
精神攻撃/魅了系など 個別効果ごとの固定式 NO_STUN で最終無効

モンスターへの影響

  • モンスターの通常打撃は、攻撃者が朦朧していると 1/2 で自動失敗します。対プレイヤー、対モンスターの両方に適用されます。
  • 非生得の魔法・特殊能力は、朦朧中だと 1/2 で詠唱失敗します。生得能力はこの失敗判定を受けません。
  • 騎乗中の乗騎が朦朧している場合、移動時に 1/2 で制御不能になります。
  • モンスターリストやヘルス表示では状態ラベル「朦朧」として表示されます。

回復

モンスターの一時効果処理で、朦朧は通常 残り値 - 1 ずつ減ります。ただし randint0(10000) <= レベル^2 に成功すると即座に 0 へ戻ります。可視モンスターが回復した場合は回復メッセージが表示されます。

処理の違い

観点 プレイヤー モンスター
保存場所 PlayerStun mtimed[STUN]
値の上限 10000 200
重症度 値から 5段階ランクへ変換 残り値のみ。ランク分けはしない
蓄積 BadStatusSetter::mod_stun() で現在値へ加算 EffectMonster::do_stun をダメージ後に適用
耐性 種族/職業の朦朧免疫なら常に 0 NO_STUN で追加無効
自然回復 耐久補正に応じて毎ターン 1-10 減少 毎処理で -1、またはレベル依存で即時回復
