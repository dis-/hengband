ハイ=メイジ / High-Mage

← 職業一覧 / Classes ・ 🏠 ホーム / Home

概要

ハイメイジは一つの領域に特化し、その領域を通常のメイジよりはるかに深く学んだメイジです。１つの領域に特化したおかげで、彼らは自らが選択した領域の呪文を唱える際の消費ＭＰ、最低レベル、失敗率で相当な恩恵を受けます。しかし、生命の領域ではプリーストほどうまくはなれないことには注意すべきです。魔法に必要な能力値は知能です。

固有システム・特殊能力

ハイ=メイジの呪文の詳細は クラス別魔法: ハイ=メイジ を参照する。レイシャル特殊能力は、選択している領域が呪術かどうかで変わる。

呪術以外の領域では、レベル25から「魔力食い」を使える。消費は1、判定能力値はINT、難度は25%。魔法道具から魔力を吸収してMPを回復し、POWERは Lv * 2 で計算される。

呪術領域では、レベル1から「詠唱をやめる」を使える。消費は0、判定能力値はINT、難度は0%。呪術の詠唱を全てやめる。

条件 能力 最低Lv 消費 能力値 難度 効果
呪術以外 魔力食い 25 1 INT 25 魔法道具から魔力を吸収してMPを回復する。POWERは Lv * 2。
呪術 詠唱をやめる 1 0 INT 0 呪術の詠唱を全てやめる。

戦闘・装備上の特徴

ハイ=メイジ固有の差分は、通常の打撃処理ではなく魔法運用とレイシャル特殊能力の分岐にある。呪術を選んだ場合は「詠唱をやめる」が継続中の呪術の停止手段になり、呪術以外では「魔力食い」によって魔法道具をMP回復資源として使える。

装備重量によるMPへの影響は職業別の固有能力ではないため、詳細は 鎧によるMPペナルティ を参照する。
