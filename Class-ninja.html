忍者 / Ninja

← 職業一覧 / Classes ・ 🏠 ホーム / Home

概要

忍者は暗闇に潜む恐るべき暗殺者であり、光源を持たずに行動し、相手の不意をつき一撃で息の根を止めます。また、相手を惑わすための忍術も身につけます。罠やドアを見つける能力に優れ、罠の解除や鍵開けに熟達しています。軽装を好み、重い鎧や武器を装備すると著しく動きが制限され、また、盾を装備しようとはしません。軽装ならば、レベルが上がるにつれより速くより静かに行動できます。さらに忍者は恐怖せず、成長すれば毒がほとんど効かなくなり、透明なものを見ることができるようになります。忍術に必要な能力は器用さです。

固有システム・特殊能力

忍者は忍術系の能力と高速移動を扱う職業で、職業能力として「速駆け」を持つ。

能力 最低Lv 消費 能力値 難度 効果
速駆け 20 0 DEX 0 身体を酷使して素早く移動する。使用中は移動の消費エネルギーが (45 - レベル / 2)% になる。

「速駆け」は ACTION_HAYAGAKE をON/OFFする。現在地が投射不能地形、または浮遊なしで深い地形にいる場合は「ここでは素早く動けない。」となる。速駆け中は移動の消費エネルギーだけが (45 - レベル / 2)% になり、Lv1なら45%で約2.2倍速、Lv50なら20%で5倍速で移動する。他の行動は速くならない。使用中は自然HP回復ができない。これは忍者の恒常速度補正とは別物である。忍者は暗い場所へ移動すると超隠密 s_stealth になり、明るい場所へ出ると解除される。s_stealth 中は後述の奇襲が発生し得る。

戦闘・装備上の特徴

忍者の恒常速度は、軽装かつ両手が攻撃可能なら+3され、クラッコン・妖精・いかさま以外で他の加速源がなければさらに Lv / 10 される。重い防具では逆に -Lv / 10 され、「装備が重くてバランスを取れない。」という状態通知が出る。

不意打ちは近接武器を装備し、その手の武器がふさわしくない装備でない時だけ判定される。眠っていて見えている敵には急所攻撃が発生し、ダメージは 3 + Lv / 20 倍。逃げていて見えている敵には追い打ちが発生し、ダメージは1.5倍。忍者はさらに s_stealth 中、隠密とレベルからの判定に成功し、相手が全耐性でなければ奇襲になり、ダメージは (5 + Lv * 2 / 25) / 2 倍になる。急所攻撃または奇襲中は、全耐性でない相手への命中判定が成功扱いになる。

投擲では、盗賊と忍者は投げたターンの消費が 100 - Lv になる。忍者がくさび、または「投げやすい」剣を投げる場合は手裏剣扱いになり、命中値が2倍になる。「八方手裏剣」は所持中のくさびを最大8回投げる。

忍者は軽い武器を好む。装備武器の熟練上限が初心者より高く、かつ反対側の手に盾を装備していない場合だけ、忍者にふさわしい武器として扱われる。それ以外の近接武器は「今の装備はどうも自分にふさわしくない気がする。」となり、打撃回数が半減し、Lv25の麻痺知らずも得られない。盾を持つと反対側の手の武器もふさわしくない扱いになる。

武器を持たないか、装備中の武器で攻撃できる状態なら、ACに Lv / 2 + 5 の職業補正を得る。装備品のダメージ修正は、正の値なら半分に丸められる。通常の打撃回数計算では筋力側の指数が1下がる。技能面の一般的な解析は 技能 を参照。

職業固有の耐性・能力

レベルに応じて職業から恒常的に付与される耐性・能力（src/player-base/player-class.cpp の tr_flags）。装備や一時効果とは別に、条件を満たす限り常に有効。

  • 常時: 遅消化、恐怖耐性、暗視（夜目・光源なしでも周囲が見える）
  • 軽装時（両手が空くか攻撃可能）: 加速 +3、さらに他の加速源が無ければ +レベル/10。逆に重い鎧を着ると加速 −レベル/10 のペナルティ
  • Lv20〜: 毒耐性
  • Lv25〜: 麻痺知らず（両手ともふさわしい武器の時）、器用さ維持
  • Lv30〜: 透明視認
