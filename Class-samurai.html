剣術家 / Samurai

← 職業一覧 / Classes ・ 🏠 ホーム / Home

概要

剣術家は戦士に次ぐ戦闘力があり、様々な技を使うことができます。彼らのMPはレベルに依存せず、賢さだけで決まり、気合いをためることにより、最大値を越えてMPを増やすことができます。しかし、戦士と同様、高レベルの魔法のアイテムは彼らの扱える範囲を越えており、罠の解除や探索の能力も高いとはいえません。必殺技の使用に必要な能力は賢さです。

固有システム・特殊能力

剣術家はMPを剣術の資源として扱う職業で、気合いため によりMPを増やし、上限をある程度超えて蓄えることができる。

能力 最低Lv 消費 能力値 失敗率 効果
気合いため 1 0 WIS 0% 気合を溜めてMPを増やす。上限値をある程度超えられる。
型 25 0 DEX 0% 型に構えて特殊な能力を得る。

剣術は mind-samurai.cpp、型は stances-table.cpp に定義される。剣術の技一覧への導線は 剣術 / Kendo を参照。

戦闘・装備上の特徴

剣術家の戦闘は、通常攻撃に加えて剣術と型を使い分ける構造になっている。

型は居合、風塵、降鬼、無想が定義される。風塵は打撃回数を1減らす。降鬼はACを50下げる。無想はACを100増やす。

剣術の一部は攻撃時の倍率計算に関わり、対象の種別や耐性に応じて効果が変わる。詳細な技一覧は 剣術 / Kendo に譲る。

MP計算や装備重量による魔法使用上の扱いは 装備重量によるMPペナルティ を参照。
