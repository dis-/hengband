火炎免疫（TR_IM_FIRE）

← プレイヤー耐性一覧 / Resistances

概要

火炎免疫は TR_IM_FIRE、または ele_immune 中に対応する DEFENSE_* が立っている状態で得られる。has_immune_fire() が真なら、火炎属性ダメージは免疫として扱われる。

has_resist_fire() は通常耐性と ult_res に加えて has_immune_fire() の結果も含む。免疫がある場合、通常耐性・一時耐性・弱点より強く、通常の被ダメージは 0 になる。

効果

fire_dam() では、倍率計算の前に次の判定を行う。calc_fire_damage_rate() 自体には免疫判定はない。

if (has_immune_fire(player_ptr) || (dam <= 0)) return 0;

火炎属性の倍率式は次の通り。

per = 100;
for each cause in has_vuln_fire(player_ptr):
    if (cause == FLAG_CAUSE_MUTATION) per *= 2;
    else per += per / 3;
if (has_resist_fire(player_ptr)) per = (per + 2) / 3;
if (is_oppose_fire(player_ptr)) per = (per + 2) / 3;
return per;
条件 効果
has_immune_fire(player_ptr) 通常の火炎HPダメージは 0
変異以外の弱点要因 要因ごとに per += per / 3
PlayerMutationType::VULN_ELEM による弱点 per *= 2
has_resist_fire(player_ptr) per = (per + 2) / 3
is_oppose_fire(player_ptr) さらに per = (per + 2) / 3

副次効果は次の条件で処理される。

処理 条件
do_dec_stat(player_ptr, A_STR) `aura
所持品破壊 inventory_damage(..., BreakerFire(), inv) !aura && !(is_oppose_fire(player_ptr) && has_resist_fire(player_ptr))
プラズマの所持品破壊 inventory_damage(..., BreakerAcid(), 3) `!(has_resist_fire(player_ptr)

一時耐性・補足

is_oppose_fire() は次のいずれかで真になる。

条件
player_ptr->oppose_fire != 0
music_singing(player_ptr, MUSIC_RESIST)
PlayerClass(player_ptr).samurai_stance_is(SamuraiStanceType::MUSOU)
player_ptr->mimic_form == MimicKindType::DEMON
PlayerRace(player_ptr).equals(PlayerRaceType::BALROG) && player_ptr->lev > 44

地形 TerrainCharacteristics::LAVA は !is_invuln(player_ptr) && !has_immune_fire(player_ptr) のときだけ地形ダメージ処理に入る。走行判定でも、溶岩は火炎免疫があれば危険地形扱いで停止しない。

TR_SELF_FIRE や騎乗中の火炎オーラも !has_immune_fire(player_ptr) のときだけ処理される。これらは弱点なら damage += damage / 3、通常耐性なら damage = damage / 3、一時耐性ならさらに damage = damage / 3、最後に std::max(damage, 1) が適用される。
