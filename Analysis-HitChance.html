命中率計算

← 解析 / Analysis

概要

命中率は、プレイヤーの「基本命中値」（種族・職業・性格・武器熟練度・能力値・状態異常などから合成）と、対象モンスターのACから、hit_chance()（src/combat/attack-accuracy.cpp）で百分率に変換される。実際に命中したかどうかは、この百分率と 1d100 の比較で決まる（test_hit_norm()）。

命中判定の大枠

test_hit_norm(chance, ac, visible):
  見えない相手には chance = (chance+1)/2 に半減
  hit_chance(chance, ac) >= 1d100 なら命中

hit_chance() の中身：

hit_chance(chance, ac):
  chance <= 0 なら 常に 5%
  chance_left = 90（ただし性格が「なまけもの」なら (90*19+9)/20 = 85）
  result = 5 + (100 - ac*75/chance) * chance_left / 100
  result の下限は 5%
  • 100 - ac*75/chance は「命中値がACに対してどれだけ優っているか」を百分率化した項で、AC が高いほど、あるいは chance が低いほど小さく（マイナスにもなり得る）なり、命中率を押し下げる。
  • 下限 5% のみ式でクランプされる。上限（randint1(100) は 1〜100 なので hit_chance が 100 以上ならほぼ確実に命中）は式上クランプされていないため、命中値がACを大きく上回れば実質100%近くに張り付く。

基本命中値 (chance) の合成 — 通常の武器攻撃

src/player-attack/player-attack.cpp の直接攻撃処理は calc_attack_quality()（src/mind/mind-samurai.cpp、全職業共通で呼ばれる）で chance を作る：

bonus  = to_h[攻撃手] + 武器の to_h
chance = skill_thn + bonus * BTH_PLUS_ADJ(=3)
  • skill_thn（calc_to_hit_melee()、src/player/player-status.cpp）: 種族・職業・性格それぞれの近接命中テーブル値 r_thn/c_thn/a_thn を合算し、レベルに応じた追加加算 x_thn × Lv/10 と a_thn × Lv/50 を加える。武器を持たなくても種族・職業・性格・レベルだけで決まるベース値（各職業・種族・性格ごとの数値はそれぞれの個別ページに記載）。
  • 武器の to_h: アイテム自体の命中修正値（強化値 +h・アーティファクト固有値など）。
  • to_h[手]（calc_to_hit()、src/player/player-status.cpp）: 下記の各項を合成した最終値。

to_h[手] の加算項目（calc_to_hit）

すべて hit に加減算され、chance = skill_thn + (to_h[手] + 武器to_h) × 3 に効く（1点の to_h が命中値3点ぶんに相当）。

chance への上乗せ（calc_attack_quality、剣術家ほか）

  • 居合の型 +60、剛毅刃の型 +150
  • 捨て身：chance = max(chance × 3/2, chance + 60)
  • 徳「勇気」：+ valour徳値 / 10（正負いずれもあり）

二刀流ペナルティ（calc_double_weapon_penalty）

両手に近接武器を装備しているときのみ発生し、各手について次を計算して to_h[手] から減算する（src/player/player-status.cpp）：

penalty = (100 - 二刀流熟練度/160) - (130 - その手の武器重量) / 8
特定の対アーティファクトのペア（クイック＆タイニー／アイシング＆きらめき／
  アヌビス＆チャリオット）: penalty = penalty/2 - 5
easy_2weapon フラグ（該当手）があり penalty>0: penalty /= 2
副手が TR_SUPPORTIVE を持つ: penalty = max(0, penalty - 10)
武蔵の二刀流セット: penalty = min(0, penalty)  ← ペナルティ完全消去
その手の武器が長柄(POLEARM): penalty += 10
  • 二刀流熟練度が高いほど、また武器が軽いほどペナルティは小さい（熟練度は160ごと・重量は8ごとに1点改善）。武器重量は 0.1lb 単位で、130（=13.0lb）を基準に軽ければペナルティ減。
  • ペナルティは各手ごとに独立に計算され、それぞれの命中に効く。長柄は取り回しが悪く +10 加算（＝命中が余計に下がる）。

具体例

例1: hit_chance の感度（chance と AC の関係）

hit_chance() は整数演算（切り捨て）。標準性格・視認可の場合：

chance AC 計算 命中率
120 30 5 + (100 - 30×75/120)×90/100 = 5 + (100-18)×90/100 = 5+73 78%
120 100 5 + (100 - 100×75/120)×90/100 = 5 + (100-62)×90/100 = 5+34 39%
60 100 5 + (100 - 100×75/60)×90/100 = 5 + (100-125)×90/100 = 5+(-22) → 下限 5%
300 50 5 + (100 - 50×75/300)×90/100 = 5 + (100-12)×90/100 = 5+79 84%

chance が AC の 75% を大きく上回ると 84% 付近で頭打ちに近づき、下回ると急落して 5% で底打ちする。視認できない相手は chance が半分になるため、上表の chance を半減して読む。

例2: 命中値 chance の組み立て（近接・数値は仮定）

項目 値
skill_thn（種族＋職業＋性格＋Lv補正） 60
to_h[手] 能力値補正（STR 18/100=+5, DEX 18/90=+5） +10
主攻撃手の STR+DEX 再加算（両手持ち） +10
武器熟練（例: 熟練度6000）(6000-4000)/200 +10
武器の to_h（強化 +9） +9
bonus = to_h手 + 武器to_h(9) 39
chance = skill_thn(60) + bonus(39)×3 177

この chance = 177 で AC 50 のモンスター（視認可）を攻撃すると： 5 + (100 - 50×75/177)×90/100 = 5 + (100-21)×90/100 = 5 + 71 = 76%。 祝福（+10）や英雄（+12）が乗ると to_h が増え、bonus×3 を通じて chance がさらに上がる（祝福なら +10×3 = 命中値+30 相当）。

対象モンスターのAC

decide_attack_hit()（src/combat/attack-accuracy.cpp）が test_hit_norm(chance, monrace.ac, 視認可否) を呼ぶ。ACはそのモンスター種族の基本AC（monrace.ac）で、個体差はない。

例外的な必中・確率固定の攻撃

  • 毒針の武器 (SV_POISON_NEEDLE) または必殺技「急所突き」: 命中判定を飛ばし、1/n の確率で成功／失敗が決まる（n は両手持ちや三段の条件で倍加）。ACや命中値は一切関与しない。
  • 忍者の奇襲・不意打ち（対象が RESIST_ALL を持たない場合）: 無条件で命中。
  • 必殺技「魔神斬り」: 命中判定後に 1/2 で強制的にミス扱いへ上書き。

射撃・投擲の命中値

近接とは別の合成関数を使う（同じ hit_chance()/test_hit_norm() に渡す chance の作り方が異なるだけ）。

  • 射撃: calc_to_hit_shoot() — r_thb/c_thb/a_thb を合算し、レベル加算は近接と同じ形（x_thb * Lv/10 と a_thb * Lv/50）。
  • 投擲: calc_to_hit_throw() — 射撃と同じテーブルを使うが、狂戦士化中は -20 の固定ペナルティが入る。

モンスターからプレイヤー／モンスターへの命中判定

プレイヤーへの命中判定とは全く別の式（check_hit_from_monster_to_player() / check_hit_from_monster_to_monster()、src/combat/attack-accuracy.cpp）。

1d100 の結果が 10 未満なら、5 未満で命中・5以上でミス（常に1/20で命中、1/20でミスが先に確定）
それ以外は:
  i = 攻撃属性ごとの基本命中値(power) + モンスターレベル×3
  1d(i) が (対象AC×3/4) を超えれば命中

朦朧状態の攻撃側は追加で 1/2 の確率で無条件ミスになる。対プレイヤーの場合、ACは装備由来の player_ptr->ac + to_a（双剣の構え「水月」なら +Lv×2）。この式は「対プレイヤー用命中値(chance)＋AC」を使うプレイヤー側の式とは異なり、"モンスターの攻撃力とレベル" 対 "ACの3/4" という別系統の乱数比較になっている。
