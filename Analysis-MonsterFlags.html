モンスターフラグ

← 解析 / Analysis

概要

モンスターの性質・行動・能力は、モンスター種族データ（monrace）が保持する複数の「フラグ集合」によって定義される。現行ソースでは、かつての一枚岩の RF* フラグ群が用途ごとに分割され、それぞれ独立した enum class として src/monster-race/ 以下に定義されている。各カテゴリは種族データ上で別々のビット集合（EnumClassFlagGroup）として保持され、モンスター思い出（display-lore*）で日本語ラベル付きで表示される。

本稿では全網羅ではなく、カテゴリ構造と各カテゴリの代表的フラグの意味を、現行ソースに基づいてまとめる。日本語ラベルは主に src/view/display-lore-status.cpp および src/view/display-lore.cpp の表示処理から採録している。

フラグカテゴリ一覧

行動 MonsterBehaviorType race-behavior-flags.h 移動・扉・アイテム・知能・友好性

種別フラグ（MonsterKindType）

種族と道徳的属性を表す。思い出では [ユニーク] [邪悪] などのタグとして表示される（display_monster_kind_tags）。

フラグ ラベル 意味
UNIQUE ユニーク 一体しか存在しない固有モンスター。テレポート耐性・即死無効などが暗黙で付与される
EVIL 邪悪 邪悪属性。「邪悪不浄」系の攻撃・退散に弱い
GOOD 善良 善良属性
UNDEAD アンデッド 不死者。冷血・生命に関わる各種処理の対象
DRAGON ドラゴン ドラゴン種族。屠竜など対ドラゴン効果の対象
DEMON デーモン 悪魔種族
ANIMAL 自然界 自然界の生物（動物）
ORC / TROLL / GIANT オーク/トロル/巨人 対応する亜人種族
HUMAN / AMBERITE / ANGEL 人間/アンバー/天使 それぞれ人間・アンバーの王族・天使
QUANTUM 量子生物 量子生物（観測により振る舞いが変わる）
NONLIVING （無生物） 生命を持たない。吸血・毒などが効かない扱い

行動フラグ（MonsterBehaviorType）

移動・扉・アイテム・知能・敵対性を制御する。

フラグ ラベル 意味
NEVER_MOVE 不動 その場から動かず、侵入者を追跡しない
NEVER_BLOW （近接不可） 近接攻撃を行わない
OPEN_DOOR 扉開 扉を開ける
BASH_DOOR 扉壊 扉を打ち破る
MOVE_BODY 他者移動 弱いモンスターを押しのけて進む
KILL_BODY 他者攻撃 弱いモンスターを倒して進む
TAKE_ITEM アイテム拾得 床のアイテムを拾う
KILL_ITEM アイテム破壊 床のアイテムを破壊する
RAND_MOVE_25 / RAND_MOVE_50 乱歩25/50 一定確率でランダムに移動（両方で「乱歩75」）
STUPID （愚鈍） 知能が低く、無謀な行動をとる
SMART （利口） 知能が高く、状況に応じて賢く行動する
FRIENDLY 友好 プレイヤーに敵対せず友好的

耐性・免疫・弱点フラグ（MonsterResistanceType）

同一属性について「弱点(HURT_*)／耐性(RESIST_*)／免疫(IMMUNE_*)」が別個のフラグとして定義される。思い出の [耐性] 表では属性ごとに弱点/耐性/免疫の状態が一覧表示される（display_monster_resistance_table）。

フラグ ラベル 意味
RESIST_ALL 全攻撃無効 あらゆる攻撃を軽減する（ごく一部の存在）
HURT_FIRE / RESIST_FIRE / IMMUNE_FIRE 火弱点/火耐性/火免疫 火炎に対する弱点・耐性・完全免疫（他属性も同構造）
HURT_ACID … IMMUNE_POISON 酸/電撃/冷気/毒 基本4属性も火炎と同様に弱点/耐性/免疫の3段階
RESIST_LITE / HURT_LITE 閃光耐性/弱点 閃光への耐性・弱点（免疫は無し）
RESIST_DARK, RESIST_NETHER, RESIST_CHAOS, RESIST_NEXUS, RESIST_DISENCHANT ほか 暗黒/地獄/カオス/因果混乱/劣化 等 上位属性の耐性（多くは耐性のみ、免疫なし）
HURT_ROCK / RESIST_ROCK 岩石溶解弱点/耐性 岩石除去魔法（ストーン・トゥ・マッド等）への弱点・耐性
RESIST_TELEPORT テレポート耐性/無効 テレポート強制の抵抗。ユニークでは「無効」相当
NO_FEAR 恐怖無効 恐怖状態にならない
NO_STUN 朦朧無効 朦朧（スタン）しない
NO_CONF 混乱無効 混乱しない・混乱耐性を持つ
NO_SLEEP 睡眠無効 眠らされない
NO_INSTANTLY_DEATH 即死無効 即死攻撃で倒せない（ユニークは暗黙で即死無効）

発動能力フラグ（MonsterAbilityType）

モンスターが使う遠隔攻撃・魔法・召喚を定義する。数が非常に多く、以下は代表例（日本語名は enum のコメント／display-lore-magics に準拠）。

分類 代表フラグ 意味
ブレス BR_FIRE, BR_COLD, BR_ELEC, BR_ACID, BR_POIS 各属性のブレス（火炎/冷気/電撃/酸/毒 など）
上位ブレス BR_NETH, BR_CHAO, BR_DISI, BR_TIME, BR_GRAV, BR_MANA 地獄/カオス/分解/時間逆転/重力/魔力ブレス
ボール BA_FIRE, BA_MANA, BA_CHAO, BA_NUKE ファイアボール、魔力の嵐、ログルス球、放射能球 など
ボルト BO_FIRE, BO_MANA, BO_PLAS, BO_ICEE, MISSILE 各種ボルトおよびマジックミサイル
直接攻撃系 CAUSE_1〜CAUSE_4, MIND_BLAST, BRAIN_SMASH, HAND_DOOM 呪殺（軽傷〜秘孔）、精神・脳攻撃、破滅の手
状態異常 SCARE, BLIND, CONF, SLOW, HOLD プレイヤーに恐慌/盲目/混乱/減速/麻痺
補助 HASTE, HEAL, INVULNER, BLINK, TPORT, WORLD 加速、治癒、無敵、短/長距離転移、時間停止
移動干渉 TELE_TO, TELE_AWAY, TELE_LEVEL プレイヤーを引き寄せる/飛ばす/階を変える
特殊 SHRIEK, DISPEL, ROCKET, SHOOT, SPECIAL, PSY_SPEAR 叫ぶ、魔力消去、ロケット、射撃、特殊攻撃、光の剣
召喚 S_MONSTER(S), S_UNDEAD, S_DRAGON, S_HI_UNDEAD, S_HI_DRAGON, S_UNIQUE, S_KIN, S_CYBER 各種モンスター・上位アンデッド/ドラゴン・ユニーク・同族・サイバーデーモンの召喚

（XXX1〜XXX4 は未使用の予約枠。）

GUARDIAN （ダンジョンの主） ダンジョンの最深部を守る主

地形適性フラグ（MonsterFeatureType）

地形との相互作用を定義する。思い出では移動能力として表示される。

フラグ ラベル 意味
AQUATIC 水棲 水中に棲み、水がないと生きられない
CAN_SWIM 水渡 水を渡れる
CAN_FLY 飛行 空を飛ぶ（水・溶岩などの上を移動可能）
PASS_WALL 壁抜け 壁をすり抜ける
KILL_WALL 壁破壊 壁を掘り進む（壁を破壊して移動する）

ドロップフラグ（MonsterDropType）

死亡時の落とし物を制御する。

フラグ 意味
ONLY_GOLD / ONLY_ITEM 金のみ / アイテムのみを落とす
DROP_GOOD / DROP_GREAT 上質な品 / 特別な（優良度の高い）品を落とす
DROP_60 / DROP_90 それぞれ60%/90%の確率で1個追加ドロップ
DROP_1D2 … DROP_4D2 1d2〜4d2 個のドロップ（数を上乗せ）
DROP_CORPSE / DROP_SKELETON 死体 / 骨を残す
DROP_COPPER … DROP_ADAMANTITE, DROP_OBSIDIAN 特定の宝石・金属（銅/銀/ガーネット/金/オパール/サファイア/ルビー/ダイヤ/エメラルド/ミスリル/アダマンタイト/黒曜石）を落とす

思い出では「最大 N 個の上質な／特別なアイテム／財宝を持っていることがある」と表示される（display-lore-drops.cpp）。

生息数フラグ（MonsterPopulationType）

ゲーム全体での個体数を制限する。

フラグ 意味
NAZGUL ナズグル型。世界に一定数までしか存在せず、残り数が管理される
ONLY_ONE 同時に一体しか存在できない
BUNBUN_STRIKER 特定の生成制限を持つ個体（ブンブン系）

荒野マップ上でどの地形に出現するかを指定する。

フラグ 意味
WILD_TOWN 町
WILD_SHORE / WILD_OCEAN 海岸 / 海洋
WILD_WASTE / WILD_GRASS / WILD_WOOD 荒地 / 草原 / 森林
WILD_VOLCANO / WILD_MOUNTAIN 火山 / 山岳
WILD_ONLY 荒野にのみ出現（ダンジョンには出ない）
WILD_ALL あらゆる地形に出現

見た目・発光・オーラ

視覚表現と接触時効果を定義するカテゴリ。

見た目（MonsterVisualType）

フラグ 意味
CLEAR / CLEAR_COLOR 背景が透ける表示 / 背景色で表示
SHAPECHANGER 表示シンボルが変化する
MULTI_COLOR / RANDOM_COLOR / ANY_COLOR 多色 / ランダム色 / 任意色で表示

発光（MonsterBrightnessType）

フラグ ラベル 意味
HAS_LITE_1 / HAS_LITE_2 ダンジョンを照らす 周囲を照らす（範囲1/2）
HAS_DARK_1 / HAS_DARK_2 ダンジョンを暗くする 周囲を暗くする
SELF_LITE_1 / SELF_LITE_2 光っている 自分自身が発光する
SELF_DARK_1 / SELF_DARK_2 暗黒に包まれている 自分の周囲を暗くまとう

オーラ（MonsterAuraType）

接触（近接攻撃）時に反撃ダメージを与える属性のまとい。FIRE（炎）・COLD（冷気）・ELEC（電撃）が実装済みで、それ以外（酸・毒・プラズマ・光・闇・カオス・神聖・地獄など）は予約領域。思い出では「〜は炎に包まれている」等と表示される。

会話・個別特殊フラグ

会話（MonsterSpeakType）／メッセージ（MonsterMessageType）：SPEAK_BATTLE（戦闘時）・SPEAK_FEAR（恐慌時）・SPEAK_FRIEND（友好時）・SPEAK_DEATH（死亡時）・SPEAK_SPAWN（分裂時）などの状況で固有の台詞を発する。MonsterMessageType はさらに歩行距離別メッセージ（WALK_CLOSERANGE など）や反射・時間停止・ブレス音などの演出メッセージを含む。

個別特殊（MonsterSpecialType）：特定ユニーク専用の処理を表す。現状 DIMINISH_MAX_DAMAGE（ラフィーII のダメージ軽減特性）のみが定義されている。

補足

  • 各カテゴリは種族データ上で独立したビット集合として保持され、モンスターの「思い出（memory）」蓄積量に応じて段階的に開示される（未判明時は ??? 表示）。
  • ユニーク（UNIQUE）であることは、テレポート耐性・即死無効などの複数の性質を暗黙に付与する点に注意（display-lore-status.cpp の判定を参照）。
  • 属性系の弱点/耐性/免疫は「同じ属性でも別フラグ」という構造のため、例えば「火炎耐性」と「火炎免疫」は排他ではなく、免疫があれば耐性・弱点判定より優先して免疫として扱われる。
