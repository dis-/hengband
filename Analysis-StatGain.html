能力が上昇時にどれだけ増えるか

← 解析 / Analysis

概要

能力値上昇薬などを使うと、内部関数 inc_stat()（src/status/base-status.cpp）が呼ばれて基本能力値（stat_cur）が1回ぶん上昇する。上昇量は現在値によって計算式が3通りに分かれ、乱数を含む。ここでは現行ソースに基づいて、その増加量を正確に説明する。

なお能力値の上昇薬を飲む処理（do_inc_stat()）では、増加の前にまず能力値をドレインから回復（res_stat()）してから inc_stat() を呼ぶ。したがって本ページで扱う「増加量」は、あくまで回復後の「基本値の最大まで届いている状態」から、さらに stat_max_max（能力の上限）を伸ばす分の話である。

能力値の内部表現

能力値は内部的に整数で保持される。

18以下          : そのままの数値（3〜18）
18/00 〜 18/(n) : 内部値 = 18 + n    （例: 内部値 88 は 18/70 と表示）

能力の上限 stat_max_max はキャラクター生成時に決まり、能力ごとの内部値で

stat_max_max = 18 + 60 + dice * 10   （dice は 1〜7 の乱数）

となる。したがって上限は内部値で 88〜148、表示では 18/70 〜 18/130 の範囲になる。以下の増加ロジックはこの stat_max_max を上限として働く。

増加ロジック

inc_stat() は現在の基本値 value（= stat_cur）を見て、次のように分岐する。まず value がすでに stat_max_max に達していれば上昇しない（失敗）。

(1) 現在値が18未満のとき

75%の確率で +1、25%の確率で +2 される。

value += evaluate_percent(75) ? 1 : 2;

evaluate_percent(75) は「randint0(100) < 75」、すなわち75%で真。したがって

75% の確率で +1
25% の確率で +2

平均すると約 +1.25 の上昇となる。18を超えて18/xx帯に踏み込む場合もそのまま加算される（例: 17 で +2 なら 19、つまり 18/01 相当）。

(2) 現在値が18以上で、かつ (stat_max_max − 2) 未満のとき

上限に対する残り幅が大きいほど大きく増える。まず増加の基準値 gain を計算する。

gain = (((stat_max_max) - value) / 2 + 3) / 2;   // 整数除算
if (gain < 1) gain = 1;

（(stat_max_max - value) は上限までの残り幅。それを4で割って +1〜2 する形。整数除算のため端数は切り捨て）

実際の増加量はこの gain を使って

value += randint1(gain) + gain / 2;

となる。randint1(gain) は 1〜gain の一様乱数、gain / 2 は整数除算。したがって1回の増加量は

増加量 = randint1(gain) + (gain / 2)
       = (1 + gain/2) 〜 (gain + gain/2)   の一様乱数

加算後、stat_max_max - 1 を超えていたらそこで頭打ちにされる。

if (value > (stat_max_max - 1)) value = stat_max_max - 1;

このため、この分岐だけでは stat_max_max そのもの（表示上の完全な上限）には到達せず、内部値で1だけ手前（stat_max_max - 1）までしか届かない。

増加量の具体例（上限が 18/100、すなわち stat_max_max = 118 の場合）

現在値（内部/表示） 残り幅 gain 増加量の範囲（=randint1(gain)+gain/2）
18（18/00） 100 (100/2+3)/2 = 26 14 〜 39
68（18/50） 50 (50/2+3)/2 = 14 8 〜 21
98（18/80） 20 (20/2+3)/2 = 6 4 〜 9
108（18/90） 10 (10/2+3)/2 = 4 3 〜 6

このように、上限までの残りが大きいほど1回の上昇が大きく、上限に近づくほど少しずつしか伸びなくなる。ただし途中で stat_max_max - 1 に丸められるため、上表の上側の値は残り幅で頭打ちになる点に注意。

(3) 現在値が (stat_max_max − 2) 以上のとき

上限のすぐ手前の帯では、乱数を使わず確実に +1 される。

value++;

この分岐によって、内部値で stat_max_max - 1（分岐(2)の頭打ち位置）や stat_max_max - 2 の状態からでも、最終的に stat_max_max（完全な上限）まで1ずつ到達できる。すでに stat_max_max に達していれば最初の判定で失敗する。

まとめ

  • 18未満: 75%で +1、25%で +2（平均 約+1.25）。
  • 18以上・上限の3手前まで: 上限までの残り幅に応じた gain を基準に、randint1(gain) + gain/2 だけ乱数増加。残りが大きいほど大きく増える。加算後は内部値で stat_max_max - 1 に頭打ち。
  • 上限の2手前以上: 乱数なしで確実に +1。これにより表示上の完全な上限（18/70〜18/130、能力ごとに異なる）まで到達できる。
  • 上限 stat_max_max はキャラクター生成時に能力ごとに 18/70〜18/130 の範囲でランダムに決まっており、これを超えて上昇することはない。

（増加量は乱数を含むため、実際の1回あたりの上昇幅は上記の範囲内でばらつく。「1回飲めば必ずこれだけ増える」という固定値ではない。）
