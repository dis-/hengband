地獄耐性（TR_RES_NETHER）

← プレイヤー耐性一覧 / Resistances

概要

地獄耐性は TR_RES_NETHER を中心に、has_resist_neth() と calc_nether_damage_rate() で参照される。地獄属性ダメージを乱数倍率で軽減し、地獄属性の経験値吸収を防ぐ。

効果

ダメージ倍率は calc_nether_damage_rate() の per で計算され、最終ダメージは dam * per / 100 になる。

per = 100;
if (has_resist_neth(player_ptr)) {
    if (!PlayerRace(player_ptr).equals(PlayerRaceType::SPECTRE)) per \*= 6;
    per \*= 100;
    per /= randrate(4, 7, mode);
}

CALC_RAND の randrate(4, 7, mode) は randint1(4) * 100 + 7 * 100。

条件 効果
has_resist_neth() かつ種族が SPECTRE ではない per *= 6; per *= 100; per /= randrate(4, 7, mode)
has_resist_neth() かつ種族が SPECTRE per *= 100; per /= randrate(4, 7, mode)

地獄属性の副次効果は effect_player_nether() で処理される。

if (PlayerRace(player_ptr).equals(PlayerRaceType::SPECTRE)) {
    if (!evaded) hp_player(player_ptr, ep_ptr->dam / 4);
    ep_ptr->get_damage = 0;
    return;
}
if (!has_resist_neth(player_ptr) && !evaded) {
    drain_exp(player_ptr, 200 + (player_ptr->exp / 100), 200 + (player_ptr->exp / 1000), 75);
}
条件 効果
種族が SPECTRE かつ !check_multishadow() hp_player(dam / 4) で回復
種族が SPECTRE get_damage = 0 で処理終了
!has_resist_neth() かつ !check_multishadow() drain_exp(200 + exp / 100, 200 + exp / 1000, 75)
has_resist_neth() 上記の経験値吸収を防ぐ

一時耐性・補足

has_resist_neth() は通常耐性に加えて ult_res と tim_res_nether を耐性要因に含める。

result = common_cause_flags(player_ptr, TR_RES_NETHER);
if (player_ptr->ult_res || player_ptr->tim_res_nether) result |= FLAG_CAUSE_MAGIC_TIME_EFFECT;
