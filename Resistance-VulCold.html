冷気弱点（TR_VUL_COLD）

← プレイヤー耐性一覧 / Resistances

概要

冷気弱点（TR_VUL_COLD）は、冷気属性ダメージ倍率計算で has_vuln_cold(player_ptr) の原因フラグとして扱われる弱点です。has_immune_cold がある場合は倍率計算が 0 を返すため、弱点・通常耐性・一時耐性より先にダメージが 0 になります。

効果

calc_cold_damage_rate(player_ptr) の倍率 per は、弱点の原因フラグごとに次の順で計算されます。最終ダメージは cold_dam() で dam = dam * ${calc}(player_ptr) / 100 として適用されます。

per = 100;
if (${immune}(player_ptr)) return 0;
for (check_flag in ${vuln}(player_ptr)) {
    if (check_flag == FLAG_CAUSE_MUTATION) per *= 2;
    else per += per / 3;
}
if (${resist}(player_ptr)) per = (per + 2) / 3;
if (${oppose}(player_ptr)) per = (per + 2) / 3;
return per;
条件 効果
has_vuln_cold(player_ptr) に TR_VUL_COLD 由来の原因フラグがある その原因フラグ 1 個につき per += per / 3
has_vuln_cold(player_ptr) に FLAG_CAUSE_MUTATION がある その原因フラグでは per *= 2
has_immune_cold(player_ptr) return 0
has_resist_cold(player_ptr) 弱点補正後に per = (per + 2) / 3
is_oppose_cold(player_ptr) さらに per = (per + 2) / 3

cold_dam() で確認できる副次効果は次の通りです。

条件 処理
ダメージ計算後 dam <= 0 return 0
`aura
!aura && !(${oppose}(player_ptr) && ${resist}(player_ptr)) inventory_damage(player_ptr, ${itemBreaker}, inv)

一時耐性・補足

is_oppose_cold(player_ptr) は一時耐性を表し、通常耐性とは別に同じ (per + 2) / 3 をもう一度適用します。oppose_* の通常の時限値に加えて、music_singing(player_ptr, MUSIC_RESIST) と SamuraiStanceType::MUSOU でも真になります。

冷気の自己オーラ/騎乗オーラ処理では、PlayerRace(player_ptr).tr_flags().has(${flag}) のとき damage += damage / 3、その後 ${resist}(player_ptr) と ${oppose}(player_ptr) がそれぞれ damage = damage / 3 を適用し、最後に std::max(damage, 1) で 1 以上に丸められます。
