浮遊（TR_LEVITATION）

← プレイヤー耐性一覧 / Resistances

概要

浮遊は TR_LEVITATION に対応する能力で、プレイヤー状態では player_ptr->levitation = has_levitation(player_ptr) として保持される。has_levitation() は装備・種族・職業・構えの TR_LEVITATION に加え、変異 PlayerMutationType::WINGS、ult_res、magicdef、tim_levitation を原因として成立する。

乗馬中は、装備などの結果ではなく、騎乗中モンスターが MonsterFeatureType::CAN_FLY を持つ場合だけ浮遊扱いになる。

効果

成立条件

条件 効果
装備・種族・職業・構えが TR_LEVITATION を持つ has_levitation() が真になる
変異 PlayerMutationType::WINGS has_levitation() が真になる
ult_res または magicdef has_levitation() が真になる
tim_levitation has_levitation() が真になる
乗馬中で騎乗モンスターが CAN_FLY 浮遊扱い
乗馬中で騎乗モンスターが CAN_FLY でない 浮遊扱いにならない

落とし穴・落とし戸

落とし穴系の罠では、浮遊していると罠を飛び越えて処理を終了する。

罠 浮遊時
PIT 落ちずに終了
SPIKED_PIT 落ちずに終了
POISON_PIT 落ちずに終了
TRAPDOOR 落とし戸を飛び越え、落下ダメージと階層移動を受けない

通常時の落下ダメージは、落とし穴が 2d6、落とし戸が 2d8。

pit damage = Dice::roll(2, 6)
trapdoor damage = Dice::roll(2, 8)

深い水

移動可否判定では、深い水は浮遊または水泳がないと入れない。

if terrain has WATER and DEEP:
    if !levitation && !can_swim:
        cannot enter

溺れダメージは、深い水にいて、浮遊も水泳も水耐性もなく、さらに所持重量が重量制限を超えている場合だけ発生する。

if deep_water && !levitation && !can_swim && !has_resist_water:
    if inventory_weight > weight_limit:
        take_hit(randint1(player.level), drowning)

溶岩・地形ダメージ

溶岩地形の通行判定では、火炎免疫または無敵なら通行可能。深い溶岩は常に進入不可。浅い溶岩は浮遊がないと進入不可。

if !LAVA || immune_fire || invuln:
    can enter
else if DEEP:
    cannot enter
else:
    can enter only if levitation

溶岩などの地形ダメージ処理では、深い地形は浮遊していても基礎ダメージを持つ。浅い地形では、浮遊していると基礎ダメージが 0 になり、結果としてダメージが発生しない。

if DEEP:
    damage = 6000 + randint0(4000)
else if !levitation:
    damage = 3000 + randint0(2000)
else:
    damage = 0

damage = damage * damage_rate / 100
if levitation:
    damage = damage / 5
damage = damage / 100 + evaluate_percent(damage % 100)

虚無・深淵ダメージへの影響

浮遊は属性ダメージの倍率計算にも関与する。

  • 虚無（VOID_MAGIC）: calc_void_damage_rate() で、壁抜けも反テレポートも無い場合に限り per = per * 2 / 3（約67%）に軽減される。詳細は 虚無 / VOID_MAGIC。
  • 深淵（ABYSS）: calc_abyss_damage_rate() の 1.25倍増加は「浮遊なし かつ 反テレポート」が条件のため、浮遊しているとこの増加を受けない（ただし軽減もしない）。詳細は 深淵 / ABYSS。

補足

CAN_FLY 地形は、浮遊があれば通行可能になる。逆に、移動処理では MOVE を持たず CAN_FLY を持つ地形に対し、浮遊していない場合は「空を飛ばないと行けない」として移動を止める。
