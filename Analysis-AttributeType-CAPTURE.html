捕獲 / AttributeType::CAPTURE

← AttributeType 一覧

項目 内容
ID 99
enum AttributeType::CAPTURE
分類 モンスター制御 / Monster utility
プレイヤー処理 未処理（defaultでダメージ0）
モンスター処理 effect_monster_capture()
地形処理 effect-feature.cpp で参照
アイテム処理 -
描画色 0x0E

概要

捕縛（CAPTURE）は、モンスターボールで対象のモンスターを捕らえる属性である。捕縛には対象を十分に弱らせておく必要があり、ユニークなど一部のモンスターは捕縛できない。

モンスターへの効果

effect_monster_capture（effect-monster-charm.cpp）で処理される。まず、以下のいずれかに該当すると捕縛できず「効果がなかった」と表示される。

捕縛不可条件
KILL_ALL クエスト中で、対象がペットでないクエストモンスター
ユニークモンスター（MonsterKindType::UNIQUE）
クエスト出現モンスター（MonsterMiscType::QUESTOR）
ナズグル（MonsterPopulationType::NAZGUL）
唯一無二（MonsterPopulationType::ONLY_ONE）
ぶんぶんストライカー（MonsterPopulationType::BUNBUN_STRIKER）
召喚元（親）を持つモンスター（has_parent()）

捕縛不可時のメッセージ:

%sには効果がなかった。

捕縛可能な場合、捕縛可能HPしきい値を計算する（calcutate_capturable_hp）。係数は対象の状態・職業により変化する。

対象・職業 係数（対象HPに対して）
ペット ×4
ビーストマスターかつ生命体 ×3/10
上記以外 ×3/20

しきい値の判定:

r_max_hp    = monrace の最大HPロール値
threshold_hp = calcutate_capturable_hp(r_max_hp)
capturable_hp = max(2, calcutate_capturable_hp(max_maxhp))

threshold_hp < 2 または 現在HP >= capturable_hp のとき捕縛失敗（弱らせ不足）

弱らせ不足の場合のメッセージ:

もっと弱らせないと。

上記を満たしたうえで、捕縛成否を乱数で判定する。

現在HP <= randint1(capturable_hp) なら捕縛成功

捕縛成功時（effect_monster_captured）、カメレオンなら変身を解除し、モンスターボールへ種族・速度・HP・愛称を記録して対象をフロアから消去する。騎乗していた場合は落馬処理を行う。

捕縛成功: %sを捕えた！
落馬時:   地面に落とされた。

判定に失敗した場合のメッセージ:

うまく捕まえられなかった。

CAPTURE は完全耐性（RESIST_ALL）を貫通する特例属性に含まれる。

プレイヤーへの効果

effect-player-switcher.cpp に CAPTURE のケースは無く、default に落ちてダメージ0となる。プレイヤーへの効果は無い。

アイテムへの効果

effect-item.cpp に CAPTURE のケースは無い。アイテムへの効果は無い。

地形への効果

effect-feature.cpp では CAPTURE は「ほとんどの効果を無視する」グループに含まれ、地形への効果は無い。
