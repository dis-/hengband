創傷 / AttributeType::WOUNDS

← AttributeType 一覧

項目 内容
ID 116
enum AttributeType::WOUNDS
分類 モンスター制御 / Monster utility
プレイヤー処理 未処理（defaultでダメージ0）
モンスター処理 effect_monster_wounds()
地形処理 -
アイテム処理 -
描画色 既定色

概要

創傷 (WOUNDS) は、対象に出血 (HP割合) ダメージを与える魔法属性である。モンスターに対してはレベルに応じて確率で無効化される。プレイヤーへの専用処理・アイテム・地形への効果はない。

モンスターへの効果

処理は effect_monster_wounds (effect-monster-switcher.cpp) で行われる。

以下の条件を満たすと効果が無効化され、ダメージが 0 になる。

randint0(100 + dam) < (level + 50)
条件 メッセージ ダメージ
上記判定に該当 (無効) 「には効果がなかった。」 0
上記判定に非該当 （ダメージそのまま） dam

無効化されなかった場合、そのままダメージを与える。

プレイヤーへの効果

創傷属性に対するプレイヤー専用の処理はなく、ダメージは 0 となる (switch_effects_player の default)。

アイテムへの効果

アイテムへの効果はない。

地形への効果

地形への効果はない。
