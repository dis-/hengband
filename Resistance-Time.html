時間逆転耐性（TR_RES_TIME）

← プレイヤー耐性一覧 / Resistances

概要

時間逆転耐性は TR_RES_TIME に対応する高級耐性で、has_resist_time() が真になると時間逆転属性ダメージを軽減し、時間逆転の追加効果を防ぐ。

効果

時間逆転属性ダメージ

calc_time_damage_rate() では、時間逆転耐性がある場合だけ倍率が変わる。

per = 100;
if (has_resist_time(player_ptr)) {
    per *= 400;
    per /= randrate(4, 7, mode);
}

CALC_RAND では randrate(4, 7) は (1d4 + 7) * 100 なので、実戦時の倍率は次の範囲になる。

damage_rate = 400 / (1d4 + 7)
実効倍率 = 36% から 50%
条件 ダメージ倍率
時間逆転耐性なし 100%
時間逆転耐性あり 400 / (1d4 + 7)%

時間逆転の追加効果

時間逆転属性を受けた後、耐性がない場合だけ追加効果 effect_player_time_addition() が実行される。

if (!has_resist_time(player_ptr) && !evaded) {
    effect_player_time_addition(player_ptr);
}

追加効果の分岐は randint1(10) で決まる。

出目 効果
1-5 アンドロイド以外は lose_exp(player_ptr, 100 + (exp / 100) * MON_DRAIN_LIFE)
6-9 ランダムな能力値低下
10 全能力値低下
条件 追加効果
時間逆転耐性なし、かつ分身回避なし 発生する
時間逆転耐性あり 発生しない

時間攻撃の打撃

モンスターの時間攻撃打撃でも、時間逆転耐性は追加効果を防ぎ、打撃ダメージを軽減する。

process_monster_attack_time(player_ptr);
if (has_resist_time(player_ptr)) {
    monap_ptr->damage = monap_ptr->damage * (randint1(4) + 4) / 9;
}
条件 打撃ダメージ倍率 追加効果
時間逆転耐性なし 100% 発生しうる
時間逆転耐性あり (1d4 + 4) / 9 発生しない
