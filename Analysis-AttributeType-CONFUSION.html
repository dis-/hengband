混乱 / AttributeType::CONFUSION

← AttributeType 一覧

項目 内容
ID 22
enum AttributeType::CONFUSION
分類 ダメージ / Damage
プレイヤー処理 effect_player_confusion()
モンスター処理 effect_monster_confusion()
地形処理 -
アイテム処理 -
描画色 mh_attr(4)

概要

混乱 (CONFUSION) は、対象に混乱状態を付与する魔法属性である。モンスターに対しては混乱耐性 (NO_CONF) の有無でダメージと効果が変化し、プレイヤーに対しては混乱耐性がなければ混乱状態を付与しつつダメージを与える。

モンスターへの効果

処理は effect_monster_confusion (effect-monster-resist-hurt.cpp) で行われる。

混乱耐性 (NO_CONF) を持たないモンスターには、以下の混乱付与値 (do_conf) を設定する。

do_conf = (10 + randint1(15) + r) / (r + 1)

（r は距離減衰係数）

混乱耐性 (NO_CONF) を持つモンスターにはダメージが軽減される。

dam = dam * 3 / (randint1(6) + 6)
条件 結果
混乱耐性なし do_conf 分の混乱を蓄積
混乱耐性あり 「には耐性がある。」、ダメージ 3/(randint1(6)+6) 倍

蓄積された混乱値は effect_damage_piles_confusion (effect-monster.cpp) で適用される。混乱耐性を持つ場合は適用されない。

状態 メッセージ
新規に混乱 「は混乱したようだ。」
すでに混乱中に追加 「はさらに混乱したようだ。」（残り混乱値 + do_conf/2 を加算）

プレイヤーへの効果

処理は effect_player_confusion (effect-player-resist-hurt.cpp) で行われる。

盲目状態の場合、「何か混乱するもので攻撃された！」と表示される。

ダメージは混乱ダメージ率で補正される。

dam = dam * calc_conf_damage_rate(player_ptr, CALC_RAND) / 100

混乱耐性がなく、多重影 (multishadow) でもない場合、混乱状態を付与する。

混乱付与ターン = randint1(20) + 10

補正後ダメージで take_hit によるダメージを受ける。

アイテムへの効果

アイテムへの効果はない。

地形への効果

地形への効果はない。
