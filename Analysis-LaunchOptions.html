起動オプション

← 解析 / Analysis

概要

変愚蛮怒の起動オプション（コマンドライン引数）は、ビルドするプラットフォームによって扱いが大きく異なる。

  • Windows版（src/main-win.cpp ＋ src/main-win/commandline-win.cpp）：コマンドライン引数はほぼセーブファイルの指定と一部のデバッグ用途に限られる。グラフィック・音楽・効果音・キー配置などは、コマンドラインではなく INIファイルから読み込まれ、ゲーム内のオプションメニューで変更・永続化される。
  • POSIX/Unix版（src/main.cpp、#ifndef WINDOWS の共通 main()）：伝統的な1文字オプション（-n, -b, -u<who> など）と、-- 以降に表示モジュールへ渡すサブオプションを持つ。

このページでは両プラットフォームの起動オプションを網羅する。オプション名はソースの switch 文（src/main.cpp の main()／src/main-win/commandline-win.cpp の CommandLine::handle()）から導出している。

1. Windows版のコマンドライン

Windows版は CommandLineToArgvW() で取得した引数を CommandLine::handle() が走査する。認識するのは次の6つだけで、これ以外の引数は無視される。

オプション 効果
--debug-console デバッグ用コンソール（標準出力）を AllocConsole() で開く
--output-spoilers スポイラー（各種ゲームデータ一覧）ファイルを生成して即終了（create_debug_spoiler）
--bot-json-output[=path] Bot向けJSON出力モードを有効化（arg_bot_json_output）。=path で出力先を指定、=- で標準出力
-o / -r オリジナル／ローグライク・キー配置を強制（arg_force_original / arg_force_roguelike）
先頭が - でない最初の引数 セーブファイル名とみなす（savefile_option）。以降の非オプション引数は無視

なお、起動時の引数ダンプ（argv[n] : …）は標準エラーへ出力される。--bot-json-output=- を指定したときに標準出力をJSONL専用の出力先として使えるようにするためである。

セーブファイル引数は、実質的にセーブファイルをアイコンにドラッグ&ドロップ／ダブルクリックで起動したときに Windows が渡すファイル名を受け取るための仕組みである（check_for_save_file がそのファイルで game_in_progress = true にしてゲームを再開する）。

Windowsの設定はINIファイル＋メニュー経由

Windows版の描画・音まわりは起動時に INIファイル（GetPrivateProfileIntA("Angband", …)）から読まれる。対応する arg_* 変数と既定値は次の通り。

INIキー 変数 内容
Graphics arg_graphics グラフィックモード（0=なし）
Bigtile arg_bigtile ビッグタイル表示
Sound arg_sound 効果音の有効/無効
SoundVolumeTableIndex arg_sound_volume_table_index 効果音の音量段
Music arg_music BGMの有効/無効
MusicVolumeTableIndex arg_music_volume_table_index BGMの音量段
SaveFile savefile 前回のセーブファイルパス

これらはオプションメニュー（グラフィックなし／旧／新／新2、ビッグタイル、音楽＋音量、効果音＋音量）で切り替えると、WritePrivateProfileStringA によってINIへ書き戻され次回起動に反映される。すなわち Windows版では「起動オプション ＝ INI設定＋メニュー選択」であり、コマンドラインフラグでこれらを指定することはできない。

2. POSIX/Unix版のコマンドライン

main()（src/main.cpp）は引数を先頭から走査し、2文字目でオプションを判定する。多くは大文字・小文字の両方を受け付ける。オプションでない引数や未知のオプションに当たると display_usage() を表示する。

オプション 効果
-n / -N 新規キャラクターで開始（new_game）
-b / -B BGM（音楽）モードを要求（arg_music）
-v / -V 効果音モードを要求（arg_sound）
-g / -G グラフィックモードを要求（arg_graphics = ORIGINAL）
-r / -R ローグライク・キー配置を強制（arg_force_roguelike）
-o / -O オリジナル・キー配置を強制（arg_force_original）
-s<num> / -S<num> ハイスコアを <num> 件表示（0以下なら10件）
-u<who> / -U<who> プレイヤー名 <who>（＝セーブファイル）を使用。<who> 省略時はusage
-m<sys> 表示モジュール main-<sys> を強制（x11／gcu／cap）。省略時はusage
-M モノクロモード（arg_monochrome）
-d<def> / -D<def> lib サブディレクトリのパスを再定義（第3章）
-x<path> 記録済みプレイムービーを再生（prepare_browse_movie_with_path_build）。省略時はusage
--output-spoilers スポイラーを出力して終了
--bot-json-output[=path] Bot向けJSON出力モードを有効化（parse_long_opt）。=path で出力先を指定、=- で標準出力
-- オプション解析を打ち切り、以降を表示モジュールへ渡す（第4章）

usage に載るが未実装のオプション

display_usage() のヘルプ文には次の2つが記載されているが、実際の main() の switch には対応する case が無い。指定すると default（usage表示）に落ちる。

  • -f … 「Request fiddle mode」と表示されるが未実装。
  • -w … 「Request wizard mode」と表示されるが未実装。

ヘルプ文が実装より先行している箇所なので、-f / -w で fiddle / wizard を起動することはできない点に注意。

3. -d による lib ディレクトリの再定義

-d<what>=<path> の形式で、lib 以下のサブディレクトリの実パスを個別に差し替えられる（change_path）。<what> は差し替えたいディレクトリの頭文字1文字で、= 以降がパス。= が無い、または未知の頭文字だと quit_fmt でエラー終了する。

<what> 変数 用途
a ANGBAND_DIR_APEX ハイスコア等
f ANGBAND_DIR_FILE テキストデータ
h ANGBAND_DIR_HELP ヘルプ
i ANGBAND_DIR_INFO info
u ANGBAND_DIR_USER ユーザーファイル
x ANGBAND_DIR_XTRA 追加リソース（音・画像等）
b ANGBAND_DIR_BONE 墓（bone）ファイル
d ANGBAND_DIR_DATA データ
e ANGBAND_DIR_EDIT 編集データ（lib/edit）
s ANGBAND_DIR_SAVE セーブファイル
z ANGBAND_DIR_SCRIPT スクリプト

例：-ds=/path/to/save でセーブディレクトリだけを差し替える。頭文字の判定は小文字化されるため大文字でもよい。

4. 表示モジュールのサブオプション（-- 以降・Unix限定）

-- 単体を指定するとそこで標準オプションの解析を終え、残りの引数を選択された表示モジュール（X11／GCU／CAP）の初期化関数へそのまま渡す。以下は display_usage() が挙げるサブオプションで、対応するモジュールをビルドに含めた場合のみ有効。

X11（-mx11）

サブオプション 効果
-- -d ディスプレイ名を指定
-- -fb ビットマップフォントを使用
-- -ft TrueTypeフォントを使用
-- -o 旧8×8タイルグラフィック
-- -a Adam Bolt 16×16タイルグラフィック
-- -b ビッグタイル表示
-- -s スムーススケーリングを無効化
-- -n# 使用するターム（サブウィンドウ）数

GCU（GNU Curses）（-mgcu）

サブオプション 効果
-- -o 旧サブウィンドウ配置（bigscreen無効）

CAP（Termcap）（-mcap）：固有のサブオプションは無い。

5. 環境変数

  • ANGBAND_PATH（POSIX/Unix版・init_stuff）：lib パスの基点を指定する。未設定なら DEFAULT_LIB_PATH が使われる。末尾にパス区切りが無ければ自動で補われる。

まとめ

  • Windows版の実効的なコマンドライン起動オプションは --debug-console・--output-spoilers・--bot-json-output・-o/-r・セーブファイル名のみ。描画や音などのゲーム設定はINI＋オプションメニューで行う。
  • POSIX/Unix版は -n/-b/-v/-g/-r/-o/-s/-u/-m/-M/-d/-x・--output-spoilers・--bot-json-output・-- を持つ。-u<who> はプレイヤー名（セーブファイル）指定、-m<sys> は表示モジュール強制、-d<what>=<path> は lib ディレクトリ再定義に使う。
  • 両版共通で --output-spoilers はスポイラーファイルを生成して終了し、--bot-json-output[=path] はBot向けJSON出力モードを有効化する。
  • usage に載る -f（fiddle）・-w（wizard）はソース上未実装で、指定するとusageが表示される。
