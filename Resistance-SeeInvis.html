可視透明（TR_SEE_INVIS）

← プレイヤー耐性一覧 / Resistances

概要

可視透明は TR_SEE_INVIS に対応する能力で、プレイヤー状態では player_ptr->see_inv = has_see_inv(player_ptr) として保持される。has_see_inv() は装備・種族・職業・構えの TR_SEE_INVIS に加え、一時効果 ult_res または tim_invis を原因として成立する。

効果は透明モンスターの視認であり、モンスター種族が MonsterMiscType::INVISIBLE を持つ場合でも、視界条件を満たしていれば通常の視認フラグを立てられる。

効果

成立条件

条件 効果
装備・種族・職業・構えが TR_SEE_INVIS を持つ has_see_inv() が真になる
ult_res または tim_invis has_see_inv() が真になる

透明モンスターの視認

透明モンスターの判定は check_invisible() で行われる。まず対象グリッドが player_can_see_bold() で見えていなければ失敗する。対象が透明モンスターの場合、player_ptr->see_inv があると視認可能扱いになる。

if !player_can_see_bold(player, monster_pos):
    not visible

if monster has INVISIBLE:
    if player.see_inv:
        easy = true
        flag = true
else:
    easy = true
    flag = true

decide_sight_invisible_monster() 側では、距離と視線、盲目状態も条件になる。

条件 結果
距離が視認範囲外 可視透明による通常視認処理に進まない
対象位置に LOS がない 可視透明による通常視認処理に進まない
プレイヤーが盲目 可視透明による通常視認処理に進まない
対象が透明、かつ see_inv あり easy / flag を立て、モンスターを見える状態に更新する

補足

通常のモンスター感知 detect_monsters_normal() では、透明でないモンスター、またはプレイヤーが see_inv を持つ場合だけ MARK / SHOW を付ける。

if !monster.INVISIBLE || player.see_inv:
    MARK, SHOW

透明モンスター専用の感知 detect_monsters_invis() は、種族が MonsterMiscType::INVISIBLE を持つモンスターを対象にする。
