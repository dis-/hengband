元素使い / Elementalist

← 職業一覧 / Classes ・ 🏠 ホーム / Home

概要

元素使いはエレメンタルの力を駆使して戦う魔法使いです。扱える属性は限られますが、その力を十二分に引き出すことができます。魔法に必要な能力は賢さです。

固有システム・特殊能力

元素使いはエレメンタルの力を駆使して戦う魔法使いで、出生時に選ぶ元素系統により習得する呪文の属性が決まる。元素魔法は領域魔法ではないため、専用の呪文一覧ページは持たない。

元素使いの「明鏡止水」、元素攻撃、元素系統別の力はいずれも職業由来の職業能力（クラスパワー）であり、種族由来の種族能力ではない。U コマンドは種族由来の能力と職業由来の能力をまとめて表示するだけで、元素使いの能力そのものは職業能力として扱う。

レベル15から「明鏡止水」を使える。消費は0、判定能力値はWIS、難度は10%。MPを回復する能力で、回復量のMANAは 3 + Lv / 20 で計算される。

元素魔法

元素魔法は b で閲覧し、m で使う。失率はWISで下がり、重い鎧で+5、ふさわしくない武器1本ごとに+5される。攻撃呪文は選んだ元素系統の**3属性（属性0/1/2）**のいずれかを参照する（下表の呪文一覧の「属性」列が対応）。

戦闘・装備上の特徴

元素使い固有の戦闘要素は、通常の武器攻撃ではなく元素魔法と属性別の職業能力にある。元素魔法は G コマンドで学習する必要がなく、選んだ元素系統の属性名が %s に入る。

反魔法バリア中は「元素魔法」が邪魔される。装備重量によるMPへの影響は職業別の固有能力ではないため、詳細は 鎧によるMPペナルティ を参照する。

  • 魔法種別 / Magic type: 魔法なし/None
  • 詠唱能力値 / Spellcasting stat: 賢さ/Wisdom
  • 魔法領域は選択しません（固有の技術体系または魔法なし。詳細は上記「概要」を参照）。

職業固有の耐性・能力

レベルに応じて職業から恒常的に付与される耐性・能力（src/player-base/player-class.cpp の tr_flags）。装備や一時効果とは別に、条件を満たす限り常に有効。

  • 選択した元素系統に応じて耐性・免疫を得る（Lv1で耐性、Lv30で免疫または上位耐性）:
  • 炎系統 → 火炎耐性 → Lv30 火炎免疫
  • 氷系統 → 冷気耐性 → Lv30 冷気免疫
  • 空系統 → 電撃耐性 → Lv30 電撃免疫
  • 海系統 → 酸耐性 → Lv30 酸免疫
  • 闇系統 → 暗黒耐性 → Lv30 地獄耐性
  • カオス系統 → 混乱耐性 → Lv30 カオス耐性
  • 地系統 → 破片耐性 → Lv30 反射
  • 瘴気系統 → 毒耐性 → Lv30 劣化耐性
