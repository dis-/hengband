白兵攻撃 / AttributeType::ATTACK

← AttributeType 一覧

項目 内容
ID 103
enum AttributeType::ATTACK
分類 内部処理 / Internal
プレイヤー処理 未処理（defaultでダメージ0）
モンスター処理 do_cmd_attack()
地形処理 effect-feature.cpp で参照
アイテム処理 -
描画色 0x0F

概要

白兵（AttributeType::ATTACK、GF_ATTACK）は、効果システム（project/affect）の枠組みを使ってプレイヤーの近接攻撃を発動させるための特殊属性である。ダメージ属性としての実体は持たず、剣術（必殺技）などが対象マスへ通常の白兵攻撃を差し込む用途で用いられる。

switch_effects_monster()（src/effect/effect-monster-switcher.cpp）での処理:

case AttributeType::ATTACK:
    return do_cmd_attack(player_ptr, em_ptr->y, em_ptr->x,
        i2enum<combat_options>(em_ptr->dam)) ? PROCESS_TRUE : PROCESS_FALSE;

ここで dam フィールドはダメージ量ではなく、combat_options（剣術種別、src/combat/combat-options-type.h の HISSATSU_*）として再解釈され、対象座標に対して do_cmd_attack() による白兵攻撃を実行する。

モンスターへの効果

上記の通り、属性固有のダメージ計算は行わず、do_cmd_attack() を呼んで対象マスへ通常の近接攻撃を行う。実際のダメージ・命中・状態異常はすべて通常の白兵戦闘（および指定された剣術 combat_options）のロジックに委ねられる。攻撃が成立すれば PROCESS_TRUE、しなければ PROCESS_FALSE を返す。

プレイヤーへの効果

switch_effects_player()（src/effect/effect-player-switcher.cpp）に ATTACK の分岐は無く、default に落ちて dam = 0 となり、プレイヤーには何の効果も無い。

アイテムへの効果

affect_item()（src/effect/effect-item.cpp）に ATTACK の分岐は無く、default（break のみ）に落ちるため、アイテムには一切影響しない。

地形への効果

affect_feature()（src/effect/effect-feature.cpp）では、ATTACK は効果を無視する属性群（break のみ）に含まれ、地形には一切影響しない。
