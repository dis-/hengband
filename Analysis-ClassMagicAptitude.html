職業魔法の得意さの段階（仮仕様）

← 解析 / Analysis

⚠️ 仮仕様（検討中）。本家への提案前の設計案で、数値も含めて変わる可能性があります。

目的

現行の lib/edit/ClassMagicDefinitions.jsonc は、職業×領域×魔法ごとに習得レベル・消費MP・難易度・初回経験値倍率の 4 値を 手で書いています（14 職業 × 最大 10 領域 × 32 魔法 = 2,784 行、約 11,000 個の数値）。魔法を 1 つ追加・調整するたびに 全職業分を直す必要があります。

これを次の 2 段に分け、職業別の値はゲームの読み込み時に計算します。

  • 魔法の基準表: SpellDefinitions.jsonc の各魔法に基準値 4 つ（習得レベル・消費MP・難易度・初回経験値倍率）を持たせる。 歌・武芸・呪術（現在はソースに固定の technic_info）も同じ形で基準表に移す。
  • 得意さの段階: 職業×領域に「得意さの段階」（−3 専用 〜 3 かなり苦手、0 がメイジ相当）を 1 つ書き、段階ごとの補正（段階表）で 基準値から職業別の値を導く。意図のある例外は、習得不可の一覧と個別の上書きで書く。

データ形式

ClassMagicDefinitions.jsonc は、先頭の段階表（aptitude_table）と、職業ごとの領域の要素（段階と例外）になります。 職業単位の項目（spell_type、magic_status、first_spell_level など）は変わりません。

{
  "version": 2.0,
  "aptitude_table": [
    { "aptitude": -3, "learn_level": { "percent_by_book": [40, 40, 70, 70] }, "mana_cost": { "percent": 55 }, "difficulty": { "offset": -15 } },
    { "aptitude": -2, "learn_level": { "percent_by_book": [60, 60, 80, 85] }, "mana_cost": { "percent": 70 }, "difficulty": { "offset": -10 } },
    { "aptitude": -1, "learn_level": { "percent_by_book": [80, 80, 90, 90] }, "mana_cost": { "percent": 85 }, "difficulty": { "offset": -5 } },
    { "aptitude": 0 },
    { "aptitude": 1, "learn_level": { "percent_by_book": [115, 115, 105, 105], "offsets_by_book": [1, 1, 1, 1] }, "mana_cost": { "percent": 115 } },
    { "aptitude": 2, "learn_level": { "percent_by_book": [130, 120, 110, 110], "offsets_by_book": [2, 2, 2, 2] }, "mana_cost": { "percent": 130 }, "difficulty": { "offset": 5 } },
    { "aptitude": 3, "learn_level": { "percent_by_book": [145, 130, 115, 115], "offsets_by_book": [3, 3, 3, 3] }, "mana_cost": { "percent": 145 }, "difficulty": { "offset": 10 } },
  ],
  "classes": [
    {
      "name": "BEASTMASTER",
      "spell_type": "SORCERY",
      // ... 職業単位の項目は今のまま ...
      "realms": [
        {
          "name": "TRUMP",
          "aptitude": 2,                                               // 得意さの段階（省略時 0）
          "unlearnable": ["Phantasmal_Servant", "Trump_Undead"],       // 習得不可の魔法
          "overrides": [
            { "spell_tag": "Trump_Spiders", "aptitude": -1 },          // この魔法だけ別の段階
            { "spell_tag": "Haste_Monster", "aptitude": -1 },
          ],
        },
      ],
    },
    {
      "name": "TOURIST",
      // ...
      "realms": [
        {
          "name": "ARCANE",
          "aptitude": 1,
          "overrides": [
            { "spell_tag": "Identify", "aptitude": -3 }, // 職業別の得意魔法（段階 −3）。明示の値（learn_level など）も書ける
          ],
        },
      ],
    },
  ],
}
  • 段階表の要素は aptitude（整数、一意）と補正の係数を持ちます。係数は learn_level.percent_by_book / offsets_by_book（巻 1〜4 ごと）、learn_level.delay_by_difficulty（高難度の魔法の遅れ）、 mana_cost.percent / offset、difficulty.percent / offset、first_cast_exp_rate.percent。省略は既定値（倍率 100%・差 0）。
  • 領域の要素は aptitude のほか、max_book（習得できる巻数）、unlearnable（習得不可の魔法）、overrides（個別上書き）を持ちます。 係数を直接書いて段階表の値を項目ごとに上書きすることもできます。
  • 上書きの要素は spell_tag と、aptitude（その魔法だけ別の段階）か明示の値（learn_level など）を書きます。

導出の式

整数演算で、四捨五入は (x × percent + 50) / 100 の形で行います。book は spell_id / 8 + 1（1〜4）です。

(0) 係数の解決: 既定値 ← 段階表[領域の aptitude] ← 領域に直接書いた項目
    （魔法の上書きに aptitude があれば、既定値 ← 段階表[その aptitude] だけ）
(1) 基準の learn_level が 99                  → 習得不可
(2) book > max_book または unlearnable にある → 習得不可
(3) それ以外:
      遅れ        = round(max(0, 基準難易度 − threshold) × percent / 100)
      learn_level = clamp(round(基準 × percent_by_book[book]) + offsets_by_book[book] + 遅れ, 1, 50)
      mana_cost   = max(1, round(基準 × percent) + offset)
      difficulty  = clamp(round(基準 × percent) + offset, 0, 100)
      first_cast_exp_rate = round(基準 × percent)
(4) 上書きの明示の値で置き換える
(5) 最終的に learn_level が 99 なら他の 3 値は 0
(6) 範囲検査（習得レベル 1〜50 か 99、消費MP 0〜2047、難易度 0〜100、初回経験値倍率 0〜2047）

段階表（初期値）

段階 t の設計値は、習得レベルが巻 1 で ×(100＋15t)%、巻 2 で ×(100＋10t)%（段階 1 以下は巻 1 と同じ）、巻 3〜4 で ×(100＋5t)%（t が負なら 100＋20t / 100＋10t。段階 −2 の巻 4 だけ 85%）に差 max(0, t)、 消費MP が ×(100＋15t)%、難易度が ＋5(t−1)（t ≥ 1）または ＋5t（t < 0）、初回経験値倍率は 100% です。

職業×領域の段階（初期値）

メイジ・スペルマスターは全領域 0（基準表そのまま）、ハイ=メイジは全領域 −1、プリーストの生命は −2 です。 段階 −3（専用）は職業別の得意魔法のための段で、観光客の鑑定とパラディンの啓明に使っています。 魔獣使いのトランプは領域が 2 で、「〇〇のカード」（感知のカードを除く）とスピード・モンスター、回復モンスターだけ −1 にしています。 プリーストの暗黒・悪魔・破邪は領域が 0 で、聖職者らしい魔法（祈り・祝福・退魔・死者と霊・使役・炎・地獄・吸血など、各 16 個）だけ −1 にしています。 歌（吟遊詩人）・武芸（剣術家）・呪術（ハイ=メイジ）は段階 0 で、現在の technic_info の値がそのまま基準表になります。
