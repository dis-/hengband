騎乗時処理

← 解析 / Analysis

概要

騎乗（riding）は、ペット化した（あるいは荒馬慣らしで乗りこなした）モンスターに乗り、その速度で移動し、騎兵戦を行うシステムである。乗れるのは特定のモンスターに限られ、乗馬中は速度・命中・攻撃回数・地形通過などが騎乗中のモンスターに依存して変化する。落馬判定や制御失敗もある。

以降で扱う数値・条件は、いずれもソースコードから確認できたもののみを記載する。乗馬技能そのものの成長・ランク詳細は別ページ（技能）を参照。

騎乗できる条件

騎乗コマンド（do_cmd_riding）で、隣接マスにいるモンスターに乗ろうとする。以下をすべて満たす必要がある。

  • 混乱していないこと。
  • そのマスにモンスターがいて、視認できていること。
  • そのモンスターがペットであること（荒馬慣らしなど force 指定時は非ペットでも可）。
  • そのモンスターが RIDING フラグ（乗馬可能フラグ）を持つこと。持たない場合「そのモンスターには乗れなさそうだ。」と表示され失敗する。
  • そのマスにプレイヤーが（乗馬状態で）進入可能であること。

これらを満たした上で、以下の騎乗成功判定に通る必要がある。

騎乗失敗する条件:
    モンスターのレベル > randint1( 乗馬技能値 / 50 + プレイヤーレベル / 2 + 20 )

失敗すると「うまく乗れなかった。」と表示され、100 のターンエネルギーを消費する。成功した場合、対象が眠っていれば起こして騎乗する。

randint1(n) は 1 以上 n 以下の一様乱数を表す。したがって乗馬技能値とプレイヤーレベルが高いほど、また相手モンスターのレベルが低いほど成功しやすい。

荒馬慣らし（騎兵の特殊能力）

騎兵（CAVALRY）のレイシャルパワー「荒馬慣らし」（rodeo）は、非ペットのモンスターにも強制的に騎乗を試み、乗りこなせればペット化する。

騎乗後、対象がペットでなければ乗りこなし判定を行う。まず相手の実効レベル rlev を求める。

rlev = モンスターのレベル
UNIQUE なら  rlev = rlev * 3 / 2
rlev > 60 なら  rlev = 60 + (rlev - 60) / 2

そのうえで、以下をすべて満たせば手なずけ成功（ペット化）。

randint1( 乗馬技能値 / 120 + プレイヤーレベル * 2 / 3 ) > rlev
かつ one_in_(2)
かつ アリーナ内でない・戦闘会場でない
かつ 相手が GUARDIAN でも QUESTOR でもない
かつ rlev < プレイヤーレベル * 3 / 2 + randint0( プレイヤーレベル / 5 )

成功しなければ「振り落とされた！」となり、強制落馬（force = true）して乗馬解除される。

騎乗中の移動速度

乗馬中はプレイヤー本来の速度計算を破棄し、騎乗中のモンスターの速度をもとに再計算する（set_exception_bonus）。乗馬時は次の項のみを合算する。

  • 基準速度（STANDARD_SPEED）
  • 騎乗ボーナス（下記 riding_bonus）
  • 重量ペナルティ（下記、通常時とは別計算）
  • 探索中ペナルティ（探索中は -10）

装備・種族・職業・加速アイテムなどによる通常の速度補正は乗馬中は反映されない。

騎乗ボーナス

モンスターの速度 mspeed が基準速度を上回るかどうかで式が分かれる。

mspeed > STANDARD_SPEED のとき:
    bonus = (mspeed - STANDARD_SPEED)
          * (乗馬技能値 * 3 + プレイヤーレベル * 160 - 10000) / 22000
    bonus < 0 なら bonus = 0

mspeed <= STANDARD_SPEED のとき:
    bonus = mspeed - STANDARD_SPEED

すなわち、モンスターが速い場合はその加速分をまるごとは活かせず、乗馬技能とプレイヤーレベルに応じた割合しか得られない（技能・レベルが低いと 0 になりうる）。モンスターが遅い場合はその減速分がそのまま乗り手に及ぶ。

さらに、上記に次の技能・レベル由来の加算が加わる。

bonus += (乗馬技能値 + プレイヤーレベル * 160) / 3200

加えて、騎乗中のモンスター自身が一時的に加速状態なら +10、減速状態なら -10 される。

騎乗中の重量ペナルティ

乗馬中は所持重量の許容量が騎乗モンスターのレベルで決まる。

count = 1500 + モンスターのレベル * 25
weight > count のとき:
    bonus -= (weight - count) / (count / 5)

weight は所持品の総重量。レベルの高いモンスターに乗るほど多くの荷物を運べる。

騎乗中の移動制御と地形

移動しようとする際、騎乗中のモンスターの状態・特性により制御に失敗することがある（movement-execution）。

  • モンスターが NEVER_MOVE（決して動かない）を持つ: 「動けない！」で移動不可。
  • モンスターが恐怖している: 「〜が恐怖していて制御できない。」で移動不可。
  • 両手がふさがっている等で riding_ryoute（両手騎乗）状態: 制御不能で移動不可。
  • モンスターが朦朧（stun）している: one_in_(2) で「うまく動けない！」となり移動不可。

地形の通過可否も騎乗モンスターの特性に従う。

  • CAN_FLY 地形（深淵など）は、モンスターが CAN_FLY を持てば通過可。プレイヤーが浮遊を得るかどうかも騎乗中はモンスターの CAN_FLY に依存する。
  • 水地形は、モンスターが CAN_SWIM または AQUATIC なら通れる。深い水や炎オーラ持ちは非水棲だと入れない。逆に AQUATIC（水棲）のモンスターは水以外の地形に上がれない。
  • 溶岩は、モンスターが火への完全耐性を持たなければ入れない。
  • 壁を掘り進む（KILL_WALL）・壁抜け（PASS_WALL）も、それぞれ騎乗モンスターの対応フラグがあれば可能になる。
  • 森（TREE）地形では、レンジャー・浮遊・野生の森を進めるモンスター（WILD_WOOD）のいずれかであれば移動エネルギーが 2 倍にならずに済む。

なお、乗り手（プレイヤー）が敵対的な同乗ペットに乗っている場合など、行動処理では次の条件で騎乗が維持される（そうでなければ振り落とし処理に進む）。

abs(alignment / 10) < randint0( 乗馬技能値 )

騎乗モンスターの手番

騎乗中のモンスターは独立した速度で動かず、乗り手であるプレイヤーの速度で手番を消費する。

speed = 騎乗中 ? プレイヤーの速度(pspeed) : モンスター自身の速度

また騎乗中のモンスターは、通常時に do_turn / do_move が発生しなかった際の呪文発動処理などの一部の自律行動が抑制される。

落馬判定

被ダメージ時などに落馬するかどうかを判定する（process_fall_off_horse / calc_fall_off_possibility）。ワイルドエリア（wild_mode）では落馬しない。

モンスターから直接攻撃を受けたとき（check_fall_off_horse）、騎乗中かつダメージが 0 でなければ判定を行う。このときの判定ダメージは 200 で上限が掛かる（dam > 200 ? 200 : dam）。

落馬確率の計算

force（強制落馬）なら無条件で落馬する。そうでなければ次を計算する。

cur = 乗馬技能値
fall_off_level = モンスターのレベル
両手騎乗(riding_ryoute) なら  fall_off_level += 20

randint0( dam / 2 + fall_off_level * 2 ) >= cur / 30 + 10
    → 落馬（判定続行）

dam は判定を発したダメージ量。乗馬技能値 cur が高いほど右辺が大きくなり落馬しにくい。レベルの低いモンスターに乗っているほど落馬しにくい。両手がふさがっている（両手騎乗）と落馬しやすくなる。

上の第 1 判定を通過（＝落馬しない側）した場合でも、さらに次の踏みとどまり判定がある。

( is_tamer かつ 両手騎乗でない )
   または  !one_in_( プレイヤーレベル * (両手騎乗なら 2, そうでなければ 3) + 30 )
       → 落馬しない（踏みとどまる）
   それ以外 → 落馬

ここで is_tamer は騎兵（CAVALRY）または獣王（BEASTMASTER）を指す。すなわち騎兵・獣王は（両手騎乗でない限り）第 1 判定を切り抜ければ確実に踏みとどまる。それ以外の職業はプレイヤーレベルが高いほど踏みとどまりやすい。

落馬時の処理

落馬が確定すると、まず落下先の空きマスを周囲 8 方向から探す（モンスター・進入不可地形・パターン地形は除外し、候補からランダムに 1 つ選ぶ）。

落下先が見つからない場合は落馬せず、代わりに壁への衝突ダメージを受ける。

壁への衝突ダメージ = モンスターのレベル + 3

落下先がある場合は乗馬を解除し、両手騎乗フラグ等をクリアしたうえで着地する。

  • 浮遊状態（levitation）かつ強制落馬でないなら、「空中でうまく体勢を立て直して着地した」となりダメージを受けない。
  • そうでなければ落馬ダメージを受ける。
落馬ダメージ = モンスターのレベル + 3

死亡していなければ、選ばれた落下先マスへ移動する。

なお、騎乗中のモンスターが死亡した場合や、変身によって RIDING フラグを失った場合も落馬（または地面に落とされる）処理が発生する。

騎乗中の命中・攻撃への影響

近接攻撃の命中補正

装備武器に応じて命中補正が入る（calc_to_hit）。

  • ランス（槍）を装備している場合: 命中 +15。
  • RIDING フラグを持つ武器の場合: ペナルティなし。
  • 上記以外の武器の場合、騎乗ペナルティが入る。
is_tamer（騎兵・獣王）のとき:
    penalty = 5
それ以外:
    penalty = モンスターのレベル - 乗馬技能値 / 80
    penalty += 30
    penalty < 30 なら penalty = 30
命中 -= penalty

騎兵・獣王は乗馬に不向きな武器でもペナルティが 5 に固定され、非常に軽い。それ以外の職業は最低でも 30 のペナルティを受け、乗馬技能が低くモンスターレベルが高いほど大きくなる。

弓・射撃の命中補正

射撃時にも騎乗ペナルティがある（calc_riding_bow_penalty）。

is_tamer（騎兵・獣王）のとき:
    弾がアロー(矢)でなければ penalty = 5、アローなら 0
それ以外:
    penalty = モンスターのレベル - 乗馬技能値 / 80
    penalty += 30
    penalty < 30 なら penalty = 30

弾がボルトの場合:  penalty *= 2

このペナルティが射撃命中値から差し引かれる。騎兵・獣王は矢を使えばペナルティなし、それ以外の弾でも軽微で済む。それ以外の職業は最低 30、ボルトならその 2 倍のペナルティとなる。

素手・格闘への影響

修行僧・練気術師・狂戦士の素手格闘は、利き手が空いていても騎乗中は発動しない（riding 中は monk_attack を有効化しない）。

ランスの攻撃回数・ダメージダイス

騎乗中にランスを装備すると、ダメージダイスの本数が +2 される。

両手武器・両手騎乗

騎乗中に両手武器を使う、あるいは両手がふさがると riding_ryoute（両手騎乗）状態となり、「馬を操れない」状態になる。この状態では前述のとおり移動不可となり、落馬もしやすくなる（落馬判定でモンスターレベル扱いに +20、踏みとどまり判定の分母係数も不利化）。

職業補正（騎兵・獣王）

騎兵（CAVALRY）と獣王（BEASTMASTER）は is_tamer に該当し、騎乗全般で優遇される。

  • 命中ペナルティの軽減: 乗馬に不向きな武器・弾でも近接・射撃ともにペナルティが 5（矢なら 0）に固定される。
  • 落馬しにくさ: 両手騎乗でなければ、落馬の第 1 判定を切り抜けた際に確実に踏みとどまる。
  • 騎兵のランス特化攻撃回数: 騎兵が騎乗中に RIDING フラグ付き武器を装備すると、攻撃回数計算の基礎値が特別扱いになる（num = 5, wgt = 70, mul = 4）。
  • 騎兵のペット維持コスト軽減: ユニークのペットの維持コスト計算で、騎乗中の個体は (レベル + 5) * 2、乗馬可能な控えの個体は (レベル + 5) * 7 / 2 と軽く見積もられる（騎兵以外は一律 (レベル + 5) * 10）。

乗馬技能の関与（概要）

乗馬技能値は騎乗のほぼ全処理に影響する。技能値が高いほど、

  • 騎乗成功判定に通りやすい。
  • 騎乗ボーナス（速度）を多く得られる。
  • 命中・射撃の騎乗ペナルティ（is_tamer 以外の職業）が小さくなる。
  • 落馬しにくくなる。

技能値は近接攻撃時・射撃時・落馬判定時に成長する。ランクや成長式の詳細は技能ページを参照。
