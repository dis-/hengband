魔道具術師 / Magic-Eater

← 職業一覧 / Classes ・ 🏠 ホーム / Home

概要

魔道具術師は杖、魔法棒、ロッドといった魔法のアイテムから魔力を取り込むことによって魔法を使います。魔法のアイテムを発見することが他の職業よりもはるかに重要になります。戦闘力は高くはないですが、そこそこの強さがあります。魔法に必要な能力は知能です。

固有システム・特殊能力

魔道具術師は、魔法道具を取り込んで魔力として扱う職業である。取り込んだ魔法道具は取り出せない。

能力 最低Lv 消費 能力値 難度 効果
魔力の取り込み 1 0 INT - 魔法道具を取り込み魔力にする。取り出せない。
強力発動 10 10+(Lv-10)/2 INT - 取り込んだ道具を威力を高めて発動する。

取り込んだ魔力の扱い

魔力の取り込み は杖・魔法棒・ロッドを対象にし、鑑定済みで充填中でない魔法道具だけを取り込める。取り込んだ実体アイテムは消滅し、後から取り出せない。何も能力を持たない杖は取り込めない。

系統 取り込み上限 充填/回復の扱い
杖 同一種類ごとに最大99、種類配列は EATER_ITEM_GROUP_SIZE=256 EATER_CHARGE=0x10000 を1回分として管理する。発動で1回分減り、自然回復で count×EATER_CHARGE まで戻る。
魔法棒 同一種類ごとに最大99、種類配列は EATER_ITEM_GROUP_SIZE=256 杖と同じく EATER_CHARGE=0x10000 を1回分として管理する。発動で1回分減り、自然回復で count×EATER_CHARGE まで戻る。
ロッド 同一種類ごとに最大99本、種類配列は EATER_ITEM_GROUP_SIZE=256 回数ではなく残り充填時間を EATER_ROD_CHARGE=0x10 単位で管理する。発動すると pval×EATER_ROD_CHARGE だけ充填時間が増え、自然回復で0へ減る。
  • 杖は取り込んだ杖の pval を基準に使用回数上限が増える。同じ種類を追加で取り込む場合、増加量は乱数を含めておよそ1/3から2/3になり、最低1は増える。
  • 魔法棒はスタック内の残り pval を本数で分けながら取り込み、同じ種類を追加で取り込む場合は杖と同じ補正を受ける。
  • ロッドは取り込んだ本数ぶん count が増える。使用可能判定は charge <= pval×(count - 1)×EATER_ROD_CHARGE で、一覧では charge から充填中の本数を表示する。
  • 魔道具術師のチャージ自然回復は通常のMP回復処理とは別に行われる。休息中は回復量が2倍になり、再生があればさらに2倍になる。杖・魔法棒は regen_amount×(30 + INT補正)×(count + 13)/(30×8) ずつ増え、ロッドは regen_amount×(30 + INT補正)×(count + 10)×EATER_ROD_CHARGE/(30×16×PY_REGEN_NORMAL) ずつ残り充填時間が減る。
  • 発動失敗率は道具のレベルを基準にする。ロッドは baseitem.level×5/6-5、杖・魔法棒は baseitem.level を使い、初期値は level×4/5+20。INTによる魔法能力補正で下がり、プレイヤーレベルが level / 2 を超える分だけさらに 3×(Lv - level/2) 下がる。最低失敗率、朦朧ペナルティ、通常の魔法失敗率補正も適用され、上限は95%。
  • 強力発動 はLv10から使え、消費MPは 10+(Lv-10)/2。発動処理へ強力発動フラグを渡し、取り込んだ道具を威力を高めて使用する。

強力発動の効果

強力発動 は杖・魔法棒・ロッドの発動処理へ powerful=true を渡す。ソース上の共通変化は次の通り。

  • 魔法棒・ロッド・杖の実効レベル lev は通常時 player_ptr->lev、強力発動時 player_ptr->lev×2。この lev を使う睡眠・減速・恐怖・変化・ボルト・ボール・ロケット等は威力や抵抗判定が伸びる。
  • 魔法棒・ロッドのボール半径 rad は通常時2、強力発動時3。
  • ロッド・杖の検知半径 detect_rad は通常時 DETECT_RAD_DEFAULT、強力発動時 DETECT_RAD_DEFAULT×3/2。地図作成は通常時 DETECT_RAD_MAP、強力発動時 DETECT_RAD_MAP×3/2。

戦闘・装備上の特徴

このページでは能力値補正・技能補正・習熟度上限・称号・魔法種別は扱わない。

魔道具術師の戦闘上の特徴は、手持ちの魔法道具を消費物として使うだけでなく、「魔力の取り込み」によって職業固有のリソースへ変換し、「強力発動」で威力を高めて発動できる点にある。

取り込んだ魔法道具は取り出せないため、通常のアイテム運用とは別の判断が必要になる。
