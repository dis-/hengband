盲目耐性（TR_RES_BLIND）

← プレイヤー耐性一覧 / Resistances

概要

盲目耐性は TR_RES_BLIND に対応する耐性で、has_resist_blind() が真になると盲目状態の付与を防ぐ。状態付与本体の BadStatusSetter::mod_blindness() と set_blindness() は耐性判定を持たず、呼び出し側が has_resist_blind() を見て付与を止める。

効果

盲目状態の付与

mod_blindness() は現在値に加算して set_blindness() を呼ぶだけで、耐性による確率軽減はない。

bool BadStatusSetter::mod_blindness(const TIME_EFFECT tmp_v)
{
    return this->set_blindness(this->player_ptr->effects()->blindness().current() + tmp_v);
}

呼び出し側では、盲目耐性がある場合に付与処理を呼ばない。

if (has_resist_blind(player_ptr) || check_multishadow(player_ptr)) {
    return;
}
BadStatusSetter(player_ptr).mod_blindness(10 + randint1(monap_ptr->rlev));
条件 盲目付与
盲目耐性なし 呼び出し側の条件を満たすと付与される
盲目耐性あり 耐性チェックがある付与元では完全に防ぐ

盲目打撃ダメージ

モンスターの盲目打撃では、耐性がある場合に打撃ダメージも軽減される。

if (has_resist_blind(player_ptr)) {
    monap_ptr->damage = monap_ptr->damage * (randint1(4) + 3) / 8;
}
条件 打撃ダメージ倍率 盲目付与
盲目耐性なし 100% 10 + 1..rlev 加算
盲目耐性あり (1d4 + 3) / 8 付与されない

光・暗黒属性からの盲目

光属性と暗黒属性の副次効果でも盲目耐性が参照される。

if (!is_blind && !has_resist_lite(player_ptr) && !has_resist_blind(player_ptr)) {
    BadStatusSetter(player_ptr).mod_blindness(randint1(5) + 2);
}

go_blind &= !has_resist_blind(player_ptr);
if (go_blind) {
    BadStatusSetter(player_ptr).mod_blindness(randint1(5) + 2);
}
条件 光・暗黒由来の盲目
盲目耐性なし、かつ各属性側の条件を満たす 1d5 + 2 加算
盲目耐性あり 付与されない

罠

盲目ガス罠では、盲目耐性がない場合だけ盲目が加算される。

if (has_resist_blind(player_ptr) == 0) {
    BadStatusSetter(player_ptr).mod_blindness(randint0(50) + 25);
}
条件 盲目ガス罠
盲目耐性なし 25..74 加算
盲目耐性あり 付与されない
