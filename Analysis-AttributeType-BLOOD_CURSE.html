血の呪い / AttributeType::BLOOD_CURSE

← AttributeType 一覧

項目 内容
ID 109
enum AttributeType::BLOOD_CURSE
分類 精神・呪い / Mind or curse
プレイヤー処理 未処理（defaultでダメージ0）
モンスター処理 effect_monster_nothing()
地形処理 -
アイテム処理 -
描画色 既定色

概要

血の呪い (BLOOD_CURSE) は、悪魔領域の呪文などで用いられる特殊属性である。属性そのものによる直接効果はなく (モンスターへは effect_monster_nothing)、ダメージ処理後に一定確率でランダムな多重付随効果 (地震・純粋魔力・分解・テレポート・召喚・経験値吸収・能力値低下など) を発生させる。

モンスターへの効果

switch_effects_monster では effect_monster_nothing が呼ばれ、属性自体による特別な効果はない (視認していれば obvious を立てるのみ)。

ダメージ適用後、exe_affect_monster_by_damage (effect-monster.cpp) にて、属性が BLOOD_CURSE かつ one_in_(4) の場合に blood_curse_to_enemy (blood-curse.cpp) が呼び出される。

blood_curse_to_enemy はループ内で randint1(28) によりランダムな効果を選択し、fallthrough による連鎖判定 (各段階を抜けるのは !one_in_(6) のとき) を行う。ループ全体は最初の1回を必ず実行し、以降は one_in_(5) で継続する。主な効果は以下のとおり。

抽選値 効果 メッセージ
1-2 地震 (半径 4 + randint0(4)) 「地面が揺れた...」
3-6 純粋魔力 (MANA) 爆発、威力 Dice::roll(10,10) 「純粋な魔力の次元への扉が開いた！」
7-8 対象をテレポート (Dice::roll(10,10))、one_in_(13) で強力な召喚 「空間が歪んだ！」
9-11 分解 (DISINTEGRATE) 威力 50 「エネルギーのうねりを感じた！」
12-16 モンスターを怒らせる (aggravate_monsters) （メッセージなし）
17-18 強力な召喚 (activate_hi_summon) （メッセージなし）
19-22 モンスター召喚 (2/3でペット) （メッセージなし）
23-25 経験値吸収 (経験値保持なら1/160、なければ1/16。経験値保持時は75%で回避) 「経験値が体から吸い取られた気がする！」
26-28 / default 能力値低下 (one_in_(13)で全能力値を繰り返し低下、それ以外は1つ低下) （メッセージなし）

プレイヤーへの効果

血の呪い属性に対するプレイヤー専用の処理はなく、ダメージは 0 となる (switch_effects_player の default)。

（上記 blood_curse_to_enemy による経験値吸収・能力値低下・召喚などは、プレイヤーが術者となって敵に放った際の反動としてプレイヤー自身に及ぶ効果である）

アイテムへの効果

属性そのものによるアイテムへの効果はない。

地形への効果

属性そのものによる地形への効果はない。
