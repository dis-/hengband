極寒 / AttributeType::ICE

enum AttributeType::ICE

プレイヤー処理 effect_player_icee()
モンスター処理 effect_monster_icee_bolt()
地形処理 effect-feature.cpp で参照
アイテム処理 effect-item.cpp で参照
描画色 0x01

概要

極寒属性（AttributeType::ICE）は、鋭く冷たい氷塊による攻撃属性。主な発生源は極寒のブレス、アイス・ボルトなどのボルト・ボール系呪文。冷気の性質に加え、切り傷・朦朧を伴う。

ボール系ではゼロ地点からの距離 r に応じて基礎減衰を受ける。

dam = (dam + r) / (r + 1)

モンスターへの効果

effect_monster_icee_bolt() で処理される。冷気免疫（IMMUNE_COLD）で軽減、冷気弱点（HURT_COLD）で倍打。さらに轟音耐性（RESIST_SOUND）が無ければ朦朧を付与する。

条件 メッセージ ダメージ倍率
IMMUNE_COLD 保持 「にはかなり耐性がある！」 dam /= 9
HURT_COLD 保持 「はひどい痛手をうけた。」 dam *= 2
上記以外 （なし） 等倍

朦朧付与（RESIST_SOUND 非保持時、r はゼロ地点からの距離）:

do_stun = (randint1(15) + 1) / (r + 1);

プレイヤーへの効果

effect_player_icee() で処理される。盲目時のみ「何か鋭く冷たいもので攻撃された！」と表示。

ダメージは冷気属性の cold_dam()（get_damage = cold_dam(player_ptr, dam, killer, false)）で処理される。したがって冷気免疫・冷気耐性・冷気一時耐性による軽減、腕力（STR）低下判定は cold_dam() に準じる。分身時は以下の副次効果をスキップ。

副次効果（分身でない場合）:

  • 破片耐性（has_resist_shard）が無ければ切り傷を Dice::roll(5, 8) 付与。
  • 轟音耐性（has_resist_sound）が無ければ朦朧を randnum1(15) 付与。
  • 冷気耐性・冷気一時耐性のいずれも無い、または 1/12 で、冷気免疫が無ければ inventory_damage(BreakerCold(), 3) で所持品破壊判定。
if (!has_resist_shard) mod_cut(Dice::roll(5, 8));
if (!has_resist_sound) mod_stun(randnum1(15));

アイテムへの効果

affect_item() の case AttributeType::ICE（SHARDS・FORCE・SOUND と共通）で、BreakerCold().hates() に該当する床アイテムが破壊される。

  • メッセージ: 「砕け散ってしまった！」
  • 固定・ランダムアーティファクトは「%sは影響を受けない！」で破壊されない。

地形への効果

affect_feature() では、対象が木（TREE）の場合のみ効果を持つ（冷気と共通処理）。

  • メッセージ: 「木は凍り、砕け散った。」
  • 木は 1/3 で藪（BRAKE）、それ以外で草（GRASS）へ変化する。

これ以外のダンジョン地形に対しては効果を持たない（無視される属性群に含まれる）。
