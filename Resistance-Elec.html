電撃耐性（TR_RES_ELEC）

← プレイヤー耐性一覧 / Resistances

概要

電撃耐性は TR_RES_ELEC、一時耐性は is_oppose_elec()、免疫は TR_IM_ELEC、弱点は TR_VUL_ELEC と PlayerMutationType::VULN_ELEM で判定される。電撃属性ダメージは主に elec_dam() で calc_elec_damage_rate() を通して補正される。

効果

calc_elec_damage_rate() の倍率式は酸と同じで、免疫なら 0、弱点を先に加算/乗算し、その後に通常耐性と一時耐性をそれぞれ適用する。

per = 100;
if (has_immune_elec(player_ptr)) return 0;

for each flag in has_vuln_elec(player_ptr):
    if flag == FLAG_CAUSE_MUTATION:
        per *= 2;
    else:
        per += per / 3;

if (has_resist_elec(player_ptr)) per = (per + 2) / 3;
if (is_oppose_elec(player_ptr)) per = (per + 2) / 3;
dam = dam * per / 100;
条件 効果
has_immune_elec(player_ptr) calc_elec_damage_rate() が 0 を返し、elec_dam() はダメージ 0 で終了する。
has_vuln_elec() の原因が FLAG_CAUSE_MUTATION 現在の per を 2 倍にする。
has_vuln_elec() のその他の原因 現在の per に per / 3 を加える。
has_resist_elec(player_ptr) per = (per + 2) / 3。
is_oppose_elec(player_ptr) さらに per = (per + 2) / 3。通常耐性と重複する。
!(is_oppose_elec()
!aura && !(is_oppose_elec() && has_resist_elec()) inventory_damage(player_ptr, BreakerElec(), inv)。inv は元ダメージが 30 未満なら 1、60 未満なら 2、それ以上なら 3。

一時耐性・補足

has_resist_elec() は TR_RES_ELEC の共通原因に加え、player_ptr->ult_res と has_immune_elec() も耐性原因として返す。has_immune_elec() は TR_IM_ELEC と、player_ptr->ele_immune && (player_ptr->special_defense & DEFENSE_ELEC) を見る。

is_oppose_elec() は次のいずれかで true になる。

条件
player_ptr->oppose_elec != 0
music_singing(player_ptr, MUSIC_RESIST)
PlayerClass(player_ptr).samurai_stance_is(SamuraiStanceType::MUSOU)

set_oppose_elec() は継続時間 v を 0 から 10000 に丸める。既に oppose_elec があり do_dec == false で既存値の方が大きい場合は更新しない。
