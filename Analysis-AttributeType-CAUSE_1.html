軽傷の呪い / AttributeType::CAUSE_1

← AttributeType 一覧

項目 内容
ID 94
enum AttributeType::CAUSE_1
分類 精神・呪い / Mind or curse
プレイヤー処理 effect_player_curse_1()
モンスター処理 effect_monster_curse_1()
地形処理 effect-feature.cpp で参照
アイテム処理 -
描画色 0x0E

概要

軽傷の呪い（CAUSE_1）は対象を指差して呪いをかけ、ダメージを与える属性。モンスターへは抵抗判定に成功されるとダメージ0となる。プレイヤーへは反射判定に成功すると無効化され、失敗すると装備が呪われた上でダメージを受ける。地形・アイテムには効果を及ぼさない。

モンスターへの効果

呪いをかけるメッセージ（プレイヤーが術者の場合）：

「%sを指差して呪いをかけた。」

抵抗判定

randint0(100 + 術者レベル / 2) < モンスターレベル + 35

成立時（抵抗）：

「には効果がなかった。」

ダメージ0。抵抗されなければ与えられたダメージがそのまま通る（switcher 側でのダメージ増減はなく、抵抗判定のみを行う）。

プレイヤーへの効果

反射判定：

randint0(100 + rlev / 2) < skill_sav  かつ  影分身でない

成立時：

「しかし効力を跳ね返した！」

失敗した場合：

  • 影分身でなければ装備を呪う curse_equipment(player_ptr, 15, 0)（呪い発生率15）
  • ダメージ（take_hit）を受ける

アイテムへの効果

なし（affect_item に CAUSE_1 の分岐は存在しない）。

地形への効果

なし（affect_feature では「Ignore most effects」に分類される）。
