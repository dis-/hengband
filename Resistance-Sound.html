轟音耐性（TR_RES_SOUND）

← プレイヤー耐性一覧 / Resistances

概要

轟音耐性は TR_RES_SOUND を中心に、has_resist_sound() と calc_sound_damage_rate() で参照される。轟音属性ダメージを乱数倍率で軽減し、轟音・プラズマ・水流・フォース・ロケット・重力・冷気破片系の朦朧付与条件にも関係する。

効果

ダメージ倍率は calc_sound_damage_rate() の per で計算され、最終ダメージは dam * per / 100 になる。

per = 100;
if (has_resist_sound(player_ptr)) {
    per \*= 500;
    per /= randrate(4, 7, mode);
}

CALC_RAND の randrate(4, 7, mode) は randint1(4) * 100 + 7 * 100。耐性ありの倍率は 50000 / (800..1100)、すなわち 45%..62% 相当になる。

条件 効果
has_resist_sound() per *= 500; per /= randrate(4, 7, mode)

轟音属性の副次効果は effect_player_sound() で処理される。

if (!has_resist_sound(player_ptr) && !check_multishadow(player_ptr)) {
    plus_stun = randnum1<short>((ep_ptr->dam > 90) ? 35 : (ep_ptr->dam / 3 + 5));
    BadStatusSetter(player_ptr).mod_stun(plus_stun);
}
if (!has_resist_sound(player_ptr) || one_in_(13)) inventory_damage(player_ptr, BreakerCold(), 2);
条件 効果
!has_resist_sound() かつ !check_multishadow() かつ dam > 90 randnum1(35) の朦朧を加算
!has_resist_sound() かつ !check_multishadow() かつ dam <= 90 randnum1(dam / 3 + 5) の朦朧を加算
!has_resist_sound() または one_in_(13) BreakerCold() で強度 2 のインベントリ破壊

轟音耐性は他属性の朦朧付与にも使われる。

処理 条件 効果
effect_player_plasma() !has_resist_sound() かつ !check_multishadow() かつ dam > 40 randnum1(35) の朦朧
effect_player_plasma() !has_resist_sound() かつ !check_multishadow() かつ dam <= 40 randnum1(dam * 3 / 4 + 5) の朦朧
effect_player_water() !has_resist_sound() かつ !has_resist_water() かつ !check_multishadow() randnum1(40) の朦朧
effect_player_force() !has_resist_sound() かつ !check_multishadow() randnum1(20) の朦朧
effect_player_rocket() !has_resist_sound() かつ !check_multishadow() randnum1(20) の朦朧
effect_player_gravity() !(has_resist_sound()
effect_player_gravity() !(has_resist_sound()
effect_player_icee() !has_resist_sound() かつ !check_multishadow() randnum1(15) の朦朧

一時耐性・補足

has_resist_sound() は通常耐性に加えて ult_res を耐性要因に含める。

result = common_cause_flags(player_ptr, TR_RES_SOUND);
if (player_ptr->ult_res) result |= FLAG_CAUSE_MAGIC_TIME_EFFECT;
