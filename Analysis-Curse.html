呪い

← 解析 / Analysis

概要

「呪い」は装備品に付随する負の特性であり、装備している間だけプレイヤーに悪影響を及ぼす。呪いには大きく分けて以下の2系統がある。

  • 呪いの重さ（CURSED / HEAVY_CURSE / PERMA_CURSE）: 呪いの強さと解呪のしにくさを表す段階。
  • 呪いの効果（TY_CURSE、DRAIN_EXP、TELEPORT など）: 実際に発揮される個別の悪影響。

これらは装備品ごとに curse_flags として保持され、内部的には列挙型 CurseTraitType（旧称 TRC_*）で管理される。呪い効果の一部はターン経過ごとに確率で発動し、一部は装備している間ずっと常時ステータスに影響する。

呪いの重さ（3段階）

段階 内部フラグ 解呪の可否
軽い呪い CURSED 「解呪」（弱）で解除可能
重い呪い HEAVY_CURSE 「解呪」（弱）では解除不可。「解呪」（強）で解除可能
永遠の呪い PERMA_CURSE どの解呪でも解除できない

重い呪いが付いている装備は、各呪い効果の悪影響が強化される（発動確率の上昇や効果量の増大など。後述）。

呪い効果の一覧

以下は個別の呪い効果フラグ（CurseTraitType）と、ソースで確認できる効果である。憶測を避けるため、数値はソースに明記されている値のみを記載する。

ターン経過で確率発動する呪い

呪い効果の発動判定は、10ゲームターン（1 tick）ごとに execute_cursed_items_effect → occur_curse_effects で行われる（src/world/world-turn-processor.cpp の process_world、src/inventory/inventory-curse.cpp）。フェイズアウト中・広域マップ移動中は判定されない。以下の確率はいずれもこの1 tickあたりのもの（one_in_(N) は 1/N の確率）。

呪いの付加

curse_equipment（src/object-enchant/object-curse.cpp）が装備品への呪い付加を担う。処理の流れは以下の通り。

  1. randint1(100) > chance なら何もしない（chance は呼び出し側が指定する基本確率）。
  2. 対象は装備スロットのうち INVEN_MAIN_HAND + randint0(12) でランダムに1つ選ばれる。
  3. 対象が TR_BLESSED（祝福）を持つ場合、呪いを跳ね返して終了する。
  4. randint1(100) <= heavy_chance かつ対象がアーティファクトまたはエゴの場合、HEAVY_CURSE + CURSED を付与（呪い強度 +1）。そうでなければ CURSED のみ付与。
  5. heavy_chance >= 50 の場合、呪い強度をさらに +1。
  6. get_curse(呪い強度, 装備) で個別の呪い効果を1つ抽選して付与。

付加される呪い効果の抽選（get_curse）

get_curse(power, o_ptr) は付加する呪い効果を抽選する。抽選範囲は TY_CURSE から MAX-1 まで。power（呪い強度）によって候補が絞られる。

  • power == 2（重い呪い相当）: 重い呪いマスク（TRC_HEAVY_MASK）に含まれる呪いのみを抽選。
  • power == 1（特殊呪い除外）: 特殊呪いマスク（TRC_SPECIAL_MASK = TY_CURSE, AGGRAVATE）を除いて抽選。
  • power == 0（軽い呪い相当）: 重い呪いマスクに含まれる呪いを除いて抽選。

TRC_HEAVY_MASK（重い呪い候補）: TY_CURSE, AGGRAVATE, DRAIN_EXP, ADD_H_CURSE, CALL_DEMON, CALL_DRAGON, CALL_UNDEAD, TELEPORT。

さらに、LOW_MELEE は武器にのみ、LOW_AC は防具にのみ付加される（条件を満たさなければ再抽選）。

呪いの除去

解呪処理は exe_curse_removal（src/spell-kind/spells-curse-removal.cpp）で行われ、装備スロットを走査して呪いを外す。

  • remove_curse（弱い解呪 / all=false）: HEAVY_CURSE を持つ装備はスキップする（重い呪いは解除できない）。
  • remove_all_curse（強い解呪 / all=true）: 重い呪いも含めて解除する。
  • PERMA_CURSE（永遠の呪い）: どちらの解呪でも解除不可。curse_flags は CURSED・HEAVY_CURSE・PERMA_CURSE の3つだけを残して個別効果フラグは除去されるが、呪い自体は装備に残り続ける。
  • 解呪に成功したアイテムがあると「誰かに見守られているような気がする。」というメッセージが表示され、解呪した装備数が返る。

その他

  • 特定の光源アーティファクト『審判の宝石』（FixedArtifactId::JUDGE）を装備している場合、呪い効果とは別枠で 1/999 の確率で体力吸収（min(レベル, 50) ダメージ）が発生する。反魔法状態では発生せず、呪い耐性があると 1/2 の確率で回避される（execute_cursed_items_effect 末尾）。
