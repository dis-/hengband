加速内部値

← 解析 / Analysis

概要

変愚蛮怒における「速度(スピード)」は、画面に表示される加速値(+10、-5 など)とは別に、内部では 110 を標準速度(加速0) とした整数値で管理されている。この内部値を src/system/gamevalue.h では次のように定義している。

constexpr auto STANDARD_SPEED = 110; /* プレイヤー/モンスターの標準速度 (加速0) */

つまり画面表示の加速値と内部速度値の関係は次の通り。

内部速度 = 110 + 表示加速値
  • 加速0 → 内部速度 110
  • 加速+10 → 内部速度 120
  • 加速-10 → 内部速度 100

行動の仕組み: エネルギー蓄積モデル

変愚蛮怒では、キャラクターは毎「ゲームターン」ごとに速度に応じた量の 行動エネルギー を蓄え、蓄積量が一定の閾値(100 単位)に達すると1回行動できる。速度が速いほど1ゲームターンあたりに蓄えるエネルギーが多くなり、結果として行動回数が増える。

プレイヤーの処理では、内部速度から得たエネルギーを energy_need(次の行動までに必要な残エネルギー)から差し引いていく(src/core/player-processor.cpp)。

player_ptr->energy_need -= speed_to_energy(player_ptr->pspeed);
// ...
if (player_ptr->energy_need > 0) {
    return; // まだ行動できない
}

モンスターも同じ方式で処理される(src/monster/monster-processor.cpp)。

monster.energy_need -= speed_to_energy(speed);
if (monster.energy_need > 0) {
    continue; // まだ行動できない
}

energy_need が 0 以下になったとき初めて行動でき、行動すると消費エネルギー(通常行動で 100 単位相当)が再び energy_need に加算される。

加速→エネルギー変換 (speed_to_energy)

1ゲームターンあたりに蓄えるエネルギー量(ETA: Energy per Turn / Amount)は、内部速度値をインデックスとする変換テーブル extract_energy[] から求められる(src/core/speed-table.cpp)。

byte speed_to_energy(byte speed)
{
    return speed > 199 ? 49 : extract_energy[speed];
}

このテーブルは元々、次の関数を離散化したものである(ソース内コメントより)。

基本関数: (S >= 110) ? (S - 110) : (100 / (120 - S))

ただし高速域ではこの関数そのままではなく、テーブルが調整されている。加速+30 を超えると増加が鈍り、1行動あたり 最大 50 エネルギー(実際のテーブル上限値は 49)に漸近する。

加速+10 で行動回数が約2倍になる理由

標準速度(内部110)では 1ゲームターンあたり 10 エネルギー、加速+10(内部120)では 20 エネルギーを蓄える。閾値は同じ 100 単位なので、必要ゲームターン数は

  • 加速0: 100 ÷ 10 = 10 ゲームターン/行動
  • 加速+10: 100 ÷ 20 = 5 ゲームターン/行動

となり、加速+10 ごとに 1行動あたりに要するゲームターンがおよそ半分、すなわち 行動回数が約2倍 になる。ただしこの「+10で2倍」の関係が成り立つのは、テーブルが線形に増える標準〜加速+20付近の範囲であり、高速域では鈍化する。

消費エネルギー側の乱数

上記は「蓄積」側の速度依存量である。行動時に energy_need へ加算される消費エネルギー(通常行動)は固定 100 ではなく、正規乱数で揺らぐ(src/core/speed-table.h)。

/*! 消費する行動エネルギー値を正規乱数で返す(中央100/分散25) */
#define ENERGY_NEED() (randnor(100, 25))

実際のプレイヤー行動処理では、行動の種類ごとの基礎消費 energy_use にこの乱数を掛け合わせて energy_need に反映する(src/core/player-processor.cpp)。

player_ptr->energy_need += (int16_t)((int32_t)player_ptr->energy_use * ENERGY_NEED() / 100L);

したがって「通常1回の行動 ≒ 100 エネルギー消費」を基準としつつ、実際の消費は平均100・標準偏差25の正規分布でばらつく。この乱数化により、同じ速度差でも行動順が完全に固定化されず揺らぎが生じる。

速度が影響するその他の処理

speed_to_energy は行動頻度以外にも、速度に比例する各種処理の重み付けに流用されている。

  • 満腹度(消化)の減少量 — 速いほど多く消化する(src/player/digestion-processor.cpp)。
  • モンスターの覚醒判定量 — プレイヤーの速度に比例(src/monster/monster-status.cpp)。
  • モンスター撃破時の経験値計算 — モンスター/プレイヤー速度を分母・分子に使用(src/monster/monster-damage.cpp)。

まとめ

  • 内部速度 = 110 + 表示加速値(STANDARD_SPEED = 110)。
  • 1ゲームターンあたり extract_energy[内部速度] エネルギーを蓄積し、100 単位ごとに1行動する。
  • 標準〜加速+20付近では ETA が内部速度1あたり約1ずつ線形に増え、加速+10で行動回数が約2倍になる。
  • 加速+30 以降は増加が鈍化し、内部速度180(表示+70)以上で ETA は上限の 49 に張り付く。それ以上の加速は、重い装備などによる実効速度低下の相殺以外にはほぼ意味がない。
