精神攻撃 / AttributeType::PSI

← AttributeType 一覧

項目 内容
ID 85
enum AttributeType::PSI
分類 精神・呪い / Mind or curse
プレイヤー処理 未処理（defaultでダメージ0）
モンスター処理 effect_monster_psi()
地形処理 effect-feature.cpp で参照
アイテム処理 -
描画色 0x09

概要

サイキック攻撃（PSI）は対象の精神を直接攻撃する属性。モンスターに対しては視線（LOS）が通っていないと無効となり、精神の性質によって完全耐性・軽減・跳ね返しが発生する点が特徴。跳ね返された場合は術者（プレイヤー）自身がダメージと各種状態異常を受ける。地形・アイテムには効果を及ぼさない。

モンスターへの効果

視線判定

術者とモンスターの間に視線（LOS）が通っていない場合、効果は完全に無効。

「%sはあなたが見えないので影響されない！」

耐性判定（順に評価）

条件 結果
EMPTY_MIND（精神を持たない）を持つ 完全耐性。ダメージ0。「には完全な耐性がある！」
STUPID / WEIRD_MIND / ANIMAL のいずれか、またはレベル > d(3×ダメージ) 耐性。ダメージ 1/3。「には耐性がある！」

耐性を発動した（＝上記の軽減が起きた）モンスターのうち、以下をすべて満たすと跳ね返し（バックラッシュ）が発生する。

  • UNDEAD または DEMON（堕落した精神）である
  • レベル > 術者レベル / 2
  • 1/2 の確率

「%sの堕落した精神は攻撃を跳ね返した！」

跳ね返し時のプレイヤーへの反射（下記「プレイヤーへの効果」参照）

追加効果（ダメージが通った場合）

ダメージが1以上で、かつ 1/4 の確率で以下のいずれかが発生（各耐性は無視される）。

抽選(1/4) 効果
1 混乱 3 + d(ダメージ)
2 朦朧 3 + d(ダメージ)
3 恐怖 3 + d(ダメージ)
4 睡眠 3 + d(ダメージ)。「は眠り込んでしまった！」

死亡時メッセージ

「の精神は崩壊し、肉体は抜け殻となった。」

プレイヤーへの効果

PSI 属性がプレイヤーに向かう独立した処理は存在しない（switch_effects_player に PSI の分岐は無く、default でダメージ0）。プレイヤーが PSI ダメージを受けるのは、モンスターが攻撃を跳ね返した場合の反射としてのみ。

跳ね返し発生後、まずプレイヤー側の反射判定：

randint0(100 + モンスターレベル / 2) < skill_sav  かつ  影分身でない

成立時：

「しかし効力を跳ね返した！」

ダメージ0で終了。失敗した場合はダメージを受ける（take_hit）。さらに 1/4 の確率かつ影分身でない場合、追加効果：

抽選(1/4) 効果
1 混乱 3 + d(ダメージ)
2 朦朧 d(ダメージ)
3 恐怖 3 + d(ダメージ)（NO_FEAR モンスターの反射時は「には効果がなかった。」で無効）
4 麻痺 d(ダメージ)（自由行動があれば無効）

アイテムへの効果

なし（affect_item に PSI の分岐は存在せず、アイテムには影響しない）。

地形への効果

なし（affect_feature では PSI は「Ignore most effects」に分類され、地形を変化させない）。
