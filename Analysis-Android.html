アンドロイドのレベル

← 解析 / Analysis

概要

アンドロイド種族は、他の種族と異なり「敵を倒して得た経験値」ではレベルが上がりません。アンドロイドのレベルは、現在身に付けている装備品の価値（金銭価値） から算出した疑似経験値によって決定されます。強力・高価な装備を身に付ければレベルが上がり、外せば下がります。

この解説は src/racial/racial-android.cpp の calc_android_exp() 関数と、src/player/player-status.cpp の check_experience()、および src/player/player-status-table.cpp の経験値テーブル player_exp_a に基づきます。

全体の流れ

装備の各スロットについて、以下の手順で寄与経験値を求め、合計して疑似経験値 total_exp を得ます。その total_exp を経験値としてセットし、通常のレベル判定処理でレベルを決定します。

1. 装備スロットを1つずつ調べる
2. 対象外スロット（指輪・首・光源）はスキップ
3. アイテム由来の「レベル値」level を計算する
4. アイテムの「実売価値」value を計算する（割引・呪いは無視）
5. level と value から寄与経験値 exp を計算する
6. スロット種別に応じた分母で割って total_exp に加算する
7. total_exp を経験値とし、経験値テーブルでレベルを決定する

対象となる装備スロット

計算対象は装備スロット全体（INVEN_WIELDING_SLOTS）を走査しますが、次のスロットは明示的に計算から除外されます。

スロット 内部名 アンドロイドのレベルへの影響
利き手 INVEN_MAIN_HAND あり
逆手 INVEN_SUB_HAND あり
射撃 INVEN_BOW あり
利き手指（指輪） INVEN_MAIN_RING なし（除外）
逆手指（指輪） INVEN_SUB_RING なし（除外）
首 INVEN_NECK なし（除外）
光源 INVEN_LITE なし（除外）
体 INVEN_BODY あり（さらに追加ボーナスあり）
体の上（クローク等） INVEN_OUTER あり
頭 INVEN_HEAD あり
腕（盾等） INVEN_ARMS あり
脚（靴等） INVEN_FEET あり

つまり、指輪・アミュレット（首）・光源はアンドロイドのレベルに一切影響しません。

また、装備の割引率（discount）と呪い（curse_flags）はレベル計算に影響しません。計算時にはこれらを取り除いたクローンを用いて価値を算出します。

アイテムの「レベル値」level の計算

各アイテムについて、まずベースとなるレベル値を次のように定めます。ベースアイテムのレベル（get_baseitem_level()）から8を引いた値と1の大きい方を取ります。

level = max(ベースアイテムのレベル - 8, 1)

この後、アイテムの種別（固定アーティファクト／エゴ／ランダムアーティファクト）に応じてレベル値が補正されます。

固定アーティファクトの場合

level = (level + max(アーティファクトのレベル - 8, 5)) / 2
level += min(20, アーティファクトのレア度 / X)

ここで X は、そのアーティファクトが「一点物生成（INSTA_ART）」フラグを持つなら 10、そうでなければ 3 です。

エゴアイテムの場合

level += max(3, (エゴの rating - 5) / 2)

ランダムアーティファクトの場合

付与された能力フラグの総コスト（flag_cost）から仮のレベル fake_level を求め、それを使ってレベル値を補正します。fake_level の閾値は、武器・弾（is_weapon_ammo）かどうかで異なります。

武器・弾以外の場合:

フラグ総コスト total_flags fake_level
15000 未満 10
15000 以上 35000 未満 25
35000 以上 40

武器・弾の場合:

フラグ総コスト total_flags fake_level
20000 未満 10
20000 以上 45000 未満 25
45000 以上 40

補正式:

level = max(level, (level + max(fake_level - 8, 5)) / 2 + 3)

ドラゴン装甲・カードによるレベル半減

アイテム種別（tval）がドラゴン装甲（DRAG_ARMOR）またはカード（CARD）の場合、レベル値を半分にします。

level /= 2

アイテムの「価値」value の計算

割引と呪いを取り除いたクローンについて、実売価値 object_value_real() を求めます。ここで value が0以下ならそのスロットは加算対象外（continue）です。

その後、次の補正が入ります。

危ない水着の特例

アイテムが「危ない水着」（SOFT_ARMOR の SV_ABUNAI_MIZUGI）で、かつプレイヤーの性格が「セクシー（PERSONALITY_SEXY）」でない場合、価値を 1/32 にします。

value /= 32

価値の上限

value は 5,000,000 で頭打ちになります。

if (value > 5000000) value = 5000000

寄与経験値 exp の計算

exp の計算式は、アイテムが「価値の高い特別な装備」か「通常の装備」かで分岐します。

「特別な装備」と判定されるのは、次のいずれかに該当する場合です。

  • 固定アーティファクトまたはランダムアーティファクト
  • エゴアイテム
  • ドラゴン装甲、またはドラゴン系の防具（ドラゴンの兜 SV_DRAGON_HELM、ドラゴンの盾 SV_DRAGON_SHIELD、ドラゴンの籠手 SV_SET_OF_DRAGON_GLOVES、ドラゴンの具足 SV_PAIR_OF_DRAGON_GREAVE）
  • ダイヤモンドエッジ（SWORD の SV_DIAMOND_EDGE）

特別な装備の場合

まず、レベル値が大きいほど伸びが鈍化するよう、level を段階的に圧縮します。

if      (level > 65) level = 35 + (level - 65) / 5
else if (level > 35) level = 25 + (level - 35) / 3
else if (level > 15) level = 15 + (level - 15) / 2

その後、次式で exp を求めます（level の2乗に比例）。

exp = min(100000, value) / 2 * level * level
if (value > 100000) {
    exp += (value - 100000) / 8 * level * level
}

通常の装備の場合

こちらは level の1乗に比例します。

exp = min(100000, value) * level
if (value > 100000) {
    exp += (value - 100000) / 4 * level
}

スロット種別による割り引きと合算

求めた exp を、スロットの種類に応じた分母で割ってから total_exp に加算します。

条件 分母
利き手／逆手に近接武器を装備、または射撃スロット 48
それ以外のスロット 16 
（近接武器を持つ利き手・逆手、または射撃スロット）
    total_exp += exp / 48
（それ以外）
    total_exp += exp / 16

さらに、体（INVEN_BODY）スロットには追加ボーナスがあり、上記に加えて次が足されます。

if (スロット == INVEN_BODY) {
    total_exp += exp / 32
}

経験値からレベルへの変換

全スロットの寄与を合計した total_exp を、アンドロイドの経験値および最大経験値としてセットし、check_experience() でレベルを判定します。

player_ptr->exp = player_ptr->max_exp = total_exp;
check_experience(player_ptr);

レベル判定では、アンドロイド専用の経験値テーブル player_exp_a が用いられます。次レベルへの必要経験値には、種族の経験値修正 expfact（アンドロイドは 200）が掛かります。レベルが上がる条件は次の通りです。

現在の経験値 >= player_exp_a[レベル - 1] * expfact / 100

expfact が 200 なので、アンドロイドはテーブル値の2倍の経験値が各レベルで必要になります。

上限レベル

プレイヤーの最大レベルは PY_MAX_LEVEL（50）で、アンドロイドも同様に レベル50が上限 です。レベル判定ループの継続条件に player_ptr->lev < PY_MAX_LEVEL が含まれるため、これを超えてレベルが上がることはありません。

まとめ

  • アンドロイドのレベルは、装備品の実売価値から算出した疑似経験値で決まる。
  • 指輪・首（アミュレット）・光源は影響しない。
  • 割引・呪いは影響しない。
  • 武器（近接・射撃）は寄与が小さく（分母48）、防具は寄与が大きい（分母16）。
  • 体スロットのみ追加ボーナス（さらに exp/32 を加算）がある。
  • アーティファクト・エゴ・ドラゴン系防具・ダイヤモンドエッジは、level の2乗に比例する式で計算され、高価値ほど大きな経験値になる。
  • 各アイテムの価値は 5,000,000 で頭打ち。
  • 必要経験値はアンドロイド専用テーブル player_exp_a に expfact = 200（=2倍）を掛けた値。
  • 上限は他種族と同じレベル50。
