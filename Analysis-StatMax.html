能力の最大値

← 解析 / Analysis

概要

変愚蛮怒には腕力(STR)・知能(INT)・賢さ(WIS)・器用さ(DEX)・耐久力(CON)・魅力(CHR)の6種類の基本能力値があります。これらは画面上では 18/100 のように表示されますが、内部的には単一の整数値として保持されており、「18/xx」という独特の表記は連続した整数を人間に読みやすい形へ変換したものです。

このページでは、能力値の内部表現、表示形式との対応、そして能力値ごとに定まる上限値(能力の最大値)の仕組みを解説します。

内部表現と「18/xx」表記

能力値は short(16bit符号付き整数)として保持されます(src/system/player-type-definition.h)。内部値と表示の対応は次のとおりです。

  • 内部値 3〜18 は、そのまま 3〜18 と表示されます。
  • 内部値 19以上 は 18 を超えた分を「18/xx」として表示します。具体的には、内部値から18を引いた値(bonus)を用いて 18/bonus と表示します。

したがって、

  • 内部値 19 → bonus 1 → 18/01
  • 内部値 28 → bonus 10 → 18/10
  • 内部値 118 → bonus 100 → 18/100
  • 内部値 238 → bonus 220 → 18/220

という対応になります。表示処理は cnv_stat()(src/player/player-status.cpp)が担当しており、以下のように分岐します。

  • 内部値が18以下: そのまま数値を表示
  • bonus が100未満: 18/%02d 形式(例: 18/70)
  • bonus が100以上220未満: 18/%03d 形式(例: 18/150)
  • bonus が220以上: 18/*** と表示

つまり bonus 220(内部値238)以上はすべて 18/*** と表示され、それ以上の細かい数値は画面上では区別されません。

能力値の増減単位

能力値は「18未満は1刻み、18以上は10刻み(1/10単位)」で増減します。この変換は modify_stat_value()(src/player/player-status.cpp)や adjust_stat()(src/birth/birth-stat.cpp)で行われます。

  • 増加時: 内部値が18未満なら +1、18以上なら +10
  • 減少時: 内部値が 18+10(=28、すなわち18/10)以上なら -10、18より大きく28未満なら18へ、18以下なら -1(下限は3)

このため能力値の上昇系列は原則として次のようになります。

3, 4, ..., 17, 18, 18/10, 18/20, ..., 18/220

ただし種族・職業・性格などによる補正が「18/xx」の1の位に端数として残る場合があり、その場合は次のような系列になります。

18/13, 18/23, 18/33, ..., 18/220

なお、能力回復ポーション等による内部値そのものの上昇(inc_stat())は端数を持たない10刻みですが、この端数はソース内コメントにも記載されている仕様です。

内部整数と処理用インデックス(0〜37)

戦闘・魔法などの各種計算では、能力値そのものではなく 0〜37の整数インデックス(stat_index)へ圧縮した値が使われます。変換は update_index_status()(src/player-status/player-basic-statistics.cpp)で行われます。

  • 内部値が18以下: インデックス = 内部値 − 3(つまり 3→0 … 18→15)
  • 内部値が18より大きく 18+219(=237)以下: インデックス = 15 + (内部値 − 18) / 10
  • 内部値が 18+219 を超える場合: インデックス = 37(固定)

この結果、adj_str_th[] や adj_con_mhp[] などの補正テーブル(src/player/player-status-table.cpp)は次のように索引されます。各テーブルの末尾要素は 18/220+ に対応しており、コメント上も明記されています。

  • インデックス0〜15: 内部値3〜18(18/00-18/09)
  • インデックス16以降: 18/10-18/19, 18/20-18/29 … と10刻み
  • インデックス36: 18/210-18/219
  • インデックス37: 18/220+

すなわち 各種計算上の能力値の効果は 18/220 以上ですべて頭打ちになります。表示・内部値がそれ以上に達していても、戦闘・魔法などへの寄与は 18/220 の場合と同じです。

能力の最大値(stat_max_max)

能力値には、キャラクターごと・能力ごとに固定された上限値が設定されています。これが「能力の最大値」であり、stat_max_max[] として保持されます。この値はキャラクター生成時(および新生の薬・能力シャッフル時)に get_max_stats()(src/birth/birth-stat.cpp)で決定されます。

決定式は次のとおりです。6能力それぞれに dice[i] = randint1(7)(1〜7の乱数)を割り当て、6能力の合計がちょうど24になるまで振り直します。その上で各能力の最大値は次式で計算されます。

stat_max_max = 18 + 60 + dice * 10

dice は1〜7なので、1つの能力の最大値が取りうる範囲は次のようになります。

  • dice = 1: 内部値 88 → 18/70
  • dice = 2: 内部値 98 → 18/80
  • dice = 3: 内部値 108 → 18/90
  • dice = 4: 内部値 118 → 18/100
  • dice = 5: 内部値 128 → 18/110
  • dice = 6: 内部値 138 → 18/120
  • dice = 7: 内部値 148 → 18/130

したがって 1つの能力の素の最大値(stat_max_max)は 18/70 から 18/130 の範囲で決まります。6能力の dice の合計は常に24なので、平均は dice=4(=18/100)となり、ある能力を高くすれば別の能力の上限が下がるトレードオフになります。

この stat_max_max は、能力回復ポーションなどによる能力上昇の上限として機能します。inc_stat()(src/status/base-status.cpp)は現在値が stat_max_max に達している場合は上昇せず、stat_max_max − 1 を超えないように上昇量を調整します(最後の1点は別処理で上限まで到達可能)。

なお、能力の最大値そのものは「自分自身に関する情報」画面で 18/xx 形式で確認できます(src/view/display-self-info.cpp。表示は stat_max_max − 18 を用いる)。キャラクターシート上では、ある能力が最大値に達すると ! マーカーが表示されます(src/view/display-player.cpp など)。

種族・職業・性格による補正と最終的な能力値

画面に表示され、実際の計算に使われる能力値(stat_use / stat_top)は、素の能力値(stat_cur / stat_max)に 種族補正(r_adj)・職業補正(c_adj)・性格補正(a_adj)・装備補正などの合計(stat_add) を modify_stat_value() で加算したものです(src/player-status/player-basic-statistics.cpp)。

ここで重要なのは、stat_max_max はあくまで素の能力値(自然値)に対する上限である点です。種族・職業・性格・装備による補正は stat_max_max とは別に上乗せされるため、これらの補正込みの表示上・計算上の能力値は stat_max_max を超えて 18/220 付近まで到達し得ます。ただし前述のとおり、計算上の効果は 18/220(内部インデックス37)で頭打ちです。

まとめ

  • 能力値は内部的には単一の整数で保持され、3〜18 はそのまま、19 以上は「18/(内部値−18)」として表示される。
  • 18以上は10刻み(1/10単位)で増減する。
  • 表示は bonus 220(内部値238)以上ですべて 18/*** になる。
  • 各種計算には0〜37の圧縮インデックスが使われ、18/220 以上は同一(インデックス37)として扱われ効果が頭打ちになる。
  • 素の能力値の上限(能力の最大値 stat_max_max)は生成時に 18 + 60 + dice*10(dice=1〜7、6能力の合計=24)で決まり、1能力あたり 18/70〜18/130 の範囲となる。
  • 種族・職業・性格・装備の補正はこの上限とは別に加算され、補正込みの能力値は上限を超えることがある。
