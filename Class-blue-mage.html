青魔道師 / Blue-Mage

← 職業一覧 / Classes ・ 🏠 ホーム / Home

概要

青魔道師は優れた魔法使いであり、その機知によって生き延びなければなりません。メイジ等の他の魔法使いとの違いは魔法の覚え方で、青魔道師はモンスターの魔法の効果を受けることでその魔法を覚えます。覚えるためには「ラーニング」の状態になっていないといけません。魔法に必要な能力は知能です。

固有システム・特殊能力

青魔道師は、青魔法を学習して扱う職業である。青魔法はモンスターが使う魔法に対応しており、各呪文の威力の考え方は モンスターの攻撃魔法 が参考になる。

Uコマンドのレイシャル特殊能力として、青魔法の学習状態を切り替える「ラーニング」を持つ。

能力 最低Lv 消費 能力値 難度 効果
ラーニング 1 0 INT - 青魔法の学習開始/終了。学習中はMPを消費する。

戦闘・装備上の特徴

このページでは能力値補正・技能補正・習熟度上限・称号・魔法種別は扱わない。

青魔道師の固有性は、「ラーニング」で学習状態に入り、青魔法を覚える点にある。学習中はMPを消費するため、魔法の習得とMP管理が同じサブシステムに結び付いている。習得できる青魔法はモンスターの攻撃魔法に対応する（→ モンスターの攻撃魔法）。

青魔法一覧

青魔道師が習得しうる青魔法（＝モンスターの特殊能力）の一覧（src/mspell/monster-power-table.cpp の monster_powers）。難度はその呪文の基本失敗率で、ここからレベル差・能力値(知能)・装備などで増減した値が実際の失敗率になる。

独自のレベル計算: 青魔道師の呪文ダメージは、術者レベルではなく 有効レベル = プレイヤーレベル × 2 で計算される（monspell_bluemage_damage が plev * 2 を渡す）。したがって同レベルの他職より各呪文の威力が高い。ダメージ式は モンスターの攻撃魔法 に、この有効レベルを代入して求める。

威力 列はダメージの 最小値–最大値（両手武器なし・プレイヤーLv50＝有効レベル100・非powerful での計算値）。ダイスの振れ幅が範囲になる。ブレス系は術者の現在HP依存のため、HP÷N（上限C） の式で併記する（例: 火炎のブレス=HP÷3、上限1600）。- は非ダメージ呪文。
