クローン・モンスター / AttributeType::OLD_CLONE

← AttributeType 一覧

項目 内容
ID 51
enum AttributeType::OLD_CLONE
分類 モンスター制御 / Monster utility
プレイヤー処理 未処理（defaultでダメージ0）
モンスター処理 effect_monster_old_clone()
地形処理 -
アイテム処理 -
描画色 既定色

プレイヤー処理詳細

解釈

  • プレイヤー処理に固有分岐がない属性です。switch_effects_player() の default で ep_ptr->dam=0 になり、この属性単体ではプレイヤーHPダメージや状態異常は発生しません。

参照: src/effect/effect-player-switcher.cpp, src/effect/effect-player-resist-hurt.cpp, src/player/player-damage.cpp

モンスター処理詳細

解釈

  • モンスター処理は EffectMonster の dam、状態量、表示メモ、学習フラグを調整する段階です。ここで変化した値が後続の実HP減少や状態付与に使われます。

参照: src/effect/effect-monster-switcher.cpp と各 effect_monster_* 実装。

地形処理詳細

解釈

  • この属性では地形への固有変化はほぼありません。木への共通属性反応を除き、床・壁・ドアなどはそのまま残ります。

参照: src/effect/effect-feature.cpp

アイテム処理詳細

解釈

  • この属性では床上アイテムへの固有処理はありません。投射が通っても、アイテム破壊・識別・復活などは起きません。

参照: src/effect/effect-item.cpp

処理の読み方

  • プレイヤーが効果を受ける場合は switch_effects_player() の分岐が使われます。
  • モンスターが効果を受ける場合は switch_effects_monster() の分岐が使われます。
  • 地形・アイテム欄が ○ の属性は、ダメージ以外に床/壁/ドア/罠/アイテム破壊などの副作用を持つ可能性があります。
  • 弾色は spell_color() の新グラフィック分岐から抽出しています。通常表示では gf_colors のランダム色が使われる場合があります。
