敵打撃の充填魔力吸収処理

モンスターの打撃効果 UN_POWER（充填魔力吸収）は、プレイヤーが持つ魔法棒・杖の充填魔力（チャージ、pval）を吸い取り、吸い取ったモンスター自身を回復させる打撃効果です。ここでは充填魔力の吸収量、モンスターへの回復、各種軽減、そして関連する MP 吸収打撃 DR_MANA の内部仕様を、ソースから確認できた範囲でまとめます。

対象ソース: src/monster-attack/monster-eating.cpp、src/monster-attack/monster-attack-switcher.cpp。

全体の流れ

充填魔力吸収打撃（RaceBlowEffectType::UN_POWER）が命中すると、まず打撃ダメージを軽減して適用し（calc_blow_un_power）、プレイヤーがまだ生きていて多重残像（check_multishadow）でかわしていなければ、ザックのアイテムをランダムに走査して、最初に見つかった魔法棒・杖から充填魔力を吸収します（process_un_power）。

吸収対象アイテムの走査回数

calc_blow_un_power は、ザックのスロットをランダムに選んで走査し、最初に吸収できた魔法棒・杖でループを打ち切ります。走査回数は魔道具使用能力向上フラグの有無で変わります。

魔道具使用能力向上あり: 最大 5 回走査
魔道具使用能力向上なし: 最大 10 回走査

走査対象は毎回 rand_choice(INVEN_PACK_SLOTS) で選ばれるザック内スロットで、有効なアイテムでなければその回はスキップされます。

吸収対象アイテムの条件

process_un_power は、対象アイテムが以下を満たす場合のみ吸収を行います。

  • アイテムが**魔法棒(WAND)または杖(STAFF)**であること（is_wand_staff()）。ロッド(rod)は対象外です。
  • そのアイテムの充填魔力 pval が 0 でないこと。

いずれかを満たさない場合は吸収せず（false を返す）、走査ループが続行されます。

吸収する充填魔力量（drain）

吸収量 drain は、そのベースアイテムが本来持つ充填魔力の基準値 base_pval（get_baseitem_pval()）を基準に決まります。

魔道具使用能力向上フラグの有無で式が変わります。level はモンスターのレベル（rlev）です。

魔道具使用能力向上なし:
    drain = base_pval

魔道具使用能力向上あり:
    drain = min( base_pval,
                 base_pval * level / 400 + base_pval * randint1(level) / 400 )

その後、実際に残っている充填魔力を超えないよう頭打ちされます。

drain = min(drain, o_ptr->pval)

drain が 0 以下になった場合は吸収せず終了します（false）。

つまり魔道具使用能力向上がなければ、対象アイテムのベース充填魔力ぶんを一度に吸われ（実際の残量が上限）、能力向上があると吸収量がモンスターレベル依存でおおむね一部に抑えられます。吸収量がアイテムの残チャージより少なかった場合（drain != o_ptr->pval）には「あなたの魔法を操る力がその一部を取り返した！」というメッセージが表示されます。

吸収後のアイテムの充填魔力

吸収後、対象アイテムの残り充填魔力 pval は次のように更新されます。

魔道具使用能力向上なし          → pval = 0（全部吸われる）
魔道具使用能力向上あり かつ pval==1 → pval = 0
魔道具使用能力向上あり かつ pval>1  → pval = pval - drain

魔道具使用能力向上がない場合は、残っていたチャージが全て 0 にされます。能力向上がある場合のみ、吸われた drain ぶんだけ差し引かれて一部が残ります。

吸収したモンスターの回復

吸収したモンスターは、吸い取った充填魔力に応じて HP を回復します。回復量 recovery は、吸収量 drain にそのベースアイテムのレベル（get_baseitem_level()）を掛けた値です。

recovery = drain * baseitem_level

杖(STAFF)の場合はさらにアイテム個数を掛ける:
    recovery = recovery * o_ptr->number

この回復量は、モンスターの失った HP（maxhp - hp）を超えないよう頭打ちされます。

recovery = min(recovery, maxhp - hp)
monster.hp += recovery

充填魔力吸収打撃では、モンスターの回復のみが発生します（加速などの他の強化効果はこの処理には含まれません）。

打撃ダメージ本体の軽減

calc_blow_un_power では、充填魔力吸収に伴う打撃ダメージ本体も軽減されます。基準を 1000 とし、以下のフラグがあればそれぞれ 75 を引きます（1000 分率なので、それぞれ 7.5% 減）。

damage_ratio = 1000
消費魔力減少(has_dec_mana)         → -75
呪文失敗率減少(has_easy_spell)     → -75
魔道具使用能力向上(has_magic_mastery) → -75

damage = damage * damage_ratio / 1000

3 つ全て揃うと damage_ratio = 775（22.5% 減）となります。

関連: MP 吸収打撃（DR_MANA）

DR_MANA（魔力を奪う打撃、RaceBlowEffectType::DR_MANA）は、プレイヤーの現在 MP（csp）を直接削る別の打撃効果です。処理は calc_blow_drain_mana と process_drain_mana。

ダメージ軽減

こちらは基準を 100 とし、以下のフラグがあればそれぞれ 5 を引きます（5% 減）。

damage_ratio = 100
消費魔力減少(has_dec_mana)         → -5
呪文失敗率減少(has_easy_spell)     → -5
魔道具使用能力向上(has_magic_mastery) → -5

damage = damage * damage_ratio / 100

3 つ全て揃うと damage_ratio = 85（15% 減）です。

MP 吸収の式

軽減後の damage ぶんだけ、プレイヤーの現在 MP がそのまま減らされます。

csp = csp - damage
csp < 0 のとき: csp = 0, csp_frac = 0

多重残像（check_multishadow）でかわした場合は「攻撃は幻影に命中し、あなたには届かなかった」となり MP は減りません。また、この打撃では切り傷（do_cut）が 0 に上書きされます。

このソース中の process_drain_mana では、削った MP ぶんによるモンスター側の回復処理は行われていません（充填魔力吸収 UN_POWER とは異なり、ここでは MP を減らすだけです）。
