呪力耐性（TR_RES_CURSE）

← プレイヤー耐性一覧 / Resistances

概要

呪力耐性は TR_RES_CURSE に対応する耐性で、has_resist_curse() が真になる。ソース上で確認できる主な効果は、プレイヤーのセービング値への +30 と、『審判の宝石』の周期的な生命力吸収判定の軽減である。

CAUSE_1 から CAUSE_4 の呪い属性効果本体では、has_resist_curse() による直接のダメージ倍率は確認できない。これらはプレイヤーの skill_sav による抵抗判定を行い、呪力耐性は skill_sav 計算側で +30 として効く。

効果

セービング値への補正

プレイヤーのセービング値計算で、呪力耐性があると pow += 30 される。

if (has_resist_curse(player_ptr)) {
    pow += 30;
}
条件 セービング値補正
呪力耐性なし なし
呪力耐性あり +30

呪い属性効果への抵抗

CAUSE_1 から CAUSE_3 は、セービング成功時に効果を跳ね返す。失敗時は装備呪いとダメージを受ける。

if ((randint0(100 + ep_ptr->rlev / 2) < player_ptr->skill_sav) && !check_multishadow(player_ptr)) {
    msg_print("You resist the effects!");
} else {
    curse_equipment(player_ptr, chance, heavy_chance);
    take_hit(player_ptr, DAMAGE_ATTACK, ep_ptr->dam, ep_ptr->killer);
}
効果 装備呪い確率 重い呪い確率
CAUSE_1 15% 0%
CAUSE_2 25% min(rlev / 2 - 15, 5)%
CAUSE_3 33% min(rlev / 2 - 15, 15)%

CAUSE_4 はセービング成功時に秘孔を跳ね返す。失敗時はダメージを受け、分身回避がなければ切り傷 10d10 が加算される。

if ((randint0(100 + ep_ptr->rlev / 2) < player_ptr->skill_sav)
    && (ep_ptr->m_ptr->r_idx != MonraceId::KENSHIROU)
    && !check_multishadow(player_ptr)) {
    return;
}
take_hit(player_ptr, DAMAGE_ATTACK, ep_ptr->dam, ep_ptr->killer);
BadStatusSetter(player_ptr).mod_cut(Dice::roll(10, 10));

『審判の宝石』の周期効果

呪いの周期処理では、通常は one_in_(999) に成功したときだけ『審判の宝石』の生命力吸収判定へ進む。呪力耐性がある場合は、さらに one_in_(2) に成功するとそこで処理を中断する。

if (!one_in_(999) || player_ptr->anti_magic || (one_in_(2) && has_resist_curse(player_ptr))) {
    return;
}
take_hit(player_ptr, DAMAGE_LOSELIFE, min(player_ptr->lev, 50), "the Jewel of Judgement");
条件 『審判の宝石』の吸収へ進む条件
呪力耐性なし one_in_(999) 成功、かつ反魔法なし
呪力耐性あり one_in_(999) 成功、かつ反魔法なし、かつ追加の one_in_(2) に失敗

補足: 防御能力

麻痺知らず

FREE_ACT は has_free_act() から player_ptr->free_act に反映される。麻痺攻撃では player_ptr->free_act が真なら麻痺付与前に終了する。

if (player_ptr->free_act) {
    msg_print("You are unaffected!");
    return;
}
BadStatusSetter(player_ptr).set_paralysis(3 + randint1(monap_ptr->rlev));
能力 防ぐもの
麻痺知らず 麻痺付与

経験値維持

HOLD_EXP は経験値吸収で参照される。drain_exp() では、指定された hold_exp_prob に成功すると完全に防ぎ、失敗しても通常吸収量ではなく slip だけ失う。

if (player_ptr->hold_exp && evaluate_percent(hold_exp_prob)) {
    return false;
}
if (player_ptr->hold_exp) {
    lose_exp(player_ptr, slip);
} else {
    lose_exp(player_ptr, drain);
}
条件 経験値吸収
経験値維持あり、かつ evaluate_percent(hold_exp_prob) 成功 完全に防ぐ
経験値維持あり、かつ失敗 slip だけ失う
経験値維持なし drain を失う

可視透明

SEE_INVIS は player_ptr->see_inv に反映される。透明モンスターは、通常視認可能なマスにいても see_inv がないと視認フラグが立たない。

if (monrace.misc_flags.has(MonsterMiscType::INVISIBLE)) {
    if (player_ptr->see_inv) {
        um_ptr->easy = true;
        um_ptr->flag = true;
    }
}
能力 防ぐもの
可視透明 透明モンスターを見えないままにする状態

反射

REFLECT は has_reflect() が真で、効果側に PROJECT_REFLECTABLE があり、かつ one_in_(10) でない場合にボルト系を反射する。

can_reflect = has_reflect(player_ptr) != 0;
can_reflect &= any_bits(ep_ptr->flag, PROJECT_REFLECTABLE);
can_reflect &= !one_in_(10);
条件 反射
反射あり、PROJECT_REFLECTABLE、かつ 1/10 失敗を引かない 反射する
上記以外 反射しない

浮遊

LEVITATION は player_ptr->levitation に反映される。落とし穴・落とし戸では、浮遊していると落下処理を行わない。

if (player_ptr->levitation) {
    msg_print("You fly over a trap door.");
    break;
}

地形ダメージでは、浅い地形は浮遊中に元ダメージが 0 になり、深い地形でも最終ダメージが 1/5 になる。

if (terrain.flags.has(DEEP)) {
    damage = 6000 + randint0(4000);
} else if (!player_ptr->levitation) {
    damage = 3000 + randint0(2000);
}
if (player_ptr->levitation) {
    damage /= 5;
}

深い水の溺れ判定でも、浮遊していると条件を満たさない。

if (can_drown && !player_ptr->levitation && !player_ptr->can_swim && !has_resist_water(player_ptr)) {
    ...
}
能力 防ぐもの・軽減するもの
浮遊 落とし穴・落とし戸による落下
浮遊 深い水での溺れ条件
浮遊 浅い地形ダメージを 0、深い地形ダメージを最終的に 1/5
浮遊 浅い溶岩への進入制限を満たす条件
