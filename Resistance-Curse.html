呪力耐性（TR_RES_CURSE）

← プレイヤー耐性一覧 / Resistances

概要

呪力耐性は TR_RES_CURSE に対応する耐性で、has_resist_curse() が真になる。ソース上で確認できる主な効果は、プレイヤーのセービング値への +30 と、『審判の宝石』の周期的な生命力吸収判定の軽減である。

CAUSE_1 から CAUSE_4 の呪い属性効果本体では、has_resist_curse() による直接のダメージ倍率は確認できない。これらはプレイヤーの skill_sav による抵抗判定を行い、呪力耐性は skill_sav 計算側で +30 として効く。

効果

セービング値への補正

プレイヤーのセービング値計算で、呪力耐性があると pow += 30 される。

if (has_resist_curse(player_ptr)) {
    pow += 30;
}
条件 セービング値補正
呪力耐性なし なし
呪力耐性あり +30

呪い属性効果への抵抗

CAUSE_1 から CAUSE_3 は、セービング成功時に効果を跳ね返す。失敗時は装備呪いとダメージを受ける。

if ((randint0(100 + ep_ptr->rlev / 2) < player_ptr->skill_sav) && !check_multishadow(player_ptr)) {
    msg_print("You resist the effects!");
} else {
    curse_equipment(player_ptr, chance, heavy_chance);
    take_hit(player_ptr, DAMAGE_ATTACK, ep_ptr->dam, ep_ptr->killer);
}
効果 装備呪い確率 重い呪い確率
CAUSE_1 15% 0%
CAUSE_2 25% min(rlev / 2 - 15, 5)%
CAUSE_3 33% min(rlev / 2 - 15, 15)%

CAUSE_4 はセービング成功時に秘孔を跳ね返す。失敗時はダメージを受け、分身回避がなければ切り傷 10d10 が加算される。

if ((randint0(100 + ep_ptr->rlev / 2) < player_ptr->skill_sav)
    && (ep_ptr->m_ptr->r_idx != MonraceId::KENSHIROU)
    && !check_multishadow(player_ptr)) {
    return;
}
take_hit(player_ptr, DAMAGE_ATTACK, ep_ptr->dam, ep_ptr->killer);
BadStatusSetter(player_ptr).mod_cut(Dice::roll(10, 10));

『審判の宝石』の周期効果

呪いの周期処理では、通常は one_in_(999) に成功したときだけ『審判の宝石』の生命力吸収判定へ進む。呪力耐性がある場合は、さらに one_in_(2) に成功するとそこで処理を中断する。

if (!one_in_(999) || player_ptr->anti_magic || (one_in_(2) && has_resist_curse(player_ptr))) {
    return;
}
take_hit(player_ptr, DAMAGE_LOSELIFE, min(player_ptr->lev, 50), "the Jewel of Judgement");
条件 『審判の宝石』の吸収へ進む条件
呪力耐性なし one_in_(999) 成功、かつ反魔法なし
呪力耐性あり one_in_(999) 成功、かつ反魔法なし、かつ追加の one_in_(2) に失敗
