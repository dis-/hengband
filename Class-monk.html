修行僧 / Monk

← 職業一覧 / Classes ・ 🏠 ホーム / Home

概要

修行僧は他の職業とは著しく異なる職業です。彼らは他の職業同様武器と防具を使えますが、マーシャルアーツの訓練を積んでいるため、武器、防具なしでより強力な存在となります。高レベルでは、必要な耐性を身につけるためある種の防具を装備する必要がありますが、もしあまりに重すぎる防具を装備してしまうと、その体術に深刻な妨げとなります。レベルが上がると、彼らは新しい強力な攻撃法を学び、防御能力も上昇します。魔法に必要な能力値は賢さです。

固有システム・特殊能力

修行僧は素手打撃と型を中心に戦う職業で、通常の武器攻撃とは別にマーシャルアーツ系の処理を利用する。

能力 最低Lv 消費 能力値 難度 効果
構える 25 0 DEX 0 型に構えて特殊な能力を得る。
百裂拳 30 30 STR 20 対象に対して2回の打撃を行う。

修行僧の型は stances-table.cpp の monk_stances に定義される。使用できる型は玄武、白虎、青竜、朱雀で、構える から切り替える。混乱中は選択できず、素手でなくなると型は解除される。

戦闘・装備上の特徴

素手打撃は empty_hands を条件にしたマーシャルアーツモードで処理される。マーシャルアーツは修行僧、練気術師、狂戦士が対象だが、修行僧は型と組み合わせて扱う点が固有の軸になる。

重い防具を装備している場合、素手打撃の打撃回数は半減する。重装備になると「装備が重くてバランスを取れない。」という状態通知も出る。

玄武はAC・反射・CONを得るかわりに手数を落とす。白虎はACとCONを削って強い素手技を引きやすくする。青竜はACを下げるかわりに耐性・オーラ・浮遊を得る。朱雀は手数と命中/ダメージを落として速度と浮遊を得る。

関連する戦闘技能の一般的な見方は 技能 を参照。

職業固有の耐性・能力

レベルに応じて職業から恒常的に付与される耐性・能力（src/player-base/player-class.cpp の tr_flags）。装備や一時効果とは別に、条件を満たす限り常に有効。

  • Lv10〜: 加速 +レベル/10（重い鎧を装備しておらず、他に加速源が無い時）
  • Lv25〜: 麻痺知らず（重い鎧を装備していない時）
