魔力吸収 / AttributeType::DRAIN_MANA

← AttributeType 一覧

項目 内容

enum AttributeType::DRAIN_MANA
分類 精神・呪い / Mind or curse
プレイヤー処理 effect_player_drain_mana()
モンスター処理 effect_monster_drain_mana()
地形処理 effect-feature.cpp で参照
アイテム処理 -
描画色 0x09

概要

魔力吸収 (DRAIN_MANA) は、対象から魔力 (MP) を吸収する属性である。モンスターに対しては呪文能力の有無で効果が変わり、術者がモンスターの場合は吸収分だけ術者のHPが回復する。プレイヤーに対しては MP を吸収し、術者がモンスターならその分HPが回復する。

モンスターへの効果

処理は effect_monster_drain_mana (effect-monster-spirit.cpp) で行われる。

まず対象モンスターが魔法系の能力を持つか (無魔法マスクを除いた ability_flags が残るか) を判定する。持たなければ「%sには効果がなかった。」と表示され、ダメージ 0。

魔法能力を持つ場合、術者に応じて処理が分かれる。

術者 処理
プレイヤー 「%sから精神エネルギーを吸いとった。」、hp_player(dam) でプレイヤーのHPを回復、ダメージ 0
モンスター 術者モンスターのHPが最大未満なら dam 分回復 (最大値で頭打ち)、「%s^は気分が良さそうだ。」

いずれの場合もダメージ (dam) は 0 になる。

プレイヤーへの効果

処理は effect_player_drain_mana (effect-player-spirit.cpp) で行われる。

多重影 (multishadow) の場合、「攻撃は幻影に命中し、あなたには届かなかった。」と表示され、ダメージ 0。

現在MP (csp) が 0 ならダメージ 0。それ以外の場合、以下のメッセージを表示する。

術者 メッセージ
モンスター 「%s^に精神エネルギーを吸い取られてしまった！」
その他 「精神エネルギーを吸い取られてしまった！」

MP吸収量の扱いは以下のとおり。

dam ≥ csp なら dam = csp, csp = 0
それ以外なら csp -= dam

術者がモンスターで、そのHPが最大未満の場合、吸収した dam 分だけ術者のHPが回復する (最大値で頭打ち)。回復時、術者が視認可能 (ml) なら「%s^は気分が良さそうだ。」と表示される。

アイテムへの効果

アイテムへの効果はない。

地形への効果

地形への効果はない (effect-feature.cpp で無視される属性に含まれる)。
