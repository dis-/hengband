モンスターの攻撃魔法

← 解析 / Analysis

概要

モンスターの攻撃魔法（ブレス・ボルト・ボール・呪殺など）のダメージは、src/mspell/mspell-damage-calculator.cpp の monspell_damage_base() で一元的に算出される。この関数は呪文ごとに「固定値 dam」「ダイス dice」「倍率 mult」「除数 div」を設定し、最後に monspell_damage_roll() でダメージ値を確定する。

ダメージの確定式は次の通り（TYPE により最大/最小/実ロールを切り替える）。

最大値(DAM_MAX): dam + dice.maxroll() * mult / div
最小値(DAM_MIN): dam + dice.num * 1 * mult / div
実ロール(DAM_ROLL): dam + dice.roll() * mult / div
  • dice.maxroll() は num * sides（NdM の最大出目）。
  • dice.roll() は M面ダイスを N 個振った合計。
  • 最小値はダイス各1として num（ダイス個数）を用いる。
  • 最終結果が 1 未満なら 1 に切り上げられる。

呪文の性質により、大きく2系統に分かれる。

  • ブレス系：術者の現在HPの割合をダメージとし、属性ごとの上限値でクリップする。レベル・ダイスは使わない。
  • ボルト/ボール/呪殺系：術者レベル rlev と固定値・ダイスから算出する。HPには依存しない。

ブレス系ダメージ（HP割合ベース・上限あり）

ブレスのダメージは「術者HP ÷ 除数」で、属性ごとに定めた上限を超えないようクリップされる。ダイスは用いない。

一般式は次の通り。

ダメージ = min( HP / 除数, 上限 )

実ゲーム中のブレス発動（spell_RF4_BREATH）では DAM_ROLL が渡され、術者の現在HP（monster.hp）が HP として使われる。したがってブレスは術者が傷ついていると威力が下がる。

属性別の除数と上限は以下の通り。

ロケットと特殊ブレスの注意点

  • ロケット (ROCKET)：min(HP/4, 800)。属性ブレスとは別枠だが同じくHP割合ベース。
  • 虚無 (BR_VOID)・深淵 (BR_ABYSS)：ソース上の式は dam = ((hp / 3) > 250 ? 250 : (hp / 6)); となっている。すなわち「HP/3 が 250 を超えるなら 250、そうでなければ HP/6」という判定で、上限は 250、非クリップ時の除数は 6 である（判定に使う hp/3 とダメージに使う hp/6 が異なる点に注意）。

ボルト/ボール/呪殺系ダメージ（レベル・ダイスベース）

これらは術者レベル rlev（monspell_damage() では floor 上の実効レベル）から算出される。多くは powerful（POWERFULフラグ持ちモンスター）で威力が上がる。

mult/div は整数除算であり、多くの魔法で mult = powerful ? 2 : 1、div = 1 として 固定値 * (mult / div)（= 1倍または2倍）を作る形で使われる。

呪殺・精神攻撃系

呪殺（CAUSE_*）や精神攻撃はレベル非依存の純ダイス。spell_RF5_CAUSE から DAM_ROLL で呼ばれる。

破滅の手 (HAND_DOOM)

対プレイヤー時のみ、プレイヤーの現在HPに比例する特殊式（monspell_damage() に player_ptr->chp が渡される）。

mult = プレイヤー現在HP
div  = 100
dam  = 40 * (mult / div)   ダイス = 1d20

つまり基本部分はおおよそプレイヤー現在HPの40%、加えて 1d20 相当（* mult / div を経由）が乗る。対モンスター時は式を用いずダミー値20が使われる。

悪夢モード（ironman_nightmare）での倍化

悪夢モードでのダメージ倍化は「術者HPの倍化」を通じてブレス系にのみ効く。ボルト/ボール系はレベルベースのため直接の倍化はない。

倍化が入るのは以下の2経路。

  • 実ゲームのモンスター生成時（src/monster-floor/one-monster-placer.cpp）：悪夢モードなら生成時に max_maxhp *= 2（ただし MONSTER_MAXHP = 30000 で上限クリップ）。ブレスは現在HPの割合なので、この倍化HPを通じてダメージも実質2倍になる（上限値には別途クリップされる）。
if (ironman_nightmare) {
    hp = max_maxhp * 2;
    max_maxhp = min(MONSTER_MAXHP, hp);
}
  • 種族基準のダメージ参照時（monspell_race_damage()、モンスター図鑑等の表示用）：術者HPを hit_dice.maxroll() * (ironman_nightmare ? 2 : 1) とし、min(MONSTER_MAXHP, hp) でクリップしてから計算に渡す。

いずれも「HPを2倍にしてからブレス割合式に通す」形であり、ブレスの上限値（1600, 800 等）を超えることはない。ボルト/ボール/呪殺系はHPに依存しないため、この倍化の影響を受けない。

HP・レベルの取得元（呼び出し口の違い）

同じ monspell_damage_base() を呼ぶが、HP・レベル の供給元が3系統ある。

呼び出し関数 HP レベル 用途
monspell_damage() DAM_ROLLなら現在HP(monster.hp)、他はmax_maxhp floor上の実効レベル 実ゲームの発動
monspell_race_damage() hit_dice.maxroll() * (悪夢?2:1)（MONSTER_MAXHPでクリップ） 種族レベル(最低1) 図鑑等の参照値
monspell_bluemage_damage() プレイヤー現在HP(chp) プレイヤーレベル×2、powerful=false 青魔法

このため、実ゲームのブレスは DAM_ROLL 経由で現在HP依存となり、術者が傷つくほど弱くなる点が重要である。
