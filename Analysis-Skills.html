技能・熟練度

← 解析 / Analysis

概要

変愚蛮怒の熟練度（proficiency）は、同じ武器を振り続ける・同じ呪文を唱え続けることで蓄積していく内部経験値である。画面には数値ではなく5段階のランク（[初心者]〜[達人]）で表示され、内部値そのものが命中・AC・消費MP・失敗率などの補正に直接使われる。

熟練度は3系統に分かれる。

系統 内部データ 単位
武器熟練度 weapon_exp[tval][sval] 弓(19)・掘削具(20)・鈍器(21)・長柄(22)・剣(23) の各アイテム種別（sval）ごと
技能熟練度 skill_exp[4] マーシャルアーツ（素手）・二刀流・乗馬・盾
呪文熟練度 spell_exp[64] 第1領域の呪文が 0〜31、第2領域の呪文が 32〜63

剣術家の必殺技には熟練度が無い。知識画面でも [--] と表示され、消費MPも熟練度で変化しない（spell.smana をそのまま消費する）。

ランクと閾値

ランクは内部的に5段階（PlayerSkillRank）。系統ごとに閾値が異なり、表の値はそのランクになる下限値（例: 武器熟練度4000〜5999が[入門者]）。

内部名 表示 武器・素手・二刀流・盾 乗馬 呪文
UNSKILLED [初心者] 0 0 0
BEGINNER [入門者] 4000 500 900
SKILLED [熟練者] 6000 2000 1200
EXPERT [エキスパート] 7000 5000 1400
MASTER [達人] 8000 8000 1600

上昇処理に共通する仕組み

攻撃系の熟練度（武器・素手・二刀流）は共通の処理（gain_attack_skill_exp）で上がる。

  • 現在の帯（[初心者]帯＝次の閾値未満、以下同様）ごとに決まった「1回あたりの上昇量」を加算する。次の閾値は越えない。
  • [熟練者]帯から[エキスパート]帯へ進むにはプレイヤーレベル20以上（lev > 19）が必要。この条件を満たさない間は6999で頭打ちになる。
  • [エキスパート]帯から[達人]帯へ進むにはプレイヤーレベル35以上（lev > 34）が必要。
  • 職業ごとに定められた上限（後述）に達した項目はそれ以上上がらない。

乗馬と呪文はこの共通処理を使わず、それぞれ独自の条件で上昇する（後述）。

武器熟練度

上昇の契機

系統 契機 条件
近接 1回の攻撃コマンドにつき1回（打撃回数や命中・空振りとは無関係）。主手・副手それぞれで判定される 装備が近接武器であり、対象モンスターのレベル + 10 > プレイヤーレベル
射撃 発射した矢弾がモンスターに命中したとき 対象モンスターのレベル + 10 > プレイヤーレベル

上昇するのは装備している武器と同じ分類（tval）に属する全アイテム種別で、装備中のものと同じ sval かどうかで上昇量が変わる。剣を振れば、その剣種が大きく伸び、同じ「剣」分類の他の武器種もわずかに伸びる。それぞれ自分の上限で頭打ちになる。

上昇量（1回あたり）

近接（gain_melee_weapon_exp）:

帯 装備中と同じ武器種 同じ分類の他の武器種
[初心者]帯 80 8
[入門者]帯 10 1
[熟練者]帯 1 0
[エキスパート]帯 1/2の確率で1 0

射撃（gain_range_weapon_exp）:

帯 使用中と同じ弓の種類 同じ分類の他の種類
[初心者]帯 80 8
[入門者]帯 25 2
[熟練者]帯 10 0
[エキスパート]帯 2 0

命中への効果

近接では 熟練度200につき命中修正+1、基準は[入門者]閾値の4000である。

命中修正 += (weapon_exp[tval][sval] - 4000) / 200

この命中修正（to_h）は最終的に 命中判定値 = skill_thn + (命中修正合計) × 3（BTH_PLUS_ADJ = 3）として使われる。

熟練度 ランク 命中修正
0 [初心者] -20
4000 [入門者] ±0
6000 [熟練者] +10
7000 [エキスパート] +15
8000 [達人] +20

射撃では命中判定値・会心発生率の計算に直接組み込まれる（shoot.cpp）。

  • 弓・スリング（矢・弾を使う射撃武器）: 命中判定値 = skill_thb + ((weapon_exp - 4000) / 200 + 各種修正) × 3
  • クロスボウ（ボルトを使う射撃）: 命中判定値 = skill_thb + (weapon_exp / 400 + 各種修正) × 3（4000を引かず、200ではなく400で割る）
  • 射撃武器を装備していない場合は weapon_exp[0] を弓と同じ式で使う。

同じ値が会心（射撃クリティカル）の発生判定にも使われるため、熟練度は命中率と会心率の両方に効く。

なお近接の打撃回数（num_blow）やダメージダイスには熟練度は関与しない（腕力・器用さ・職業・武器重量で決まる）。

上限の特例

上限は職業・武器種ごとに定義される（後述の一覧）が、次の上書きがある（いずれも職業がスペルマスターでない場合のみ、apply_special_weapon_skill_max_values）。

  • 性格がセクシーギャル: ムチの上限が[達人]になる。さらに生成時にムチの熟練度が[入門者]（4000）以上に底上げされる。
  • 種族がマーフォーク: トライデントと三叉槍の上限が[達人]になる。

素手（マーシャルアーツ）技能

  • 上昇の契機: 武器を装備していない手での攻撃時。対象モンスターのレベル + 10 > プレイヤーレベル のときのみ上昇する。
  • 上昇量: [初心者]帯40 / [入門者]帯5 / [熟練者]帯1 / [エキスパート]帯は1/3の確率で1。レベル条件（20/35）は武器と共通。
  • 効果: 命中修正 += (skill_exp[素手] - 4000) / 200。武器熟練度と同じ基準・同じ刻み。
    • ただしこの補正は、主手または副手の片方だけが素手の場合、騎乗中は加算されない（両手とも素手なら騎乗中でも加算される）。
  • 素手の打撃技（ma_blows 全17種）の選択や打撃回数はプレイヤーレベルと器用さで決まり、熟練度ランクには依存しない。

二刀流技能

  • 上昇の契機: 両手に近接武器を持ってモンスターを攻撃したとき、かつ (skill_exp[二刀流] - 1000) / 200 < 対象モンスターのレベル。
  • 上昇量: [初心者]帯80 / [入門者]帯4 / [熟練者]帯1 / [エキスパート]帯は1/3の確率で1。
  • 効果: 二刀流時の命中ペナルティを軽減する。
ペナルティ = (100 - skill_exp[二刀流] / 160) - (130 - 対象の手の武器重量) / 8

熟練度による軽減は skill_exp / 160＝達人で−50。武器が軽いほどペナルティも小さい。この後、以下の補正が順に適用される。

  • クイック＆タイニー／アイシング＆トゥインクル／アヌビス＆チャリオットのセット装備: ペナルティを 1/2 して更に−5
  • easy_2weapon（二刀流を容易にする装備）: 該当装備1つにつきペナルティを半減
  • 副手に TR_SUPPORTIVE 付き装備: ペナルティ−10（下限0）
  • 武蔵セット装備: ペナルティを0以下に（実質免除）
  • 対象の手が長柄（POLEARM）: ペナルティ+10

乗馬技能

閾値だけが他と異なり、[入門者]500・[熟練者]2000・[エキスパート]5000・[達人]8000（riding_skill_rank）。上昇にレベル条件（20/35）が無い代わりに、乗騎・対象モンスターのレベルとの比較で伸びる。

上昇の契機

契機 条件と上昇量
騎乗中の近接攻撃 (現在値 / 200 - 5) < 対象モンスターのレベル で+1。さらに 現在値 / 100 < 乗騎のレベル なら+1、現在値 / 100 + 15 < 乗騎のレベル のときはその差ぶん追加
騎乗中の射撃 (現在値 - 1000) / 200 < 乗騎のレベル かつ1/2の確率で+1
落馬判定時 職業の上限が1000以下なら上昇しない。(被ダメージ / 2 + 乗騎のレベル) > (現在値 / 30 + 10) のとき、現在値 / 100 + 15 < 乗騎のレベル ならその差ぶん、そうでなければ+1

効果

熟練度が効く場面は多い。

場面 式
騎乗中の命中ペナルティ ペナルティ = 乗騎のレベル - skill_exp / 80 + 30（最低30）。獣王・騎兵は矢以外で固定5。ボルト使用時は2倍。ランス装備なら逆に命中+15、TR_RIDING 付き武器はペナルティ免除
騎乗中の速度 乗騎が加速持ち（速度 > +0）なら (乗騎速度 - 110) × (skill_exp × 3 + レベル × 160 - 10000) / 22000（負なら0）。加えて常に (skill_exp + レベル × 160) / 3200 を加算
騎乗中の呪文難度 難度 += max(乗騎のレベル - skill_exp / 100 - 10, 0)
騎乗の成否 乗ろうとするモンスターのレベル > randint1(skill_exp / 50 + レベル / 2 + 20) なら乗り損なう
落馬判定 randint0(被ダメージ / 2 + 落馬レベル × 2) >= skill_exp / 30 + 10 で落馬（落馬レベル＝乗騎のレベル、両手持ち武器なら+20）
乗騎の朦朧・混乱・恐怖 毎ターン randint0(乗騎のレベル) < skill_exp なら即座に立ち直らせる
敵対した乗騎の暴走 abs(善悪値 / 10) < randint0(skill_exp) なら暴れ出さない
騎兵の「手なずけ」 randint1(skill_exp / 120 + レベル × 2 / 3) > 補正後モンスターレベル ほかの条件を満たすとペット化、失敗すると落馬

盾（防御）技能

  • 上昇の契機: 主手か副手に盾などの「protector」を装備している状態で、モンスターの物理打撃（殴る・触る・噛む・体当たり等）を回避したとき。命中してしまった打撃や、物理打撃以外では上がらない。
  • 上昇量: (現在値 / 100) < モンスターのレベル のとき 1 + max(モンスターのレベル - (現在値 / 100 + 15), 0)。格上ほど大きく伸びる。
  • 効果: protector 装備時のACに加算される。
AC += skill_exp[盾] × (1 + プレイヤーレベル / 22) / 2000
熟練度 Lv1〜21 Lv22〜43 Lv44〜50
4000 [入門者] +2 +4 +6
6000 [熟練者] +3 +6 +9
8000 [達人] +4 +8 +12

呪文熟練度

魔法領域の呪文・歌（MUSIC）・呪術（HEX）が対象。第1領域の呪文は spell_exp[0..31]、第2領域は spell_exp[32..63] に記録される。

上昇の契機と条件

詠唱するたびに上昇するが、帯ごとにダンジョンの深さの条件が付く（dlev＝現在の階層、plev＝プレイヤーレベル、slev＝呪文レベル）。町（dlev = 0）では[入門者]までしか伸びない。

帯 条件
[初心者]帯（0〜899） 無条件
[入門者]帯（900〜1199） dlev > 4 かつ dlev + 10 > plev
[熟練者]帯（1200〜1399） dlev + 5 > plev かつ dlev + 5 > slev
[エキスパート]帯（1400〜1599） dlev + 5 > plev かつ dlev > slev

上昇量は領域によって異なる。

帯 第1領域 第2領域 歌・呪術の継続詠唱（毎ターン）
[初心者]帯 60 60 5
[入門者]帯 8 8 1/2の確率で1
[熟練者]帯 2 2 1/5の確率で1
[エキスパート]帯 1 0 1/5の確率で1

第2領域の呪文は[エキスパート]（1400）が事実上の上限である（[エキスパート]帯の上昇量が0のため[達人]に到達しない）。知識画面でも第2領域は[エキスパート]で「!」（上限到達）と表示される。

再学習による熟練度の跳ね上げ

すでに覚えている呪文を魔法書からもう一度「学ぶ」と、熟練度が一段跳ね上がる（gain_spell_skill_exp_over_learning）。上限（第1領域1600 / 第2領域1400）に達している呪文は「完全に使いこなせる」として学べない。

学習前の熟練度 学習後
1400以上 1600（[達人]）
1200〜1399 第1領域は +200、第2領域は 1400
900〜1199 1200 + (現在値 - 900) × 2 / 3
0〜899 900 + 現在値 / 3

消費MPへの効果

魔法領域・技術領域の呪文は、消費MPが熟練度で変動する（mod_need_mana）。

消費MP = ceil(基本消費MP × (3800 - 熟練度) / 2400)   （最低1）

「消費魔力減少」（dec_mana）がある場合はさらに 3/4 になる。

熟練度 ランク 倍率 基本消費20MPの例
0 [初心者] ×1.583 32
900 [入門者] ×1.208 25
1200 [熟練者] ×1.083 22
1400 [エキスパート] ×1.000 20
1600 [達人] ×0.917 19

失敗率への効果

熟練度が 1400以上で失敗率−1%、1600以上でさらに−1%（合計−2%）。この減算は最低失敗率・朦朧補正・95%上限を適用した後に行われるため、結果として職業の最低失敗率を下回ることがある。

職業による特例

  • スペルマスター: exp_of_spell が常に1600を返す＝全呪文が常に[達人]扱い（生成時の初期値も1600）。
  • 赤魔道師: 常に1200＝[熟練者]扱い（初期値も1200）。
  • それ以外の職業は全呪文が0から始まる。

熟練度の確認方法

ゲーム内の「知識」コマンドから確認できる。

  • 武器の経験値（do_cmd_knowledge_weapon_exp）: 武器種ごとのランク一覧。上限に達した項目には ! が付く。射撃に使わない「進化する銃」（SV_CRIMSON）と「ハープ」（SV_HARP）は弓分類だが一覧から除外される。
  • 技能の経験値（do_cmd_knowledge_skill_exp）: マーシャルアーツ・二刀流・乗馬・盾の4種。乗馬だけ乗馬用の閾値でランク表示される。
  • 魔法の経験値（do_cmd_knowledge_spell_exp）: 領域ごとの呪文一覧。必殺技は [--]。
  • オプション「技能値等に実値を並記する」（show_actual_value、初期値ON）を有効にすると、現在値/上限 の実数値が並記される。
  • 呪文の一覧画面（詠唱時・閲覧時）にも「熟練度」列としてランクが表示される。
