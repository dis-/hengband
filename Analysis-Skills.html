技能

← 解析 / Analysis

概要

変愚蛮怒における「技能」とは、武器・弓・素手・魔法などの熟練度（proficiency）を表す内部パラメータである。同じ武器種を使い続けたり、同じ呪文を唱え続けたりすることで熟練度が経験値として蓄積し、一定の閾値を超えると抽象的な「ランク」が上昇する。ランクが上がると命中率やダメージなどに補正がかかる。

熟練度は大きく次の4系統に分けられる。

  • 武器熟練度（weapon_exp）: 近接武器および弓の各tval/svalごとに保持
  • 技能熟練度（skill_exp）: マーシャルアーツ・二刀流・乗馬・盾の4種
  • 呪文熟練度（spell_exp）: 魔法・歌・呪術の各呪文ごとに保持
  • 各系統とも、職業・武器種によって到達できる上限ランクが異なる

技能ランクと閾値

ランクは内部的に5段階（PlayerSkillRank）で表現される。系統ごとに閾値となる経験値が異なる。

ランク（内部名） 表示名 武器・技能 乗馬 呪文
UNSKILLED [初心者] 0 0 0
BEGINNER [入門者] 4000 500 900
SKILLED [熟練者] 6000 2000 1200
EXPERT [エキスパート] 7000 5000 1400
MASTER [達人] 8000 8000 1600

表の数値は、そのランクに到達するために必要な経験値の下限である（例: 武器熟練度が4000以上6000未満なら[入門者]）。

武器熟練度

ランク別の上限（職業・武器種による違い）

各職業には、武器種（tval）・武器の種類（sval）ごとに「開始ランク」と「上限ランク」が設定されている（lib/edit/ClassSkillDefinitions.txt、W:行）。上限ランクを超えて熟練度が上がることはない。

  • 例: 戦士（WARRIOR）は多くの武器で上限が[達人]（4）だが、スリング・ショートボウ・ロングボウ・クロスボウ類は上限[エキスパート]（3）に制限される。
  • 熟練度は職業ごとに大きく異なり、魔法系職業では多くの武器種が低い上限に抑えられる。

特殊な武器熟練度上限の上書き

PlayerSkill::apply_special_weapon_skill_max_values() により、以下の場合に特定武器の上限が[達人]へ引き上げられる（いずれも職業がスペルマスター(SORCERER)でない場合に限る）。

  • 性格がセクシーギャル: ムチ（HAFTED / SV_WHIP）の上限が[達人]になる
  • 種族がマーフォーク: トライデント（POLEARM / SV_TRIDENT）と三叉槍（SV_TRIFURCATE_SPEAR）の上限が[達人]になる

なおスペルマスターは全呪文が常に[達人]扱い（後述）で、武器熟練度の特例は適用されない。

熟練度上昇の契機と上昇量

近接武器での攻撃時（gain_melee_weapon_exp）と弓での射撃時（gain_range_weapon_exp）に、装備中の武器種の熟練度が増加する。近接の場合、実際に装備している武器と同じsvalか、それ以外かで上昇量が異なる。

上昇量はランク帯ごとに定められた「1回あたりの上昇量」の配列で与えられ、次のランク閾値を超えない範囲で加算される。近接武器の上昇量は以下の通り（GainAmountListは[初心者],[入門者],[熟練者],[エキスパート]帯での1回あたり上昇量）。

帯 装備武器と同種 それ以外
[初心者]帯 80 8
[入門者]帯 10 1
[熟練者]帯 1 0
[エキスパート]帯 1/2の確率で1 0

弓（射撃）での上昇量は次の通り。

帯 使用中の弓と同種 それ以外
[初心者]帯 80 8
[入門者]帯 25 2
[熟練者]帯 10 0
[エキスパート]帯 2 0

上昇には以下の共通条件がある（gain_attack_skill_exp）。

  • [熟練者]帯から[エキスパート]帯への上昇にはプレイヤーレベル20以上（lev > 19）が必要
  • [エキスパート]帯から[達人]帯への上昇にはプレイヤーレベル35以上（lev > 34）が必要
  • また、弓の射撃で熟練度が入るのは対象モンスターのレベル+10がプレイヤーレベルより大きい場合のみ。近接では素手（マーシャルアーツ）と二刀流の熟練度取得に同様のモンスターレベル判定がある（武器熟練度自体には近接時のモンスターレベル制限はない）。

ランクが命中・ダメージに与える寄与

近接武器の命中（calc_to_hit_bonus相当、player-status.cpp）:

命中補正 += (weapon_exp[tval][sval] - [入門者]閾値(4000)) / 200

熟練度が[入門者]閾値(4000)を基準に、200ごとに命中+1される。達人まで上げると (8000-4000)/200 = +20 の命中補正となる。

弓の命中・威力（shoot.cpp）:

  • 通常の弓・スリング: (weapon_exp - [達人]閾値/2(4000)) / 200 を命中値に加算（倍率200）
  • クロスボウ（ボルト使用）: weapon_exp / 400 を加算（倍率400、[達人]閾値の減算なし）

ダメージ: ソースを確認した範囲では、武器熟練度・ランクは近接の命中および弓の命中/発射計算に寄与するが、近接の打撃回数（num_blow）や打撃ダメージダイスには直接寄与していない。近接打撃回数は腕力・器用さ・職業・武器重量などから決まる。

マーシャルアーツ（素手）技能

素手戦闘の熟練度（skill_exp[MARTIAL_ARTS]）。上限は職業ごとに設定される（僧（MONK）・練気術師（ForceTrainer）・狂戦士（BERSERKER）は開始4000・上限8000＝[達人]、多くの職業は上限4000程度）。

  • 上昇契機: 素手攻撃時、対象モンスターのレベル+10がプレイヤーレベル以下だと上昇しない（monrace.level + 10 <= lev で打ち切り）。
  • 上昇量: [初心者]帯40、[入門者]帯5、[熟練者]帯1、[エキスパート]帯は1/3の確率で1。ランク上昇のレベル条件（20/35）は武器と共通。
  • 命中への寄与: 命中 += (skill_exp[MARTIAL_ARTS] - [入門者]閾値(4000)) / 200。

素手の打撃技（ma_blows、17種）の選択はプレイヤーレベルと技の難度で決まり、熟練度ランクそのものではなく主にレベルに依存する。打撃回数もレベル・器用さで決まる。

二刀流技能

二刀流の熟練度（skill_exp[TWO_WEAPON]）。上限は職業依存（戦士・盗賊・侍・狂戦士などは上限8000）。

  • 上昇契機: 両手に武器を持って攻撃した際、(skill_exp - 1000) / 200 < monrace.level を満たすときに上昇する。
  • 上昇量: [初心者]帯80、[入門者]帯4、[熟練者]帯1、[エキスパート]帯は1/3の確率で1。
  • 効果: 副手の命中ペナルティ軽減。ペナルティは概ね (100 - skill_exp/160) - (130 - 武器重量)/8 で計算され、熟練度が高いほどペナルティが小さくなる。特定の武器の組み合わせ（クイック＆タイニー等）ではペナルティが半減され-5される。

乗馬技能

騎乗の熟練度（skill_exp[RIDING]）。閾値が武器系と異なり、[入門者]500・[熟練者]2000・[エキスパート]5000・[達人]8000（riding_skill_rank）。上限は職業依存（獣王(BEASTMASTER)・騎兵(KIHEI)は開始500・上限8000、多くの職業は0～5000）。

上昇契機は3つ。

  • 近接攻撃時（gain_riding_skill_exp_on_melee_attack）: 攻撃対象・騎乗モンスターのレベルに応じて上昇。(now_exp/200 - 5) < 対象モンスターレベル で+1、now_exp/100 < 騎乗モンスターレベル のとき差に応じて加算。
  • 射撃時（gain_riding_skill_exp_on_range_attack）: (skill_exp - 1000) / 200 < 騎乗モンスターレベル かつ1/2の確率で+1。
  • 落馬判定時（gain_riding_skill_exp_on_fall_off_check）: 上限が1000以下の職業では上昇しない。被ダメージと騎乗モンスターレベルに応じて上昇。

効果: 騎乗中の命中ペナルティを軽減する。ペナルティは概ね 騎乗モンスターレベル - skill_exp/80 + 30（下限30、調教可能職は固定5）で、熟練度が高いほど小さくなる。

盾（防御）技能

盾など「protector」装備を身につけている際に働く熟練度（skill_exp[SHIELD]）。上限は職業依存（騎兵・観光客(TOURIST)は上限8000、多くは0～6000）。

  • 上昇契機: モンスターに攻撃された時（gain_armor_exp）。主手か副手にprotectorを装備している場合、モンスターレベルに応じて上昇。(cur/100) < モンスターレベル のとき、差が大きいほど多く加算される。
  • 効果: protector装備時にACへ加算。AC += skill_exp[SHIELD] * (1 + lev/22) / 2000。熟練度とプレイヤーレベルが高いほどAC上昇量が増える。

呪文熟練度

魔法・歌（MUSIC）・呪術（HEX）の各呪文について、第1領域はspell_exp[0..31]、第2領域はspell_exp[32..63]に熟練度を保持する。閾値は[入門者]900・[熟練者]1200・[エキスパート]1400・[達人]1600（spell_skill_rank）。

  • 上昇契機（gain_spell_skill_exp）: 該当領域が自分の第1/第2領域であり、呪文IDが有効(0～31)なときに上昇。第1領域と第2領域で上昇量が異なる。
  • 歌・呪術など継続詠唱系は毎ターン少量上昇する別処理（gain_continuous_spell_skill_exp）を持つ。
  • 上昇にはダンジョン階層（dun_level）とプレイヤーレベル・呪文レベルの関係による条件がある。おおむね「深い階で、自分のレベルや呪文レベルに対して階層が十分高い」ときにのみ上位帯へ上昇する。

職業による特例

  • スペルマスター(SORCERER): exp_of_spell が常に[達人]閾値(1600)を返す＝全呪文が常に達人扱い。
  • 赤魔道師(RED_MAGE): 常に[熟練者]閾値(1200)扱い。

技能値の確認方法

ゲーム内の「知識」メニューから、武器熟練度（do_cmd_knowledge_weapon_exp）・技能熟練度（do_cmd_knowledge_skill_exp）・呪文熟練度をランク表示（[初心者]～[達人]）で確認できる。上限に達している項目には「!」が表示される。
