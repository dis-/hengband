電撃 / AttributeType::ELEC

地形処理 effect-feature.cpp で参照
アイテム処理 effect-item.cpp で参照
描画色 0x02

概要

電撃属性（AttributeType::ELEC）は、稲妻・電気による攻撃属性。主な発生源は電撃のブレス、サンダー・ボルト／ボール、稲妻の矢などのボルト・ボール系呪文や、電撃オーラを持つモンスターの接触ダメージ。

ボール系ではゼロ地点からの距離 r に応じて基礎減衰を受ける。

dam = (dam + r) / (r + 1)

モンスターへの効果

effect_monster_elec() で処理される。電撃免疫（IMMUNE_ELEC）を持つモンスターのみ軽減され、それ以外は素通し（等倍）。

条件 メッセージ ダメージ倍率
IMMUNE_ELEC 保持 「にはかなり耐性がある！」 dam /= 9
上記以外 （なし） 等倍 
// 免疫時
dam /= 9;

プレイヤーへの効果

effect_player_switcher から effect_player_elements() 経由で elec_dam() が呼ばれる。盲目時のみ「電撃で攻撃された！」と表示。

ダメージ倍率は calc_elec_damage_rate() による。

per = 100
（電撃脆弱がある場合、原因ごとに per += per/3。ただし変異由来の脆弱は per *= 2）
耐性(has_resist_elec)      : per = (per + 2) / 3
一時耐性(is_oppose_elec)   : per = (per + 2) / 3
電撃免疫(has_immune_elec)  : per = 0（ダメージ無効）
dam = dam * per / 100

耐性と一時耐性は乗算的に効き、両方あれば概ね 1/9 程度まで軽減される。

副次効果:

  • 免疫・一時耐性がなく、耐性もない状態で 1/CHANCE_ABILITY_SCORE_DECREASE の確率で敏捷（DEX）が低下する（分身時を除く）。
  • ダメージ後、aura 由来でなく「一時耐性と耐性の両方」が揃っていない場合、inventory_damage(BreakerElec(), inv) で所持品破壊判定。破壊レベル inv は元ダメージが 30 未満で 1、60 未満で 2、それ以上で 3。

電撃オーラを持つモンスターへの接触時は touch_zap_player() から elec_dam(..., aura=true) が呼ばれ、「電撃をくらった！」と表示される。

アイテムへの効果

affect_item() の case AttributeType::ELEC で、BreakerElec().hates() に該当する床アイテム（指輪・アミュレット・ワンド等）が破壊される。

  • メッセージ: 「壊れてしまった！」
  • TR_IGNORE_ELEC を持つアイテムは無視（破壊されない）。
  • 固定・ランダムアーティファクトは「%sは影響を受けない！」で破壊されない。

地形への効果

affect_feature() では、対象が木（TREE）の場合のみ効果を持つ。

  • メッセージ: 「木は燃えた。」
  • 木は 1/3 で藪（BRAKE）、それ以外で草（GRASS）へ変化する。

これ以外のダンジョン地形に対しては効果を持たない（無視される属性群に含まれる）。
