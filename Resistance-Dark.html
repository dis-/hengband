暗黒耐性（TR_RES_DARK）

← プレイヤー耐性一覧 / Resistances

概要

暗黒耐性は TR_RES_DARK を中心に、has_resist_dark() と calc_dark_damage_rate() で参照される。暗黒属性ダメージを乱数倍率で軽減し、暗黒属性による盲目付与条件にも関係する。

効果

ダメージ倍率は calc_dark_damage_rate() の per で計算され、最終ダメージは dam * per / 100 になる。

per = 100;
if (has_immune_dark(player_ptr)) return 0;
if (has_resist_dark(player_ptr)) {
    per \*= 400;
    per /= randrate(4, 7, mode);
}

CALC_RAND の randrate(4, 7, mode) は randint1(4) * 100 + 7 * 100。耐性ありの倍率は 40000 / (800..1100)、すなわち 36%..50% 相当になる。

条件 効果
has_immune_dark() ダメージ倍率 0
has_resist_dark() per *= 400; per /= randrate(4, 7, mode)

暗黒属性の盲目付与は effect_player_dark() で処理される。

go_blind = !is_blind;
go_blind &= !has_resist_blind(player_ptr);
go_blind &= !(has_resist_dark(player_ptr) || has_immune_dark(player_ptr));
go_blind &= !check_multishadow(player_ptr);
if (go_blind) BadStatusSetter(player_ptr).mod_blindness(randint1(5) + 2);
条件 効果
既に盲目でない、かつ !has_resist_blind()、かつ !(has_resist_dark()
has_resist_dark() または has_immune_dark() 上記の暗黒による盲目付与を防ぐ

深淵（ABYSS）ダメージへの軽減

暗黒耐性は、深淵属性（AttributeType::ABYSS）ダメージの唯一の軽減手段でもある。calc_abyss_damage_rate() は has_resist_dark() が真のとき、暗黒と同じ式で倍率を下げる。

per = 100;
if (has_resist_dark(player_ptr)) {
    per \*= 400;
    per /= randrate(4, 7, mode);
}

すなわち深淵ダメージも 400 / (1d4 + 7) ≒ 36〜50%（平均約42%）に軽減される。暗黒耐性が無い場合、深淵には他に軽減手段が無い（浮遊なし＋反テレポートではむしろ1.25倍に増える）。詳細は 深淵 / ABYSS を参照。

一時耐性・補足

has_resist_dark() は通常耐性に加えて TR_IM_DARK、ult_res、tim_res_dark、tim_imm_dark を耐性要因に含める。

result = common_cause_flags(player_ptr, TR_RES_DARK) | common_cause_flags(player_ptr, TR_IM_DARK);
if (player_ptr->ult_res || player_ptr->tim_res_dark || player_ptr->tim_imm_dark) {
    result |= FLAG_CAUSE_MAGIC_TIME_EFFECT;
}

has_immune_dark() は TR_IM_DARK に加え、wraith_form または tim_imm_dark を免疫要因に含める。
