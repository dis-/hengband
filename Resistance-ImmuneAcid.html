酸免疫（TR_IM_ACID）

← プレイヤー耐性一覧 / Resistances

概要

酸免疫は TR_IM_ACID、または ele_immune 中に対応する DEFENSE_* が立っている状態で得られる。has_immune_acid() が真なら、酸属性ダメージは免疫として扱われる。

has_resist_acid() は通常耐性と ult_res に加えて has_immune_acid() の結果も含む。免疫がある場合、通常耐性・一時耐性・弱点より強く、通常の被ダメージは 0 になる。

効果

calc_acid_damage_rate() では、倍率計算の先頭で次の判定を行う。

if (has_immune_acid(player_ptr)) return 0;

酸属性の倍率式は次の通り。

per = 100;
for each cause in has_vuln_acid(player_ptr):
    if (cause == FLAG_CAUSE_MUTATION) per *= 2;
    else per += per / 3;
if (has_resist_acid(player_ptr)) per = (per + 2) / 3;
if (is_oppose_acid(player_ptr)) per = (per + 2) / 3;
return per;
条件 効果
has_immune_acid(player_ptr) 通常の酸HPダメージは 0
変異以外の弱点要因 要因ごとに per += per / 3
PlayerMutationType::VULN_ELEM による弱点 per *= 2
has_resist_acid(player_ptr) per = (per + 2) / 3
is_oppose_acid(player_ptr) さらに per = (per + 2) / 3

副次効果は次の条件で処理される。

処理 条件
do_dec_stat(player_ptr, A_CHR) `aura
所持品破壊 inventory_damage(..., BreakerAcid(), inv) !aura && !(is_oppose_acid(player_ptr) && has_resist_acid(player_ptr))
acid_minus_ac() による装備AC劣化 `aura
acid_minus_ac() 成功時 dam = (dam + 1) / 2

一時耐性・補足

is_oppose_acid() は次のいずれかで真になる。

条件
player_ptr->oppose_acid != 0
music_singing(player_ptr, MUSIC_RESIST)
PlayerClass(player_ptr).samurai_stance_is(SamuraiStanceType::MUSOU)

地形 TerrainCharacteristics::ACID_PUDDLE は !is_invuln(player_ptr) && !has_immune_acid(player_ptr) のときだけ地形ダメージ処理に入る。走行判定でも、酸の水たまりは酸免疫があれば危険地形扱いで停止しない。
