プラズマ / AttributeType::PLASMA

← AttributeType 一覧

項目 内容
ID 12
enum AttributeType::PLASMA
分類 ダメージ / Damage
プレイヤー処理 effect_player_plasma()
モンスター処理 effect_monster_plasma()
地形処理 effect-feature.cpp で参照
アイテム処理 effect-item.cpp で参照
描画色 0x0B

概要

プラズマ属性（AttributeType::PLASMA）は、超高熱のプラズマによる攻撃属性。主な発生源はプラズマのブレス、プラズマ・ボルト／ボールなどのボルト・ボール系呪文。火炎と電撃の双方の性質を持つ。

ボール系ではゼロ地点からの距離 r に応じて基礎減衰を受ける。

dam = (dam + r) / (r + 1)

モンスターへの効果

effect_monster_plasma() で処理される。プラズマ耐性（RESIST_PLASMA）を持つモンスターのみ軽減される。

条件 メッセージ ダメージ倍率
RESIST_PLASMA 保持 「には耐性がある。」 dam = dam * 3 / (randint1(6) + 6)
上記以外 （なし） 等倍 
// 耐性時（乱数軽減、約 3/7～3/12 倍）
dam *= 3;
dam /= randint1(6) + 6;

プレイヤーへの効果

effect_player_plasma() で処理される。盲目時のみ「何かとても熱いもので攻撃された！」と表示。

ダメージ倍率の補正は行われず、ダメージはそのまま take_hit() に渡される（プラズマ専用の耐性倍率計算は無い）。

副次効果:

  • 轟音耐性（has_resist_sound）が無く分身でない場合、朦朧を付与。付与量は元ダメージが 40 超なら randnum1(35)、それ以下なら randnum1(dam * 3 / 4 + 5)。
  • 火炎耐性・火炎一時耐性・火炎免疫のいずれも無い場合、inventory_damage(BreakerAcid(), 3) で所持品破壊判定。
// 朦朧付与量
plus_stun = randnum1((dam > 40) ? 35 : (dam * 3 / 4 + 5));
mod_stun(plus_stun);

アイテムへの効果

affect_item() の case AttributeType::PLASMA で、火炎と電撃の両方の破壊判定を行う。

  • BreakerFire().hates() に該当: 「燃えてしまった！」（TR_IGNORE_FIRE で無視）
  • BreakerElec().hates() に該当: 「壊れてしまった！」（TR_IGNORE_ELEC で無視）。電撃判定は火炎の ignore を上書きしてから再評価される。
  • 固定・ランダムアーティファクトは「%sは影響を受けない！」で破壊されない。

地形への効果

affect_feature() では、対象が木（TREE）の場合のみ効果を持つ。

  • メッセージ: 「木は燃えた。」
  • 木は 1/3 で藪（BRAKE）、それ以外で草（GRASS）へ変化する。

これ以外のダンジョン地形に対しては効果を持たない（無視される属性群に含まれる）。
