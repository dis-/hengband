モンスターの近接攻撃

← 解析 / Analysis

概要

モンスターの近接攻撃（打撃, blow）は、モンスターがプレイヤーの隣接マスに移動した際、または移動しようとした先にプレイヤーがいた際に発生する。1体のモンスターは1ターンに最大4回まで打撃を行う（MAX_NUM_BLOWS = 4）。各打撃は「攻撃方法（method）」「攻撃効果（effect）」「ダメージダイス（damage_dice）」の3要素を持つ。

処理の起点は exe_monster_attack_to_player()（monster-attack-processor.cpp）で、そこから MonsterAttackPlayer::make_attack_normal()（monster-attack-player.cpp）が呼ばれ、打撃1回ごとに命中判定→効果適用が繰り返される。

攻撃が発生する条件

打撃処理に入る前に、以下がチェックされる（check_no_blow() および exe_monster_attack_to_player()）。

  • モンスターが NEVER_BLOW（打撃を行わない）フラグを持つ場合は攻撃しない。
  • ダンジョンが NO_MELEE（近接攻撃無効）属性を持つ場合、攻撃は行われない（STUPID でない、または混乱していないモンスターは移動自体を取りやめる）。
  • モンスターがプレイヤーに敵対的（hostile）でなければ攻撃しない。

また、プレイヤーが騎乗している場合、打撃が実行されるのは 1/2 の確率のみ（if (!player_ptr->riding || one_in_(2))）。

各打撃ループ内では check_monster_continuous_attack() により、モンスターが有効・method が NONE でない・プレイヤーとの距離が1以下（隣接）・プレイヤーが生存かつ離脱していないことを毎回確認する。1つでも満たさなければ以降の打撃を打ち切る。

なお、ペットのユニークモンスターが EXPLODE（爆発）method を持つ場合、method は HIT に変換され、ダメージダイスの個数が 1/10 になる。

攻撃を受ける前の回避処理（プレイヤー側）

打撃処理の冒頭で、プレイヤークラス・特技に応じた割り込み回避が行われる（make_attack_normal()）。

  • 剣術家の「居合」の型：メッセージを表示し HISSATSU_IAI で反撃。倒せば打撃は発生しない。
  • 忍者などの「変わり身（kawarimi）」：
    • 攻撃開始前に randint0(55) < (プレイヤーレベル × 3 / 5 + 20) の確率で発動判定し、成功すればテレポートして攻撃を回避。
    • 各打撃が命中した後にも kawarimi 判定があり、成功すればその場を離脱して攻撃を打ち切る。

命中判定

命中判定は check_hit_from_monster_to_player()（combat/attack-accuracy.cpp）で行う。重要な特徴として、モンスター側のAC（防御力）は命中判定に一切関与せず、プレイヤーのACによる回避のみが判定される。 モンスターの命中しやすさは「打撃効果ごとに定められた power 値」と「モンスターのレベル」で決まる。

命中判定 check_hit_from_monster_to_player(power, level, stun):
    k = randint0(100)                       // 0〜99

    // モンスターが朦朧(stun)状態なら 1/2 で必ず失敗
    if (stun != 0 && one_in_(2)) return 命中せず

    // 常時命中5% / 常時失敗5%
    if (k < 10) return (k < 5)              // k∈[0,4]で命中, k∈[5,9]で失敗

    i = power + (level * 3)

    ac = プレイヤーの ac + to_a
    // 酔拳(ATTACK_SUIKEN)状態なら回避力に (プレイヤーレベル × 2) を加算
    if (酔拳) ac += (プレイヤーレベル * 2)

    if (i > 0 && randint1(i) > (ac * 3 / 4)) return 命中
    return 命中せず
  • power は打撃効果ごとの基本命中値（後述の effect 一覧表を参照）。
  • level はモンスターのレベル。ただし打撃処理全体で使われる rlev は「レベルが1以上ならその値、0以下なら1」に補正される（make_attack_normal()）。
  • 効果が FLAVOR（フレーバー）の打撃は命中判定を行わず必中扱いとなる。

AC技能経験・回避時の処理

命中しなかった場合、process_monster_attack_evasion() により、method が HIT/TOUCH/PUNCH/KICK/CLAW/BITE/STING/SLASH/BUTT/CRUSH/ENGULF/CHARGE のいずれかであれば「回避した」旨のメッセージを表示し、盾（防具）を装備していれば盾技能の経験値が加算される（gain_armor_exp()）。それ以外の method では回避メッセージ等は出ない。

対邪悪結界による撃退

命中後、effect_protecion_from_evil() により以下がすべて満たされると、その打撃は撃退され効果が発動しない。

撃退条件（すべて満たすこと）:
    プレイヤーが「対邪悪結界(protection from evil)」状態である
    かつ モンスターが EVIL（邪悪）属性
    かつ プレイヤーレベル >= rlev（モンスターレベル）
    かつ (randint0(100) + プレイヤーレベル) > 50

ダメージの決定

命中して撃退もされなかった場合、process_monster_attack_hit() にてダメージを算出する。

ダメージ = damage_dice.roll()   // 打撃定義のダイスを振る（例: 3d5 なら 3〜15）
if (爆発攻撃 explode) ダメージ = 0   // 爆発はダイスによる基本ダメージを持たない

その後 switch_monster_blow_to_player()（monster-attack-switcher.cpp）で効果種別ごとの処理を行い、多くの効果は最終的に take_hit() でHPを減らす。

物理系ダメージのAC軽減

HURT（通常攻撃）・SUPERHURT（痛恨）・SHATTER（粉砕）の3効果は、プレイヤーのACによりダメージが軽減される。

AC軽減後ダメージ = ダメージ - (ダメージ * min(AC, 150) / 250)
  • ここでの AC = プレイヤーの ac + to_a。
  • ACは150で頭打ち。150以上でも軽減率は 150/250 = 最大60%軽減。
  • ACが負の場合はこの式によりダメージが増加する。

SUPERHURT（痛恨の一撃）

SUPERHURT 効果は以下の条件で「痛恨の一撃」となり、AC軽減を適用した上でダメージを2倍にする。

痛恨条件:
    ( randint1(rlev*2 + 300) > (AC + 200)  または  one_in_(13) )
    かつ 幻影(multishadow)状態でない
→ ダメージ -= ダメージ * min(AC,150) / 250
   「痛恨の一撃！」
   ダメージ = max(ダメージ, ダメージ * 2)   // 実質2倍

条件を満たさない場合は通常の HURT と同じ処理にフォールスルーする。

切り傷・朦朧の付与

describe_monster_attack_method()（monster-attack-describer.cpp）で攻撃方法に応じて do_cut（切り傷）/ do_stun（朦朧）フラグが立つ（下の method 一覧を参照）。両方が立った場合は select_cut_stun() で 1/2 ずつどちらか一方を無効化する。

  • 切り傷：PlayerCut::get_accumulation(ダメージダイス最大値, 実ダメージ) で蓄積量を算出して付与。
  • 朦朧：PlayerStun::get_accumulation_rank() で蓄積ランクを求め、以下で補正する（process_player_stun()）。
    • ダイス最大値 < 実ダメージ かつ ランク ≦ 6 なら ランク+1
    • 1/50 の確率でランク+1
    • 腕力+器用+耐久（AD&D表記の実値換算）の合計が80超なら ランク−1

爆発とオーラ反撃

  • 攻撃方法が EXPLODE の場合、monster_explode() でモンスター自身が消滅（自傷でHP+1相当のダメージを受けて死亡）する。
  • 命中処理の最後に process_aura_counterattack() が呼ばれ、プレイヤーの炎/冷気/電撃オーラ等による反撃が行われる。

補足:

  • 上表の「経験値吸収」の基本量計算は共通して Dice::roll(drain_value, 6) + (プレイヤー経験値 / 100) * MON_DRAIN_LIFE で、MON_DRAIN_LIFE = 2（gamevalue.h）。
  • DR_LIFE と CHAOS の生命力吸収時、実ダメージが5以下または吸収抵抗成功なら回復しない。回復時は Dice::roll(4, ダメージ/6) 分モンスターのHPが回復する。
  • 多くの副次効果は「幻影（multishadow）状態」だと発動しない。

幻影・無敵による無効化

  • 幻影（multishadow）状態のとき、多くの状態異常付与・盗み・吸収などの副次効果が無効化される（各効果内で check_multishadow() チェック）。
  • 実ダメージの軽減（無敵など）は take_hit() 内で処理される。

打撃情報の学習（思い出）

increase_blow_type_seen() により、正しく攻撃を認識できた場合にモンスター種別の打撃回数記録 r_blows[] が増える。非自明な打撃はダメージ0だと（既に一定以上の知識がある場合を除き）記録が増えない。幻覚攻撃（do_silly_attack）時は記録しない。

参考との差異について

参考wikiは効果23種・方法16種と記載しているが、これは旧版の情報である。現行ソース（monster-attack-effect.h / monster-attack-table.h）では効果は FLAVOR・HUNGRY・CHAOS・INERTIA・STUN などを含め上表の通り、方法は CRAWL〜SHOW を含め24種に拡張されている。本解説の数値はすべて現行ソースで確認済み。
