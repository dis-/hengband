暗黒 / AttributeType::DARK

← AttributeType 一覧

項目 内容
ID 16
enum AttributeType::DARK
分類 ダメージ / Damage
プレイヤー処理 effect_player_dark()
モンスター処理 effect_monster_dark()
地形処理 effect-feature.cpp で参照
アイテム処理 -
描画色 0x07

概要

暗黒 (DARK) 属性は闇による攻撃。ボール系の距離減衰は共通の式で処理される。

dam = (dam + r) / (r + 1)

モンスターへの効果

処理は effect_monster_dark() (effect-monster-lite-dark.cpp)。

  • 暗黒耐性 (RESIST_DARK) を持たないモンスターには倍率補正なし（等倍でダメージが通る）。
  • 暗黒耐性 (RESIST_DARK) を持つモンスターは「には耐性がある！」と表示され、ダメージが減衰する。

耐性によるダメージ倍率:

条件 ダメージ倍率
暗黒耐性 (RESIST_DARK) ×2 ÷ (randint1(6)+6)（実効 2/7〜2/12）
上記なし ×1（等倍） 
// 暗黒耐性
dam = dam * 2 / (randint1(6) + 6);

閃光 (LITE) と異なり、HURT_LITE（光弱点）などによる倍増処理は存在しない。

プレイヤーへの効果

処理は effect_player_dark() (effect-player-resist-hurt.cpp)。ダメージ倍率は calc_dark_damage_rate() による。

dam = dam * calc_dark_damage_rate(player_ptr) / 100;

ダメージ倍率 calc_dark_damage_rate():

条件 倍率
暗黒免疫 (immune_dark) 0%（無効）
暗黒耐性 (resist_dark) ×400 ÷ randrate(4,7)（実効 ≒ 8〜14%）
上記なし ×100（等倍）

追加効果:

  • 盲目でなく、盲目耐性を持たず、暗黒耐性・暗黒免疫のいずれも持たず、多重影でない場合、randint1(5)+2 ターンの盲目になる。
  • 盲目時は攻撃を受けると「何かで攻撃された！」と表示される。

アイテムへの効果

affect_item() (effect-item.cpp) に DARK 属性の case は存在せず、床のアイテムを破壊しない。

地形への効果

処理は affect_feature() (effect-feature.cpp) の DARK_WEAK / DARK / ABYSS 共通 case（マスを暗くする処理）。

  • 幻影階 (phase out) 中、または対象マスが鏡の場合は何もしない。
  • 地下、または夜間の場合、隣接する 8 マスのいずれかが発光地形 (GLOW) を持っていれば暗くしない。
  • 上記条件を満たせば対象マスの CAVE_GLOW を消去して暗くする。
  • 地形が REMEMBER 特性を持たない、または闇の元素耐性 (ElementRealmType::DARKNESS) を持つ場合、マスの記憶 (CAVE_MARK) を消去する。
  • 周辺の照明を更新し、マスにモンスターがいれば状態を更新する。
