混乱耐性（TR_RES_CONF）

← プレイヤー耐性一覧 / Resistances

概要

混乱耐性は TR_RES_CONF に対応する耐性で、has_resist_conf() が真になると混乱状態の付与を防ぐ。状態付与本体の BadStatusSetter::mod_confusion() と set_confusion() は耐性判定を持たず、呼び出し側が has_resist_conf() を見て付与を止める。

効果

混乱状態の付与

mod_confusion() は現在値に加算して set_confusion() を呼ぶだけで、耐性による確率軽減はない。

bool BadStatusSetter::mod_confusion(const TIME_EFFECT tmp_v)
{
    return this->set_confusion(this->player_ptr->effects()->confusion().current() + tmp_v);
}

呼び出し側では、混乱耐性がある場合に付与処理を呼ばない。

if (!has_resist_conf(player_ptr) && !check_multishadow(player_ptr)) {
    bss.mod_confusion(randint1(20) + 10);
}
条件 混乱付与
混乱耐性なし 呼び出し側の条件を満たすと付与される
混乱耐性あり 耐性チェックがある付与元では完全に防ぐ

混乱属性ダメージ

混乱属性ダメージでは calc_conf_damage_rate() が混乱耐性を参照する。

per = 100;
if (has_resist_conf(player_ptr)) {
    per *= 500;
    per /= randrate(4, 7, mode);
}

CALC_RAND では randrate(4, 7) は (1d4 + 7) * 100 なので、実戦時の倍率は次の範囲になる。

damage_rate = 500 / (1d4 + 7)
実効倍率 = 45% から 62%
条件 混乱属性ダメージ倍率
混乱耐性なし 100%
混乱耐性あり 500 / (1d4 + 7)%

混乱打撃

モンスターの混乱打撃では、耐性がある場合に打撃ダメージも軽減される。

if (has_resist_conf(player_ptr)) {
    monap_ptr->damage = monap_ptr->damage * (randint1(4) + 3) / 8;
}
if (!has_resist_conf(player_ptr) && !check_multishadow(player_ptr)) {
    BadStatusSetter(player_ptr).mod_confusion(3 + randint1(monap_ptr->rlev));
}
条件 打撃ダメージ倍率 混乱付与
混乱耐性なし 100% 3 + 1..rlev 加算
混乱耐性あり (1d4 + 3) / 8 付与されない
