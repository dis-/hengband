描画色 mh_attr(15)

概要

カオス（無秩序）属性は、混沌の力による攻撃属性である。ダメージに加えて、モンスターには変身と混乱、プレイヤーには混乱・幻覚・突然変異・経験値吸収といった多彩な追加効果をもたらす。アイテムや地形も破壊する。

モンスターへの効果

effect_monster_chaos により以下の順で判定される。

  • カオス耐性（RESIST_CHAOS）を持つ場合、「には耐性がある。」と表示されダメージが減少する。
  • カオス耐性が無く、デーモン（DEMON）で、かつ 1/3 の確率で「はいくらか耐性を示した。」と表示されダメージが減少する。
  • 上記いずれにも該当しない場合、変身（do_polymorph）と混乱の追加効果が発生する。

耐性・半耐性時のダメージ倍率は共通で以下の通り。

条件 ダメージ倍率
カオス耐性あり ×3 ÷ (1d6 + 6)
デーモンが 1/3 で半耐性 ×3 ÷ (1d6 + 6)

耐性が無い場合の追加効果:

  • 変身（do_polymorph）: randint1(90) <= モンスターのレベル の場合は変身しない。変身に成功すると「が変身した！」と表示されダメージは 0 になる。ユニークや QUESTOR は別処理で変身しにくい。
  • 混乱付与量:
do_conf = (5 + 1d11 + r) / (r + 1)

（r は爆発中心からの距離）

プレイヤーへの効果

effect_player_chaos による処理。ダメージは calc_chaos_damage_rate により補正される。

dam = dam * calc_chaos_damage_rate() / 100

分身（マルチシャドウ）状態の場合は追加効果を受けず、ダメージのみを受ける。それ以外の場合の追加効果:

  • 混乱耐性・カオス耐性のいずれも無い場合、混乱を randint0(20) + 10 追加。
  • カオス耐性が無い場合、幻覚を 1d10 追加。さらに 1/3 の確率で「あなたの身体はカオスの力で捻じ曲げられた！」と表示され、突然変異（gain_mutation）が発生する。
  • 地獄耐性・カオス耐性のいずれも無い場合、経験値吸収:
drain_exp(5000 + exp/100, 500 + exp/1000, 75)
  • カオス耐性が無い、または 1/9 の確率で、電撃と火炎によるインベントリ破壊（各威力 2）が発生する。

アイテムへの効果

affect_item の CHAOS 処理により、アイテムは「壊れてしまった！」と表示され破壊される。ただし以下は影響を受けない（ignore）。

  • TR_RES_CHAOS（カオス耐性）を持つアイテム
  • カオスの巻物（SV_SCROLL_CHAOS）

固定・ランダムアーティファクトは破壊されない。

地形への効果

affect_feature において、木（TREE）に対しては「木は粉砕された。」と表示され、1/3 の確率で藪、それ以外で草地に変化する。それ以外の地形に対する固有の効果は無い。
