魅力維持（TR_SUST_CHR）

← プレイヤー耐性一覧 / Resistances

概要

魅力維持（TR_SUST_CHR）は、do_dec_stat(player_ptr, ${stat}) による魅力低下を防ぐ能力です。dec_stat(player_ptr, stat, amount, permanent) を直接呼ぶ処理は、この維持判定を通りません。

効果

${func}(player_ptr) は common_cause_flags(player_ptr, ${flag}) を返し、player_ptr->ult_res があれば FLAG_CAUSE_MAGIC_TIME_EFFECT も追加します。

BIT_FLAGS result = common_cause_flags(player_ptr, ${flag});
if (player_ptr->ult_res) {
    result |= FLAG_CAUSE_MAGIC_TIME_EFFECT;
}
return result;

do_dec_stat は能力値ごとに対応する維持を確認し、維持が有効なら通常は dec_stat を呼ばずに終了します。

条件 処理
${func}(player_ptr) が真、かつ `(!ironman_nightmare
上記条件を満たさない dec_stat(player_ptr, ${stat}, 10, (ironman_nightmare && !randint0(13))) を実行

一時耐性・補足

ironman_nightmare 中は randint0(13) が 0 の場合だけ維持をすり抜け、permanent 引数を真にして dec_stat されます。dec_stat 側の現在値低下は、18 以下では amount > 90、amount > 50、amount > 20 の各条件で追加減少した後さらに 1 減少し、18 超では乱数を含む loss を引きます。
